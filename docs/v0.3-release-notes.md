# DreamFlutter v0.3 发布说明

v0.3 打地基：Agent 可以在隔离的 WSL 沙箱里工作，有了子 Agent；原来的「书桌」变成在沙箱里独立干活的「蝶君」；每个工作区有自己的运行环境；修了 v0.2 安装包实测里的问题。下一步见 [roadmap.md](roadmap.md)。

## 蝶君（原来的书桌）

- 导航改名：「对话」→「工作台」，「书桌」→「蝶君」。
- 蝶君在自己的 WSL 沙箱里工作：命令、文件、搜索都在沙箱里，**不弹审批**；默认不开 MCP，它做的卡片不能用这台电脑上的文件、网络或程序。
- 「交流」：和蝶君的对话，和工作台的会话分开，工作台里看不到。拖进来的文件以副本放进沙箱的 `inbox`。
- 「工作」：原书桌的写笺、资料、卡片都搬了过来（第一次启动时自动迁移）。写笺右上角「交给蝶君」直接交付（不再弹选动作的框），资料以副本进 `inbox`；蝶君把结果放进 `outbox`，右栏「交付」里预览文本和图片、改简单文本、保存到这台电脑。
- 沙箱还没建好时，整个蝶君页只显示建立沙箱。

## WSL 沙箱

- 设置 › 蝶君沙箱：建立、逃逸自检、联网开关、重置到干净状态、删除。没装 WSL 时给安装说明，工作台照常用。
- 沙箱是随应用附带的 Debian 13 镜像（含 Python、uv、git、ripgrep、常用 Python 包、中文字体），**不用联网，建立大约 1–2 分钟**。
- 加固：看不到 Windows 的磁盘、运行不了 Windows 程序、没有 sudo、改不了系统设置；离线只拦蝶君自己，不影响你其他的 WSL。自检 11 项。

## Agent

- **子 Agent**：标准模式的 Agent 可以派「通用」或「调研员」（只读）子 Agent，一次最多同时跑 4 个；对话里显示每个子 Agent 在做什么，结束后能点开看它的回复；花费算进这次运行。
- **工作区运行环境**：应用自带 rg、fd、uv 和便携 Python 3.13，Agent 直接能用；每个工作区有一个 `.dreamflutter\` 文件夹（git 看不到），放虚拟环境、临时文件和工作区笔记 `workspace.md`，Agent 每次运行都读这份笔记。
- **提问限时**：Agent 提问后默认等 1 分钟，没回答就选推荐项（设置 › 对话可改成 30 秒 / 5 分钟 / 一直等）。批准操作不受影响。

## 修复

- 思考档位：新装的应用里先建会话、后配模型时只剩「关闭」的问题；设置页的默认思考级别按默认模型列档位。
- 从浏览器、QQ、微信等拖图片进对话（以前只认文件）。
- 发消息、排队消息发出时窗口上下抖动。
- 安装包里缺 ripgrep，搜索工具报 `rg ENOENT`。
- 回复里提到的文件路径变成链接：左键在资源管理器里选中，右键用默认程序打开。
- 上下文面板加「缓存命中率」。

## 其他

- 记忆系统的开发设计 [memory-design.md](memory-design.md)（v0.5 实现）。
- 安装包多了沙箱镜像、uv 和 Python，大约多 370 MB。

## 已知的限制

- 蝶君还是骨架：没有人格、自主工作和专属记忆（v0.8）；技能里的脚本不能在沙箱里跑；outbox 里的 PDF、HTML 只能用默认程序打开。
- 真实模型下「交给蝶君 → 沙箱里用 Python 出图 → 保存到本机」整条流程、子 Agent、拖图片都需要在真实应用里试。
- 沙箱只支持 Windows（WSL 2）。
