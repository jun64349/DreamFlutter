# v0.2 阶段 4：多模态输入输出与 Showcard 卡片

完成：2026-10-31。用户要求卡片「完整接入」，并且**按官方规范构建**，不按调研报告自行发挥。

## 依据

- 规范：[liliMozi/showcard](https://github.com/liliMozi/showcard) `spec/1.0.md`（全文已逐条核对），参考实现 `reference/src/`，一致性套件 `conformance/`。对照的提交是 `d1e6daaf`（2026-10-09）。
- 调研报告 [research/showcard.md](research/showcard.md) 是二手材料，有几处与官方不符（见文末），以官方为准。
- **OpenHanako 没有实现 Showcard 1.0**：它的 `show_card` 是更早的单向片段卡（没有 manifest、`card:request`、授权）。所以「官方」只有规范和参考实现。

## 官方原样拷贝的部分

`core/src/cards/showcard/`：`codes.js`、`runtime-source.js`（卡内 `window.card` 运行时，含声明糖、`userGesture`、独立打开时的 L0 降级）、`placeholder-source.js`（被拦资源的占位层）、`wrap.js`（服务时注入）。MIT，原样拷贝，**不要手改**；升级就整份重新拷贝（`VERSION` 记着提交号）。

## 宿主侧（我们写的，逐条对齐规范）

| 规范 | 做法 | 文件 |
|---|---|---|
| §1.1 服务时注入、作用域凭证 | 后台本地 HTTP（和 WebSocket 同一端口）按 `/cards/{卡片id}/t/{凭证}/index.html` 提供；外壳页 `/shell/{凭证}` 把卡片放进 `sandbox="allow-scripts"` 的 iframe 并在 WebView2 与卡片之间转发消息 | `cards.ts`、`shell.ts`、`server.ts` |
| §1.4/1.5 manifest、状态快照 | 取文档里第一块；`display.preferredWidthPx` 按 240–1200 取整 | `document.ts` |
| §1.7 尺寸制式 | 对话里 `data-card-sizing="content"`，放大窗口 `viewport`；高度按 body 内容测量（不用根元素 scrollHeight，避免只涨不缩） | `document.ts` |
| §2.3–2.6 插座与信封 | 照参考 `host.js` 的分发器：`state.set(对象)` 整体替换、`state.get(key)` 返回 `{key, value}`、64 KiB 预算拒写不截断、未知能力 `CAPABILITY_NOT_SUPPORTED`、高版本 `CONTRACT_UNSUPPORTED`、限频 `RATE_LIMITED` | `cards.ts` |
| §2.3 emit | 对话里的卡投递进它所在的会话（自定义消息，Agent 下一轮看到，界面显示一行）；带 `to` 投递到那个会话；书桌上的卡不带 `to` 时 `CARD_HOST_EMIT_NO_ROUTE` | `cards.ts` |
| §3.2/3.3/4.6/5.8 授权 | 按（种类, 主体）+ 卡片实体记忆：只这一次 / 本次会话内（后台重启前）/ 始终；可单项撤销；绑定声明纪元，声明一变全部失效；用户点头后、动手前再核对声明 | `cards.ts` |
| §3.2 持久化梯度 | Agent 做的卡属于对话（对话删除时一起删）；「收进书桌」= 把当刻状态拓印成**新的常驻实体**，授权从零，之后互不影响 | `cards.ts` |
| §3.2 历史诚实 | 从历史里翻出的卡要用户点过之后才能调用工具；本次窗口里新做的卡可以直接用 | `state/cards.dart` |
| §3.5/7.1/7.2 直连网络 | 按实例签发 CSP（资源只限本卡凭证前缀 + data/blob）；卡片直连被拦时窗口询问，同意后把主机加进这张卡的 CSP，下次载入生效 | `document.ts`、`card_view.dart` |
| §4.2–4.4 绑定 | 本宿主公开的工具：`time.now`、`fetch.request`、`web.read`、`fs.read/list/write`、`exec.run`、`notify.send`。参数形状在 manifest 里钉死（主机、文件夹、程序和参数、方法），运行时只能填槽位；读取类只走 https、拒绝内网和本机地址、剥离敏感请求头；未声明主机/文件夹/程序一律拒绝 | `bindings.ts` |
| §4.6 询问 | 授权框如实展示完整调用；先后拿到「读本地」和「向外发」时给危险组合提示；导入的卡单独标注 | `card_view.dart` |
| §5.4/7.3 校验 | 铸造和导入都校验（完整文档、自然语言标题、合法 JSON、秘密扫描五条 + 本宿主的 Anthropic/Google Key 形状，不回显） | `document.ts` |
| §5.5 热更新 | `show_card` 带 `card_id` = 同一实体热更新，状态延续；新卡不带 | `cards.ts` |
| §6.3/6.4/6.6/6.8 导出导入 | 无资产导出 `.card.html`，有资产导出 `.card.zip`（根即包根）；导出装备：烧入状态、内联当时的主题变量、标准垫层（官方运行时）和占位层；文件名由标题派生；导出前提示数据会一起带出；导入 = 新实体、信任归零、放在书桌 | `cards.ts`、`zip.ts` |
| §7.8 卡片自带防线 | Agent 铸的片段卡自带默认拒绝的 CSP meta 和占位层；宿主服务时去掉它，只用签发的那份 | `document.ts` |
| §5.1 读卡 | `read_card` 工具读状态（可带源代码） | `cards.ts` |

**明确的偏差（只有一处）**：参考运行时的应答时限是 5 秒（规范 §2.6 写作「参考时限 5 s」）。授权框要等人点，5 秒不够，所以宿主服务时把这个常量换成 180 秒；导出文件保持 5 秒。

- 套件说明里列为「需要人工核对」的几项，用真实窗口验证（`app/integration_test/cards_test.dart`，截图在 `app/build/card_shots/`）：
  - 卡片在 WebView2 里真实运行；隔离探测：取不到宿主页面、Cookie、本地存储、后台地址，不能导航，`origin` 为 `null`。
  - 授权框显示完整调用，「只这一次」不被记住。
  - `--dart-define=CARDS_MODEL=true` 时让 DeepSeek 真做一张番茄钟卡片 + Mermaid + 图表：卡片在对话里活着、高度贴合内容、截图被保存；图和图表画出来，可放大、复制、另存。

## 其余三项

- **看图转述**（`core/src/modules/vision.ts`）：只在当前模型的配置里**不支持图片**时才转述；能看图的模型照常直接收到图片。在每次请求前（Pi 的 `context` 事件）把图换成「图片 N，由 X 转述」的文字，按图片哈希缓存，会话文件里仍保留原图。设置「看图模型」（模型或模型组），不设时自动挑一个能看图的；一个都没有时提示用户。界面在问题下面标注「图片由 X 转述 ›」，点开看转述内容。极简模式也生效（这是传输层的修正）。
- **文件输入**（`core/src/modules/documents.ts`）：PDF（pdf.js）、Word、Excel、PowerPoint、各类文本（UTF-8/UTF-16/GB18030）拖进或粘贴到输入框就转成文字；超过 3 万字只给路径，Agent 用 `read_document` 分段读。
- **富内容输出**（`core/src/render/renderer.ts`、`app/lib/ui/rich_blocks.dart`）：回复里的 ```mermaid、```chart（Agent 给 JSON 数据，界面用 Chart.js 画）、```svg 在一个隐藏的 WebView 里画成图，跟随主题色；可以放大、复制图片、复制源代码、另存为 PNG/SVG。标准模式的系统提示里加了一段说明（`agent/host-text.ts`，dsh 原文不动）。Mermaid 11.12.0、Chart.js 4.4.7 放在 `core/assets/render/`。
- 图片生成（可选）：没做。

## 窗口里怎么用

- 对话里：卡片标题栏有「放大」和菜单（收进书桌、导出、权限、重新载入）。最新的一张和最后点过的一张是活的，其余显示上次的截图，点一下激活。
- 书桌多了「卡片」一栏：收藏的和导入的卡片，点开是活的；右上角「+」导入 `.card.html` / `.card.zip` / 卡片文件夹。

## 调研报告与官方不符的地方

- 「OpenHanako 已实现」——实际没有实现 1.0 协议。
- 宿主包装片段——参考实现已经取消片段模式，入口必须是完整文档（我们只在 Agent 铸卡时代它补全骨架，存下的包仍是完整文档）。
- `state.set(对象)` 是合并——官方是整体替换；`state.get(key)` 返回 `{key, value}`。
- 「钉住」= 同一张卡加标记——官方是拓印成新的常驻实体。
- 错误码、`capabilities` 的结构、5 秒时限、声明糖、`userGesture`、`data-card-sizing`、导出文件名、导出前提示——报告里没有或写错。
