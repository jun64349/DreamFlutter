## 账号、Key、额度和隐私

- **账号不是 API Key。** 上述普通 ChatGPT 首次教程用 ChatGPT 账号登录，没有要求先填第三方模型 Key；这只说明该教程，不证明所有账户、地区和功能均可用。[认证文档](https://learn.chatgpt.com/docs/auth)另称 Codex 本地工作可选择 ChatGPT 登录或 API Key，桌面应用本身有 API Key 登录选项，文档将其用于本地 Codex 工作并对应 API 组织和按量计费条件；**不要把 Codex 的另一种认证方式推成普通 ChatGPT 聊天的必经步骤或所有 ChatGPT 功能的通用认证方式**。
- **免费计划并非所有能力无限。** 官方 [Work 与 Codex 用量说明](https://learn.chatgpt.com/docs/pricing)列出不同计划与共享用量，称具体限额取决于任务和计划；它不直接规定普通 Chat 的完整免费额度。个人资格、地区、各功能的可用性与费用会变化；不要把“没有先填 Key”说成所有服务无限免费。
- **文件与数据。** 本地项目、上传文件或连接工具可能给产品提供用户选择的上下文；操作能力、训练与保留设置依模式、账户、组织和实际政策而异。不能把本项目要求只看公开网页当作该产品默认权限，也不能假称“不会发送或保留数据”。官方资料：[项目](https://learn.chatgpt.com/docs/projects)、[认证及数据处理](https://learn.chatgpt.com/docs/auth)、[企业 Work 数据处理说明](https://learn.chatgpt.com/docs/enterprise/chatgpt-work-overview)（特定企业环境，不能推广到所有账号）。
- **故障资料不是本轮操作。** [桌面应用故障说明](https://learn.chatgpt.com/docs/reference/troubleshooting)提供可能的排查方向，具体原因与界面必须单独核实；本轮没有更改浏览器、网络、系统安全或任何设置。
