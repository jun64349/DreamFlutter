# 加深：M01–M30 上手门槛与方案追踪

## 证据边界

本文只将 [02 门槛清单](02-门槛清单.md)与现有 Q5/Q6 研究文档相互对照。**M01–M30 全部是待验证的风险假设，不是用户逐条确认或本轮复现的问题。** 用户反馈的是整体上手门槛偏高，不能把某项假设的原因、严重度、发生频率或方案效果说成已经证实。

本轮没有启动 DreamFlutter 副本、取得 DreamFlutter 实机截图、测试模型或读取应用源码；Q1 因副本与既有全局数据/偏好的隔离未知而跳过启动。已有交互设计、HTML 原型、历史发布说明及外部资料能够支持对应材料的内容，不能自动证明候选包当前表现。所有界面和流程建议均为**建议，尚未据此修改设计**；托管版仍是方向，未据本轮文档证明已上线。四份 Q5 与 Q6 文档中提到某编号，不等于该项已有完整设计、通过验证或问题解决。

下表采用以下文档简称；“回应”一律是**文档描述或供选择的方案**，不是已交付功能：

- **F**：[首次启动方案](05-方案-首次启动.md)，尤其五步建议、模型连接解释与错误处理。
- **H**：[引导与提示方案](05-方案-引导与提示.md)，尤其首页示例、情境提示及原型图标清单。
- **G**：[使用说明与入门指南](05-方案-使用说明与入门指南.md)，尤其 G01–G20 截图占位及版本差异；这些占位均未取得实图。
- **I**：[内置与集成方案](05-方案-内置与集成.md)，尤其模型、沙箱、技能、连接的服务及工作区逐项建议。
- **V**：[两个版本方案](06-方案-两个版本.md)，尤其版本差异、路由、令牌与费用、隐私和测试矩阵；本文按主题关联 V，V 本身未逐项标注 M 编号。

## 复核结论与后续验收

- 从主题看，30 项均能关联至少一处方案或指南；这只是**追踪关系**。尤其 M04、M07、M09、M11、M15、M17、M24–M27 仍缺具体用户说明、设计决定或运行证据，不应标记“已解决”。G 的总览列出全部编号，不代表指南每一处已经写出可执行、已验证的操作。
- 上述方案没有在本文复核范围内被明确声称为本轮已实测或整体获批；引用时仍须保留每份文件的“设计/建议/未验证”条件，不截取将来时语句当成现状。例如，托管版的服务端限额与路由是候选要求，不是已运行服务；首页示例“先填入、不发送”是待定候选，不是实际点击行为。
- 需要用户和 Claude 判断的界面变更应逐项指出所涉 [已定型条目](../../design/settled-0.8.3.md)，不修改守护测试期望。后续先证明安全隔离，再分别验证真实版本、空值/失败、凭据与费用、目录权限、帮助和无障碍；模型请求、安装、登录、系统设置和数据改动仍需符合届时的明确授权与条件。
