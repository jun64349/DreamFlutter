# 加深：上手与托管方案的外部证据独立核验

核验时间：2026-11-14 02:11 +08:00。仅查看公开官方网页，未安装、登录、注册或提交表单；网页内容及服务可能变化。此表检验现有 Q3、Q5、Q6 的证据边界，不代表已在产品或实际中转站测试。

| 来源与现有用途 | 本次可直接核到的内容 | 不支持的推断 / 对方案的影响 |
|---|---|---|
| [New API：API 密钥](https://docs.newapi.ai/zh/docs/guide/feature-guide/user/token)，Q3/Q6 的托管限权 | 页面描述可设置密钥用量、有效期、模型和 IP 范围；所述创建界面默认无限配额开启、过期时间空、模型未选，以及允许查询用户额度开启。密钥自身额度与账户额度是两个层次。 | 这是公开文档所述界面和能力，不能证明未知版本或站点的默认、权限、并发原子性或硬费用上限；也不能因每人一把密钥就断言账户余额不会暴露、密钥不会共享，或发生泄露后即时阻止已有流。上线前逐项核实并实测。 |
| [New API：安全与限制](https://docs.newapi.ai/zh/docs/guide/feature-guide/system-settings/settings-security)，Q6 的限速 | 网页读取工具返回不可访问；之后普通只读 HTTP 请求取得正文：模型请求按用户计数、同用户跨密钥共享，部分路由按 IP，搜索按用户，Redis 影响多节点计数。 | 这是上游文档而非部署验收，实例版本、配置和并发行为仍须验证；不能推断每个令牌独立限速。 |
| [W3C：WCAG 2.2 对悬停或焦点内容的说明](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus)，Q5 提示及键盘体验 | 文档针对因悬停或键盘焦点而出现又隐藏的额外内容，解释可关闭、可悬停、持续可见条件；可关闭有例外，不修改的用户代理呈现也有例外，原生 HTML title 是所列例子。 | 不能把所有提示一律说成必须响应 Esc，亦不能据此声称仅有鼠标悬停即满足键盘可用性；Flutter Windows 的具体呈现、焦点和屏幕阅读器行为仍须实际验证。说明页本身是理解材料，应结合其所引正式成功准则及适用范围评估。 |

| [Jan：桌面 Quickstart](https://docs.jan.ai/desktop/quickstart)，Q3 对本地模型起步的参考 | 官方称首启会自动下载默认基础模型，完成后可开始聊天；本地模型可在本机离线运行，云模型另需服务商 Key。页面也介绍内置联网搜索与抓取。 | 不可把“本地模型离线”推广为所有联网工具、云模型或整套使用流程均离线；首次模型获取仍需下载，设备适配、失败恢复和实际空状态未测试。指南里的示例问题不能证明出现在应用空态。 |
