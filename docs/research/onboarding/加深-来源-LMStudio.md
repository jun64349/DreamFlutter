## 本地、云端、账号、Key 与费用

- [离线运行说明](https://lmstudio.ai/docs/app/offline)称模型已取得后，本地模型聊天可离线；Discover 搜索、新模型下载、获取模型详情或运行时、更新检查则涉及联网。是否启用联网插件、远程服务器或其他扩展是不同情境，不能一概声称应用所有操作离线。
- 主桌面本地聊天指南未要求提供云服务 API key 或登录账号，但未对每个发行版、模型来源和许可作穷尽声明；“指南没有列”不等于已实测证明注册在所有情况下绝不出现。
- [Bionic 的模型选择文档](https://lmstudio.ai/docs/bionic/models)另列云端、设备本地及 LM Link 远端三个分支，并称其云端需联网、登录 LM Studio 账号、设置计费和可用额度。本研究不将这个 Bionic 云流程等同本地聊天流程，也不推断任何地区、价格或额度配置。
- 本地模型不使用 Bionic 文档所述云推理额度，仍需设备、电力与磁盘资源；获取模型、更新或使用外部功能可能需要网络，已具备模型和运行时后的本地推理不要求持续联网；各模型权重和许可、不同服务的付费规则需要分别查证。厂商关于离线和数据处理的表述未经我们独立网络审计。

## 版本和文档差异

- [桌面快速入门](https://lmstudio.ai/docs/app/basics)以 Discover → Chat → 模型加载器描述；[Bionic 文档](https://lmstudio.ai/docs/bionic/models/download-local-models)以 Settings → Local Models → Explore / Library 以及 session 选择器描述。这是不同文档产品路线，不能拼成同一套确定步骤，也不能据此推断已有桌面版本都拥有 Bionic 的按钮。
- 系统要求页、下载页及网页内容可能更新，本文记录的是检索时的公开资料；未确认运行中的特定应用版本。文档未明确的默认模型、首启步骤数、账户提示及错误恢复均保留未知。

## 对 DreamFlutter 的启发与边界

适用：把“资源已取得”“准备就绪”“可以开始对话”分阶段解释，并考虑可见进度、失败反馈和后续恢复；首次体验研究可比较现有文档中每步所需的先决条件。任何新增提示和状态都须受既定术语、位置及定型体验约束，先做可用性验证。

不适用：LM Studio 的本地权重下载、模型加载器、硬件推荐和运行时管理不是 DreamFlutter 的当前建设要求。[路线图第七节](../../roadmap.md)明确本地大语言模型暂不做，语音识别模型例外；不得把两者混同。任何会改变[已定型操作与体验](../../design/settled-0.8.3.md)的想法仅作待用户决定的设计提案。本研究没有实测 DreamFlutter。
