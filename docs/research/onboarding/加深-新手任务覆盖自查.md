# 新手任务与 M01–M30 覆盖自查

**性质：计划编写者自查，不是独立审阅。** 本文只核查 [新手任务验证计划](加深-新手任务验证计划.md)与[门槛清单](02-门槛清单.md)的设计映射；没有运行产品、招募或观察参与者，也没有验证任何门槛已经出现、得到解决或被真实任务覆盖。下表“有条件可观察”表示计划具备相应观察路径，仍依赖真实场景、参与者操作和结果记录；它不是测试通过。

## 逐项检查

| 编号 | 当前映射 | 自查：任务设计能观察到什么、缺什么 |
|---|---|---|
| M01 | T01 | 有条件可观察发行形态识别与首屏；安装版、便携版须各有真实版别说明和可用隔离环境。 |
| M02 | T03 | 有条件观察旧数据选择、顾虑与合成数据前后状态；F2、其他旧目录及旧偏好须分别建场景。 |
| M03 | T02 | 可观察位置和空间的理解；**缺少对搬迁含义与应用数据/工作区区别的明确探询**，实际迁移不得在未授权环境执行。 |
| M04 | T02 | 可观察填写与必填疑惑；称呼的外显范围及发送对象不一定由“会发生什么”自然引出，需任务后中性追问，答案未知时不能代产品作保证。 |
| M05 | T04 | 可听到对服务、模型、连接的解释；主持人提到这些词后只能评估解释，不能推断参与者会自发发现所有概念。 |
| M06 | T04 | 假服务只能观察对密钥及费用的理解，**不包含真实服务注册、计费和复制流程**；不能据此判断该完整流程的真实门槛。可用标明模拟的合成流程研究概念，真实流程须另获授权。 |
| M07 | T05 | 有条件观察无模型时的继续或阻塞；能否跳过和之后恢复以适用版本实际状态为准。 |
| M08 | T04、T06 | 有条件观察费用与密钥去向理解；安全保存和真实传输不由人对着提示回答来证明。 |
| M09 | T04、T06 | **目前没有明确要求比较对话、小任务、大任务三种用途或解释推荐依据**，即使参加两项也可能完全没机会表达；应增加受控的任务分配情景及事后中性追问。 |
| M10 | T05、T14 | 可观察可控失败与理解；每一种模拟错误须单独触发和记录，不代表真实服务。 |
| M11 | T06 | 只写“两类计费条件及可控切换”，**未保证设置订阅不可用后可能切到按量的具体前态与实际界面**；因此可能观察不到该门槛。须单列合成场景，实际版本不支持则记未测。 |
| M12 | T05、T14 | 有条件观察断连、额度不足与求助；模拟失败和实际支持渠道不可互相冒充。 |
| M13 | T07 | 可观察是否理解选择或跳过工作区；若测试版没有跳过能力，不能推断参与者已体验该分支。 |
| M14 | T07、T11、T12 | 可观察界面上对文件范围的解释、合成任务和批准决定；实际隔离和拒绝生效需独立的技术证据。 |
| M15 | T05、T07、T08 | T07 能观察工作区跳过后的找回；**T08 未规定先选稍后、离开并重新找回蝶君准备入口**，蝶君设置的找回可能没有机会观察。应补两阶段并记所需前态。 |
| M16 | T08、T11 | 可观察是否找到准备路径和参与任务；T08 不保证问到为什么需要沙箱或与工作台的差别，需在任务后中性追问，真实隔离范围仍由技术测试决定。 |
| M17 | T08、T14 | 可观察受控等待/失败文案的理解；虚构进度不能证明真实准备耗时或真实后台并行能力。 |
| M18 | T03 | 有条件观察对找回/重新开始后果的理解；比较前后合成状态，不外推其他迁移路径。 |

| M20 | T09 | 只有参与者实际点到首页示例时才可观察，计划已写未触及时记未测；可在真实存在示例时安排合适的任务情景，不能预先暗示点击即发送或修改。 |
| M21 | T09、T10、T11 | 三项分别点名“工作台”或“蝶君”，**先替参与者选了空间**，不能观察其面对新任务时如何自主选择；应另设不点名空间的安全虚构情景，观察选择后再按条件运行。 |
| M22 | T11、T12 | 可观察合成权限请求的理解、选择与受控后果；蝶君本身的沙箱动作与工作台审批规则须按实际场景分开，不能假设两者相同。 |
| M23 | T13 | 有条件观察选定图标是否能被理解；个别图标不代表全产品覆盖。 |
| M24 | T13 | 有条件观察已实际采用的鼠标、键盘或读屏路径；每种输入/辅助技术须分别安排合适参与者与设备并单独报告，没测试不能写等价可用。 |
| M25 | T13、T14 | 当前只展示设置和记录理解，**没有合成、可撤销的实际设置改变**，无法验证生效时机及撤回是否真实有效。若有另获授权且可还原的应用设置，再加前后状态任务；否则只报告文案理解，运行效果未测。 |
| M26 | T14 | “一个例子需要外部服务”已经提前告知结论，也未明确设置需要技能的可比任务；**不能充分观察参与者自行区分技能与服务**。建议用两种不预告解决方案的虚构目标，并保持无真实连接。 |
| M27 | T13、T14 | 可观察实际存在的帮助是否找得到，或产品没有帮助入口；联系是否有效仍需后续另行验证。 |
| M28 | T07、T13 | 可观察当前工作区/帮助是否找得到；**没有提供旧、较新说明产生冲突的材料**，无法直接观察过期说明会否误导。可在不触及真实数据的情况下给明确标为测试用的两份合成说明，让参与者比较并解释选择；不能把假材料当真实发布文档。 |
| M29 | T01、T02 | 能记录所测步骤和停顿；未覆盖整条实际向导或多个对照组时不能估算总体负担或改版收益。 |
| M30 | T04、T06 | 能观察模拟资料中的服务方、费用和未知项理解；实际中转、日志、反馈和保留政策须以真实部署另行核查。 |

## 优先补齐和保持边界

1. 优先补 M09、M11、M15、M21、M25、M26、M28 的具体前态与动作：它们现在有编号关联，但任务指令或材料不能保证参与者有机会表现对应行为。M03、M04、M16 可在任务后加中性探询；M06 需明确只能测试模拟部分。
2. 所有补充均先核实产品真实设计及可用状态，不创造假 UI 冒充实机；安全隔离、可控模拟和必要授权先于操作。真实模型、付费、真实账号或外发仍需当时额外明确授权，未授权就不执行。
3. “找不到”“主动停止”和“前提不存在”分别记录，不算成功完成；未触及的分支不得据编号关联就标通过。一次受控任务也不能证实整类体验、技术安全或总体发生率。

## 后续补充

上述为编写者自查时的快照。之后验证计划新增 T15–T21 和中性追问，为 M09、M11、M15、M21、M25、M26、M28、M03、M04、M16 提供有条件的观察机会；均仍需技术前提，未执行，不保证覆盖或解决。M06 的真实注册、计费和领取仍不在本轮模拟内。
