## 本地、云端、账号与费用

- [快速指南](https://docs.jan.ai/desktop/quickstart)称本地模型是默认路线、运行在本机，可离线且不需 API key；离线指模型等必需资源已经就绪的本地推理，不是无需联网获取软件或模型，也不覆盖联网搜索、MCP 等外部工具。
- 相同指南的云端分支是设置 › Model Providers 选择服务商、提供其 API key 后选模型；服务商账户、计费和地区限制由各服务商决定，不能把本地路线无需 key 推广成云服务无需 key。
- 本地快速指南未把 Jan 账号注册写成该路线必要步骤，但本次没有测试首启，不能断言所有发行版、模型来源均无需任何账号；受限模型或来源可能另有许可与认证要求。
- [Jan 模型管理](https://docs.jan.ai/desktop/manage-models)提及某些 Hugging Face 模型需要访问令牌；这属于特定模型来源分支，不应说所有本地模型都需要令牌。模型自身许可、可用性和地区可能不同，本文未逐一核验。
- [官方入门文章](https://www.jan.ai/post/run-ai-models-locally)称本地回复无需订阅费用，但设备、电力和存储仍有成本；下载、更新或联网功能可能另有网络成本；本文不替其他云模型或模型许可证作费用承诺。

## 文档版本冲突与证据边界

- 当前快速指南写首启自动下载；[官方入门文章](https://www.jan.ai/post/run-ai-models-locally)以“选择适合硬件的模型”讲解，[模型管理页](https://docs.jan.ai/desktop/manage-models)以 Hub 手动下载为入口。它们可能代表不同版本或不同补充路径，页面未给出足够版本对应关系，不能拼成一个确定的首启向导。
- 官方入门文章对 Mac 同时保留支持 Intel 的旧表述和 2026 年 10 月更新提示：自 Jan v0.8.5 起内置引擎在 Intel Mac 上不能运行本地模型。应采用对应版本安装说明重新确认，不抹平冲突。
- 官方隐私表述是厂商对其产品的陈述，不代表我们做过流量审计。启用网页搜索、云服务和外部工具可能引入联网及不同处理方；不能将纯本地聊天的描述推广到所有功能。

## 对 DreamFlutter 的启发与边界

适用：在首次需要等待时说明正在准备什么、网络与存储前提，并提供明确可见的进度、失败原因及恢复路径；示例提示属于可研究的低门槛表达，位置和文案须按既定设计审查。将“本地/远端、是否要自备 key、是否产生费用”说清楚，但具体方案仍是待验证建议。

不适用：不把 Jan 的自动下载本地 LLM 或模型 Hub 当成 DreamFlutter 的近期需求。[路线图第七节](../../roadmap.md)明确本地大语言模型暂不做，语音识别模型例外；不要混同两者。也不能因为竞争产品而改变[已定型操作与体验](../../design/settled-behaviors.md)；如方案需要改变，先记为待用户决定。本文没有 DreamFlutter 实测。
