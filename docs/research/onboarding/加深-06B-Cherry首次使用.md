# 加深 06B：Cherry Studio 的三条首次使用路径

**资料检索：2026-11-14（Asia/Taipei）；证据类型：公开官方文档，非产品实测。** 本轮没有安装或启动 Cherry Studio、Ollama 或 LM Studio，没有下载模型、登录、注册、提交表单、填写密钥或发出模型请求。下述步骤是文档描述和跨页面整理，**不是实测向导屏数、实际点击次数或新手成功率**；未取得首启空态及引导跳过行为的证据，不编造截图。

入口以官方英文桌面文档为准；菜单实际名称、流程、可用模型和资格可能随版本、地区或账号变化。本文中“内置”要分清两件事：**CherryAI 是预配置的远端模型服务；设置里的本地模型是另一个功能**，不能把无需填 Key 等同于模型随软件在本地离线运行。

## 共同起点：安装和第一次对话

1. 官方安装说明按操作系统和处理器架构选择对应安装包，Windows 分常规和 ARM；能打开客户端是安装完成的文档判据。具体下载量、安装后空间和当次系统兼容性未在本轮测量。[安装教程](https://cherryai.com/docs/en/cherry-studio/installation/)
2. 桌面快速开始以「设置 → Model Provider」配置模型服务，回到 Chat，创建或打开助手、选择模型并发送消息；文档以收到回复作为基础配置成功的判断。它是通用教程，不证明三个分支都显示相同步骤或首启必须逐屏经过这些动作。[桌面快速开始](https://cherryai.com/docs/en/getting-started/quick-start/)
3. 本轮只研究文档，不代用户执行上述安装、连接或发送。屏幕空态、示例提示、首次向导页数、步骤是否可跳过和实际耗时：**未知**。

## 路径 A：CherryAI 预配置免费服务

| 文档中的环节 | 条件与证据边界 |
|---|---|
| 1. 打开设置中的模型服务，在预置列表找到 CherryAI。 | 官方明确称 CherryAI 是随应用预配置的免费模型服务，通常不需要额外配置。[CherryAI 官方说明](https://cherryai.com/docs/en/pre-basic/providers/cherryai/) 不是安装后实际画面证据。 |
| 2. 使用该服务所提供的模型开展聊天。 | 页面写不需要第三方注册或第三方 API Key，适用于体验聊天和基本文本任务；**不等于证明所有情形都无需 Cherry 自身账号、无需任何授权或没有地区限制**。文档未给明确资格、地区清单或首次点击全过程。 |
| 3. 查可用模型、额度和网络条件。 | 该页面在本次检索时写服务当前提供 Qwen3-8B，同时声明可用模型、免费额度和速率上限可能调整；**没有承诺永久免费、不限次数或任意地区可用**。服务器配置表明这不是本地离线模型。 |
| 4. 对话、费用与数据。 | CherryAI 文档将其称为免费服务；免费额度具体数值、超限后的界面及是否还需其他操作未写明。官方[隐私政策](https://cherryai.com/docs/en/about/privacypolicy/)将内置服务描述为经过中转并由上游处理；其关于中转内容不留存的表述是**服务方政策声明，非独立实测**，上游仍有自己的政策；具体处理地点、上游留存和训练条件本轮未核实。 |

**不能推断**：首次打开自动选中 CherryAI、必然零屏向导、能直接成功回复、某国/地区可访问、稳定免费或任意请求不产生其他服务费用。本轮没有调用服务。[CherryAI 官方说明](https://cherryai.com/docs/en/pre-basic/providers/cherryai/)

### CherryIN 是不同路径

[CherryIN 官方指南](https://cherryai.com/docs/en/pre-basic/providers/cherryin-1/)描述在 CherryIN 配置页取得 API Key、添加模型并聊天，也提到可以用 CherryIN 账号 OAuth 登录；不同令牌分组可能有不同倍率。它**不是 CherryAI 免费预配置服务的同义词**，不能把 CherryAI 的免第三方注册/Key 条件套到 CherryIN，也不能根据这份指南断言其无需账号、免费额度或具体价格。

## 路径 B：自行准备服务商和凭据

1. **选服务商。** 桌面[快速开始](https://cherryai.com/docs/en/getting-started/quick-start/)建议按地区、模型能力及隐私需求选择；[服务商概览](https://www.cherryai.com/docs/en/pre-basic/providers/)说明应用提供多个连接模板，模板不是为每个用户开通服务或提供免费额度。
2. **准备凭据或查明该供应商的其他身份方式。** [服务商速查](https://www.cherryai.com/docs/en/pre-basic/providers/quick-reference/)对常见服务商描述注册并获得 API Key；不同供应商的注册、实名、付款、使用地区、订阅是否包含 API 额度各不相同，不能把此通用 Key 流程推广成每家强制相同。某个具体服务是否要求账号和 Key，须以其官方说明和实际账号资格为准。
3. **在设置中配置。** [模型服务设置](https://cherryai.com/docs/en/pre-basic/settings/providers/)描述添加并保存 Key；内置供应商通常已有服务地址。自定义地址、协议及必要认证取决于供应商；填写错误不代表模型不可用。本轮没有查看或填写任何 Key。
4. **添加并启用。** 按[服务设置文档](https://cherryai.com/docs/en/pre-basic/settings/providers/)同步模型或手工添加模型 ID、加入列表，并启用服务商；连接检查是文档所列可选步骤。同步成功、已获得模型权限、启用成功和实际对话成功是不同状态，不能相互替代。
5. **聊天并理解费用。** 按[快速开始](https://cherryai.com/docs/en/getting-started/quick-start/)在助手中选择已添加模型并发送。官方[隐私与第三方服务说明](https://cherryai.com/docs/en/about/privacypolicy/)说第三方服务收费规则由各服务商决定，客户端显示的价格仅供参考；余额、免费额度、按量费用、计费与地区须在使用前向实际供应商核实。文档描述自配第三方模型通常由终端直接连接该供应商，仍需受该供应商的数据政策约束，不能推断所有扩展功能都不外传。

**条件和缺口：**没有对任何供应商登录、充值或测试；未验证同步失败、余额不足、区域拒绝、撤销 Key 或实际 UI 报错。通用教程中的动作数不是向导屏数；不能声称应用会在每一处给出新手说明。

## 路径 C：自备本地聊天模型服务（Ollama 示例）

1. **准备本地运行环境。** Cherry 的 [Ollama 集成指南](https://cherryai.com/docs/en/pre-basic/providers/ollama/)要求先安装并运行 Ollama，再取得本地聊天模型并保持服务运行；模型初次获取需要下载。这是教程内容，本轮**没有安装、运行或下载**。
2. **在 Cherry 添加 Ollama 服务。** 官方指南写在设置的模型服务列表中选择 Ollama；服务默认地址指向本机 `localhost:11434`，修改过端口时需与实际服务一致。它描述的默认本地服务不要求 API Key；若服务端自行启用身份保护，实际认证以配置为准。[Ollama 集成指南](https://cherryai.com/docs/en/pre-basic/providers/ollama/)
3. **添加已有模型并选择。** 同一指南描述启用该服务，在模型管理中添加已经下载的模型名称，再在聊天中选择它。一个文档把这称作添加自定义服务，但操作又是从已有列表选 Ollama；不同版本的具体按钮和入口先以实际界面为准，不能借此声称界面始终一致。
4. **理解机器及离线边界。** 官方指南要求足够 CPU、内存和可能的 GPU 资源，但未给适用于所有模型的统一最低规格、下载大小或可用速度；[Ollama 官方说明](https://ollama.com/download)区分本地与云端模型，性能受设备影响。完全本地聊天需实际选择本地模型、数据路径和工具，并完成模型准备；下载、更新、联网搜索、云工具或云模型是不同的数据路径。电力、存储和设备成本仍存在；不等于所有 Ollama 功能、所有用户数据或整个应用都自动离线。
5. **另一种官方记录的本地服务。** [LM Studio 接入文档](https://cherryai.com/docs/en/pre-basic/providers/lm-studio/)描述另装客户端、准备模型、启动本地服务器并在 Cherry 中获取模型列表；其不同端口和身份配置不能直接套用 Ollama，也未在本轮执行。

### 区分 Cherry 自身的“本地模型”设置

[Cherry 的 Local Models 页面](https://cherryai.com/docs/en/pre-basic/settings/local-models/)描述本地 Embedding 和 OCR，用于知识库检索与文字识别；页面列出约 **614 MB** 和 **140 MB** 的模型资料快照，具体安装环境可能不同，**这些不是本地聊天 LLM，也不是本次实测包增量**。官方[知识库说明](https://cherryai.com/docs/en/knowledge-base/create/)明确：本地 Embedding 只说明向量化在本机，解析、重排及聊天是否走云端仍由各自配置决定。不要把“内置可下载 OCR/Embedding”误记成“软件开箱预装离线聊天模型”。

## 三路对照与未核实项

| 问题 | CherryAI 预配置服务 | 自备云服务 | 自备 Ollama 本地聊天 |
|---|---|---|---|
| 第三方注册 / Key | 官方称无需第三方注册或第三方 Key；Cherry 自身账号及具体资格未知。 | 一般按供应商要求准备；是否注册、Key 或其他授权因服务而异。 | 本地默认服务文档称无需 Key；本机额外认证和云服务另论。 |
| 模型准备 | 官方所述预配置远端服务；可用模型随服务变化。 | 在服务商页同步或手工添加，权限和可用性另核。 | 需准备 Ollama 及本地聊天模型并保持服务；初次获取可能需联网。 |
| 费用 | 官方称免费，额度、速率和持续性会变。 | 按供应商实际计费；套餐、免费额和账单另核。 | 本地推理有硬件、电力和存储代价；云模型/额外联网服务另计。 |
| 设备与地区 | 服务端推理，客户端兼容、服务网络及地区可达性未实测。 | 客户端及服务网络、账号资格和地区另核。 | 资源依模型、精度及设备而变；下载渠道的地区可达性未测。 |
| 资料到哪里 | 政策描述经过内置服务中转及上游；声明与实际服务配置均须核验。 | 官方政策描述自配服务通常直连对应供应商，按其政策处理。 | 选定本地模型时本地推理；其他联网工具、云模型和备份须分别核验。 |

## 对 DreamFlutter 的待验证建议

**建议，尚未据此修改设计。** 这些是供 Claude 和用户评估的研究假设，不是 Cherry 的实测成功经验，也不是 DreamFlutter 已有功能：

1. 面向 M05–M08、M29，可以在已有首启设计中研究让可用的受控服务先于复杂渠道配置出现；同时在发出请求前说明实际提供方、费用承担、数据去向和额度限制。托管服务需要独立的服务端认证、预算和撤销，不能把长期总 Key 打包进客户端；具体风险见 [Q3 令牌资料](Q3-来源-令牌与风险.md)。
2. 面向 M10–M12，可以分别验证“未配置”“服务不可达”“额度用尽”“模型不可用”的可理解恢复路径；不能把官方文档里的步骤当作该项目中的成功率或障碍已证实。
3. 面向 M13–M17、M26，分清“应用附带”“预配置服务”“本机已准备好”“需要另行下载或安装”，按真实代价说明存储、网络和资源；不得把本地语音识别或 Embedding 误称为离线聊天能力。
4. 相关候选仍受 [已定型体验](../../design/settled-0.8.3.md) 第 4–5、8、10–11、16 条等约束；渠道、模型组或花费页若要改变，须由用户明确决定具体条目，Claude 负责界面设计。Q1 副本未启动，M 条目仍是[待验证假设](02-门槛清单.md)。
