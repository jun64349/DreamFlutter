# DreamFlutter 1.0 预览版（1.0.0-preview.1）

第一个 1.0 预览版，用来做朋友内测。功能已经齐全，内测完成、问题修好后再发 1.0 正式版。

## 下载与安装

- 下载 `DreamFlutter-Installer.exe`（约 260 MB），双击，选安装位置（默认 `%LOCALAPPDATA%\DreamFlutter`，不需要管理员权限）。装好约 660 MB。
- 第一次打开走设置向导：称呼、数据放哪儿、接上一个模型。没有密钥的话，按课本第 2 课去 DeepSeek 拿一个（充 10 元够用很久）。
- 左下角「入门 5 课」手把手带你学会：跟它说话、让它动手改文件、交给蝶君一件事。
- 之后的新版本在程序里自动更新。

## 和 0.13 相比新增

- **安装包从 1.07 GB 降到约 260 MB**，安装后从 2.76 GB 降到约 660 MB；后台启动约 0.3 秒。沙箱系统镜像（约 650 MB）和本机语音模型（约 230 MB）改成第一次用到时下载，校验后离线可用。
- **安装时可以选位置**：新的小安装器先选目录再安装；安装进度换成主题启动图。
- **蝶君沙箱一键建好**：没有 WSL 的电脑点「建立沙箱」后，程序弹管理员确认代装 WSL（先用系统自带方式，不行就用微软官方安装包并核对签名），提示重启，重启后自动打开并接着建。
- **入门 5 课**：在真界面里跟着做，压暗其余地方只亮要点的位置，做完自动进下一步；练习用的文件（一张故意弄乱的销售表等）程序准备好。
- **十课图文课本**：设置 › 关于与更新 › 使用说明，离线可看；仓库里 [docs/guide](../guide/README.md)。
- 首页示例换成零基础也能一点就用的（「帮我写一张请假条」等）。
- 模型服务商只列我们适配过的几家和自定义：DeepSeek、智谱 GLM 编程套餐、Kimi Code、MiniMax 编程套餐、Kimi 开放平台、OpenCode Go、OpenAI / Anthropic 兼容中转。
- 第一次打开的窗口和设置向导外观统一；卸载后不再留下 WSL 的空开始菜单文件夹。

## 修复

- 窄窗口、150% 缩放时首页输入框被挤出屏幕。
- 课本里的设置跳转、引导层在多页常驻时找错位置等若干问题。

## 验证

- 后台 1044 项、窗口 400 余项测试全部通过（含「已定型体验」守护测试）。
- 真实环境走通：全新安装、从旧版升级、失败回滚、程序内卸载保留数据、重装找回、彻底卸载（[安装升级验证回执](v0.13.1-安装升级验证回执.md)）；包体与启动前后对照见 [性能与包体回执](v0.13.2-性能与包体回执.md)。
- 用户实装验收：test.6（性能与包体）、test.8（一键沙箱、入门 5 课）。

## 已知限制

- 只支持 Windows 10/11 x64。
- 课本第 2 课 DeepSeek 网站上的几步只有文字说明（下一个预览版起不再显示「截图待补」占位）。
- 托管版（内置模型池，不用自己拿密钥）不在预览版里，内测期间再定。
- 沙箱镜像和语音模型从 GitHub / Hugging Face 镜像下载，网络不好时会慢；沙箱镜像下不动会回落到国内源现场构建。
