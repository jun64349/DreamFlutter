# v0.8.0-test.1 候选版（新界面）

日期：2026-11-10。这是 0.8「新界面」的候选包，交用户实测。版本号还没改成 0.8.0，没有打标签、没有推送。

## 这一版做了什么

- **新界面**：照交互设计第一版和体验版原型（`docs/design/prototype/interaction-v2.html`，用户 2026-11-10 定为 1.0 的前端形态）重做外壳和主要页面：
  - 侧栏：工作台 / 蝶君切换、新对话、等你处理（有数字）、搜索、按时间分组的对话（分叉和「问一下」缩进在原对话下）、已归档、回收站，底部记忆 / 技能 / 花费 / 设置。
  - 对话页：过程收成一行、批准卡、出错卡、回复下的操作、「它参考了哪些记忆」「已更新记忆 · 查看 · 撤销」、选中文字「引用 / 问一下」、对话「⋯」菜单、输入框（无痕、操作前问我、上下文圆环、模型、思考深度）、右栏「本次改动」和 Git 提交。
  - 等你处理（这一笔等你点头）、记忆（记下的事）、蝶君任务（四种状态、复述后自动开工、交付卡）、技能（蝶园）、设置（一方天地，七组 + 高级 + 搜索）、花费、首次启动向导。
  - 暖纸 / 暮色默认主题，手写体只用在问候、状态短句和页面标题；统一的动效，跟随系统「减少动画」。
- **后台配套**：统一的等你处理、对话 / 小任务 / 大任务 / 看图四个模型、四类系统通知、首次启动设置、统一搜索、对话里纠正记忆的回执、任务边界记录、模板并进技能、蝶君任务四种状态、回收站（随备份和搬迁走）、窗口用的 Git 接口。
- **修好的老问题**：关窗口时窗口进程在 Flutter 引擎里崩溃（0.7.0 就有，每次退出多拖 3～6 秒）。现在正常关闭约 0.2 秒、退出码 0（隔离数据目录测 3 次）。

- 后台：TypeScript 检查通过；全量 608 项通过。
- 窗口：`flutter analyze` 无问题；全量 257 项通过、1 项付费跳过。
