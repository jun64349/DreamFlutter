# v0.7.0 源码里程碑

2026-11-09。v0.7「技能与 MCP 体系、内置办公与数据处理、Git」的功能开发、联合验收、用户中期安装实测和实测后的收尾修复已完成，本节点发布源码提交与附注标签 `v0.7.0`。**正式安装包仍等 V1.0 再发布**：不创建 GitHub Release、不上传附件。

版本同步沿用前几版的做法：后台包、锁文件根包、Core 版本常量、Flutter 显示版本及协议测试期望均为 `0.7.0`；Flutter 构建号顺延为 `0.7.0+13`。功能源码已随 `v0.7.0-test.3` 快照推送（提交 `8ec47f2`～`468bfcd`），本版在其上加收尾修复、交互设计第一版和计划修订。

## 完成范围

1. **技能与 MCP（7.1–7.5）**：技能、任务模板、MCP 服务统一管理，有来源、信任、启用状态和使用次数；内置总路由、建技能、建 MCP 三个基础技能；社区导入的技能和服务默认不信任，确认后才加载；技能脚本在蝶君沙箱里试运行；MCP 真实连接测试，蝶君能用哪个服务按服务单独授权，信任绑定服务身份。路由测试 R1 总分 27/30。
2. **展示技能 `showcard-pro`（7.4）**：周报一类的交付做成排版好的卡片和文章，不写进系统提示词。
3. **内置办公与数据处理（7.6）**：便携 Python 和沙箱镜像都随包带 python-docx、openpyxl、python-pptx、pypdf、pandas、matplotlib（用户选的推荐档），配 Word / Excel / PPT / PDF / 数据分析内置技能；本机有 Microsoft Office 时可把 Office 文档转 PDF、旧格式转新格式，没有就明确说转不了。
4. **Git（7.7）**：后台 Git 服务和 Agent 工具（状态、差异、暂存提交、分支、历史、撤销，撤销前自动留恢复点）；读操作直接做，写操作按工作台审批；随包带官方 MinGit，没装 Git 的机器也能用。
5. **修复批（7.0）**：数据库目标位置在请求时就拒绝网络路径（UNC、`\\?\UNC`、网络映射盘），不再搬完才失败（F72-02）；沙箱搬迁失败时给出占用原因和清单（F72-01 仍是已知限制，见下）。
6. **收尾修复（7.8，用户 2026-11-09 中期实测）**：
   - **窗口只开一个**（V07-02）：同一个数据目录再次启动，会把已有窗口调到前面（包括缩在托盘时）然后退出；不同数据目录的安装可以同时开。
   - **迁移来的记忆直接生效**（V07-03）：v0.2 迁移来的记忆不再一律标「待复核」；已经迁移的，升级后第一次启动时自动改回生效，是记忆日志里一条可撤销的记录。
   - **启动和退出分段计时**（V07-07）：后台日志记下启动每一步、慢的模块、退出时各部分的耗时，为下一步提速定位。
   - **测试收尾清理**（V07-05）：后台测试的临时文件放在单独目录，跑完删除。
   - **安装位置**（V07-01）：安装包支持 `DreamFlutter-win-x64-Setup.exe --installto E:\DreamFlutter`，数据也放到那里；写进可更新包的使用说明。图形化选位置放进 0.8 的首次启动向导。
7. **交互设计第一版**（用户 2026-11-09 定稿）：[design/interaction-design.md](../design/interaction-design.md) 与可点击原型 [design/prototype/interaction-v1.html](../design/prototype/interaction-v1.html)，解决实测第 4、6 条（界面混乱、按钮不明所以）。
8. **计划修订**：前端重做提前到 0.8「新界面」，原 0.8–0.12 顺延为 0.9–0.13；开发规范新增界面以设计为准、派工对照设计、测试收尾清理、每版测启动退出耗时（[roadmap](../roadmap.md)、[dev-guide](../dev-guide.md)）。

## 已知限制

- **测试 `library-t73` 子 Agent 技能用量少记一次**（见上），待查。
- **沙箱（WSL）搬迁仍不可用**（F72-01）：搬迁前蝶君沙箱会被自动拉起，官方搬迁命令报文件占用；失败时退回原位置。
- 路由测试安全项严格 4/5；R2 未正式跑分。
- 本版收尾修复没有重新打候选包；用户手里的 `0.7.0-test.3` 不含 7.8 的修复。
- 窗口单实例「调到前面」的效果、启动退出的实际耗时，要等用户用新版本时确认。
- v0.6 列出的「延后到正式版前实测」各项（ChatGPT 订阅登录、DeepSeek 搜索真实调用、原生联合手测等）仍在 V1.0 前进行。
