# v0.12.0-test.2 候选版（照原型重做新加的部分）

日期：2026-11-13。用户试了 test.1，说和原型差距太大，甚至不如 0.8.3 顺眼，要求完全照原型做。没有提交、打标签和推送。

## 这次怎么做的

test.1 是拿测试样本对原型，数据不一样，很多差距没看出来。这次在真窗口里造了一份和原型一模一样的演示数据（同样的对话、日程、提问、目标、等你处理），按原型同样的尺寸截图，逐张并排比，浅色、深色都对过。对比测试是 `app/integration_test/v012_compare_test.dart`，截图在 `app\build\v012_compare\`。

## 改了什么

- **对话里**
  - 提问卡：三张选项卡片，默认项是浅色底加边框，右上角倒计时，下面是「自己回答…」和「跳过」；答完收成一行「✓ 你选了「…」」。
  - 「要不要把「…」设为目标？」：一行问题，右边「设为目标 / 不用」。
  - 蝶君主动来找你：「今天 09:12 · 蝶君来找你」居中放在那条消息上面。
  - 过程图片：放进带边框的卡片，下面一行文件名和命令。
  - 「建了日程「…」 看日程」：两边细线，前面有日历图标。
  - **计划条**：test.1 没有，这次加上了。贴在输入框上面，默认收起，写「计划 2/5 · 正在：…」和进度条，点开看每一步。内容是这段对话里蝶君自己列的待办。
- **右栏**
  - 目标卡：目标名、一句话目标、下一步、预算条、用时，按钮改成小号。
  - 后台任务：在跑的前面有绿点，命令用等宽字，用时写在下面，结束的变淡。
- **等你处理**
  - 分组标题前面有彩色图标：旗子、叉、勾。
  - 色带画在卡片框里面。
  - 规则卡照原型：「蝶君 · 起草了一条规则」「要不要让蝶君以后自动做这件事？」，规则原文放在浅色框里。
- **日程**
  - 月历照原型：今天是实心圆、过去的事变淡、没做成的标红。
  - 「每天」那一行也列出每周的事。
  - 右边清单宽度固定，「已提醒」是绿色。
  - 编辑区改成标签在左边，下面是改动记录和「撤销这次修改」。
  - 巡检那一行的「巡检记录 / 现在巡检」靠右。
- **录音中的输入框**：红色细波形、红色计时、红色圆形停止键，输入框外面一圈淡红光。
- **技能页**：蝶君写的技能改成卡片行，右边「蝶君写的」标签和「也给工作台用」按钮。
