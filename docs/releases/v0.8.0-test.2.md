# v0.8.0-test.2 候选版（外观对齐体验版）

日期：2026-11-10。在 [test.1](v0.8.0-test.1.md) 上，用户指出界面和体验版原型差距太大。Claude 把体验版（`docs/design/prototype/interaction-v2.html`）和真软件同尺寸放在一起逐页对照，test.1 只核对了「功能在不在」，没核对「长什么样」。这一版把外观改到和体验版一致。版本号仍未改，没有打标签和推送。

## 改了什么

- **窗口外框**：品牌（蝴蝶 + DreamFlutter 梦蝶）移到侧栏顶部，顶栏（48 高）只盖在右边页面上，放「工作台 / 工作区 / 对话名」；不再是一条横贯全窗口的标题条。
- **侧栏**：选中项用卡片底色；「等你处理」用收件箱图标、红色数字；底部图标换成体验版的样子（技能用笔、花费用钱币）；切到蝶君时列「蝶君的任务」（状态点 + 标题），不再列对话。
- **统一的页面零件**（体验版的同一套）：页面最宽 760 居中；分组标签用小号灰字；列表每行一张卡片；状态用彩色小标签（进行中 / 等你 / 已完成 / 没做成）；按钮分主按钮、普通、轻按钮三种。
- **等你处理**：每件事一张卡片，第一个按钮是主按钮，「去看看」是轻按钮。
- **蝶君首页**：问候用渐变手写体，文选放在带左边线的浅色块里，示例是圆角小卡；任务列表是卡片 + 彩色状态标签 + 进度条。
- **工作台首页**：同上的问候、文选块、示例。
- **输入框**：左边回形针、带字的「无痕」、操作前问我；右边上下文圆环、模型和思考深度两个圆角小标签、圆形发送键；去掉了单独的「插入技能」按钮（输入「/」照样调出）。
- **记忆页**：下划线式的「全部 / 最近」标签，分组标签改小号灰字，宽度 760。
- **花费页**：本月、今天两张卡片；按用途每行一张卡片带比例条；明细在下面。
- **设置**：1000 宽的窗口也保留左边的分组列表；名画主题改成一行名字（日间、夜间各一行），大的预览卡片收进「高级」。
- **退出时后台残留**：窗口在后台还没连上时就关掉（比如刚打开就关），后台会一直留着。现在退出时会等后台启动完一起关（最多 15 秒）；打开后 1.5 秒、3 秒就关各测一次，都没有残留。窗口出现后 0.2 秒内就关这种极端情况仍会留下后台，下次打开会自动接上它。
