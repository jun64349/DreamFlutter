# DreamFlutter 1.0 预览版（1.0.0-preview.2）

修复版：装在某个盘下一级文件夹（例如 `D:\DreamFlutter`）时，卸载会一直转圈、删不干净。已装 1.0.0-preview.1 的会在程序里自动更新到这一版。

## 下载与安装

- 下载 `DreamFlutter-Installer.exe`，双击，选安装位置（默认 `%LOCALAPPDATA%\DreamFlutter`，不需要管理员权限）。
- 第一次打开走设置向导：称呼、数据放哪儿、接上一个模型。没有密钥的话，按课本第 2 课去 DeepSeek 拿一个。
- 之后的新版本在程序里自动更新。

## 修复

- **卸载卡住、删不干净**：装在 `某盘:\某文件夹` 时，卸载前的清理要把数据和蝶君沙箱挪到盘符根目录再删，被安全检查拒绝，数据和沙箱留了下来；系统「应用」里卸载的进度条也一直转（其实是卸载工具弹了「卸载完成」窗口在后面等人点确定）。现在：
  - 装在盘符下一级时，待删的东西挪到安装目录里面再删；
  - 沙箱注销后多等 WSL 放开文件夹（最多约 13 秒）；
  - 卸载前的清理时间从 25 秒放宽到 50 秒，清理一开始就写日志。
- 课本第 2 课 DeepSeek 网站上的几步只留文字，不再显示「截图待补」。

**如果你已经用 1.0.0-preview.1 卸载过并卡住了**：把安装文件夹删掉即可；如果还留着蝶君沙箱，可在命令行运行 `wsl -l` 找到 `DreamFlutterSandbox-…`，再 `wsl --unregister <名字>`。

## 验证

- 卸载相关 14 项后台测试通过（新增两项：盘符下一级安装、WSL 晚放手；去掉修复会失败）。
- 实装：装到盘符下一级文件夹、放入数据并让沙箱运行，卸载 5–6 秒完成，沙箱注销、文件夹删净。

## 已知限制

- 只支持 Windows 10/11 x64。
- 系统「应用」里卸载结束时会弹「卸载完成」窗口，要点「确定」；窗口可能在别的窗口后面。
- 沙箱镜像和语音模型第一次用到时从 GitHub / Hugging Face 镜像下载，网络不好时会慢。
