## 最后这轮修改

- 两个首页都使用独立的 104 像素品牌蝴蝶，去掉圆圈，轻微呼吸；减少动效时静止。名言和出处与标题使用同一手写字体，居中排列。
- 首页输入区按用户最后反馈收至最大宽度 900，默认三行输入空间，含普通工具栏总高约 130。以底部窄边确定矩形文字区，两侧各留 20，顶部宽出的部分留白。模型、思考强度、上下文环、麦克风和发送键靠右，特别长的模型名在宽首页自动分出一行工具，保留完整名称。推荐区同步收窄，五条示例自然换行。
- 侧栏模式切换和搜索改为轻微主题底色，去掉多余分隔线。等你处理的全空状态统一为一个居中图标和一句状态，有事项时仍按原分组显示。
- 思考过程块使用主题背景和强调色混合；思考摘要、标题和正文统一斜体，实际命令及工具输出保持正常字形。
- **工作台右栏**的文件、Git、后台、上下文纵向排列，默认全部展开，可分别收起；筛选、文件预览返回与折叠状态保留，上下文环仍能展开并定位上下文。蝶君的目标、后台、交付、定时卡片没有被误改成这四区。
- 待批准请求仍显示操作卡；允许、拒绝或结束后，大卡片立即收入默认折叠的「已处理 N 项审批」，运行结束不会重新展开。用户可主动查看历史，保留原批准结果与会话隔离。

原型 CSS/JS 与上述用户新决定同步。旧 `v1-shots` 存档图不包含最后这批用户改动，不能用来否定后来明确提出的要求。

## 文物组件整套落地

用户明确要求完整实现后再结束，因此继续把试用版的局部图标扩展为整套共用组件。两族各 22 枚图标同步原型与 Flutter；宋瓷用圆肩、内收和浅刻弧线，欧洲嵌木用直边、45° 截角和短拼缝。这些规则已进入按钮、输入框、搜索、下拉、分段、开关、滑块、侧栏选中、卡片、审批、右栏、主题预览和浮层，覆盖悬停、按下、焦点、选中、禁用和停止。禁用主按钮采用柔和底色，避免与可执行按钮混淆。

十二套主题保留原名画配色及品牌蝴蝶，将器物线条并入原有背景母题；侧栏与卡片边角补局部浅刻纹，不铺到文字区域。日本折本、美国彩玻等仍使用各自来源，不一律套木纹。实际组件对照板使用生产控件和真实鼠标、键盘状态；16/20 像素为实际尺寸，32 像素仅用于放大看形状。具体覆盖及来源见 [文物组件实现表](../design/research/T-143-文物组件调研.md)。

文物、开源 Agent 和首次使用调研继续作为设计资料保存；尚未采纳的建议不算已实现功能，也不借本轮收尾扩展新的操作流程。
