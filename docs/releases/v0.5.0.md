## 已知限制与后续

- 普通只读允许读取侧快照素材和边界判断，禁止提取与写入；无痕、侧边按各自排除规则处理。
- 未保存提示及实时通知只保存在内存，重启不恢复历史通知。
- 摘要复活检测是可能漏报/误报的辅助告警；压缩前失效事实指令是主要保护，不自动重写历史摘要。
- 无精确标记/确认缓存且父文件已缺失的旧分叉，按usage时间`<=`会话header近似扣除继承费用，不改旧JSONL。
- 删除不能收回已发送给供应商的内容或旧备份；只清理当前受支持的数据和来源记录。未返回模型usage不能据此推算供应商最终账单。
- **U-3 / G-07**：物理磁盘满时暂停写入、一年以上历史由用户手动压缩，移至**0.6**，与roadmap **6.14**一并处理；本版未实现，不作为v0.5验收门槛。
