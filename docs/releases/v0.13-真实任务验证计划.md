## 一轮顺序

| 场景 | 实际操作 | 判定依据 |
|---|---|---|
| 渠道和模型 | 新增渠道，连接测试，普通输出及工具调用 | 可连接、流式输出、工具参数与结果、模型显示一致 |
| 工作台 | 读取专用样本，运行脚本，生成对比报告 | 核对真实文件内容、计算结果、命令退出码；不只看模型自述 |
| 审批 | 各做一次拒绝和允许写入/命令 | 拒绝无副作用，允许后执行，已处理审批收起 |
| 蝶君与沙箱 | 同类任务在隔离沙箱执行，交付结果；缺信息时提问 | 隔离路径、产物、等待/恢复、结果通知与问题通知，普通对话静默 |
| 记忆 | 保存约定，跨新会话读取，并检查工作区范围 | 实际记忆记录、来源、作用范围；不污染日常记忆 |
| 日程 | 短期提醒及短期任务，查看运行历史 | 到点执行、状态回执、系统通知不被工作台关闭开关误伤 |
| 技能 | 导入测试技能、核对信任、调用一次 | 产品入口可见，开关和信任有效，实际执行输出符合预期 |
| 模型组 | 建组、保存、选用，验证可用成员及失败后切换 | 显示实际模型/渠道，失败可解释，切换不丢原任务 |
| 运行结束 | 查看结果、后台进程、花费与错误日志 | 对照每项成功/失败/未验证；记录使用量和本轮实际花费 |
