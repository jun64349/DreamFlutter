# DreamFlutter macOS 内测版使用说明（Apple Silicon M1–M4）

## 适用电脑与版本

- 仅支持 **Apple Silicon（M1 / M2 / M3 / M4，arm64）** 的 Mac，系统要求 **macOS 12 Monterey 或更新版本**。
- 本内测版只走随想 GPT Pro 模型池，通过激活码启用；不检查更新。

## 安装与首次放行（重要）

内测包未购买苹果商业开发者签名，首次双击会提示「无法验证开发者」或「已损坏」。请按下面任一方式放行一次即可，之后正常打开：

### 方法一：在系统设置中放行（推荐）

1. 打开下载的 `.dmg`，把 **DreamFlutter** 拖进右侧的 **应用程序（Applications）** 文件夹。
2. 在「应用程序」里双击 **DreamFlutter**，弹出无法打开的提示后点击 **「好」** 或 **「取消」**。
3. 打开 **系统设置 → 隐私与安全性**，拉到下面「安全性」区域，看到「已阻止使用“DreamFlutter”，因为它来自身份不明的开发者」，点击 **「仍要打开」**，输入开机密码并确认。

### 方法二：一条终端命令放行

如果不方便找设置开关，打开「终端（Terminal）」，复制运行：

```bash
xattr -dr com.apple.quarantine /Applications/DreamFlutter.app
```

然后双击 `/Applications/DreamFlutter.app` 即可打开。

## 首次使用

1. **输入激活码**：打开后直接填入发给你的激活码，等待验证通过后点 **「进入」**。
2. **授权弹窗（仅按需）**：
   - 第一次使用麦克风语音输入时，系统会询问是否允许访问麦克风，点 **允许**。
   - 若系统提示读写桌面/文稿/下载等文件夹或允许本地网络通信，点 **允许**。
3. **本地语音模型按需下载**：安装包内未内置 228 MB 的本地语音识别模型，首次点击麦克风使用本地识别时会自动从国内镜像下载并缓存，下载完成后可离线使用。

## 蝶君沙箱（macOS 轻量隔离）

- macOS 内测版为 **「蝶君」** 启用 macOS 原生轻量目录隔离（`sandbox-exec`）：
  - **打开即用**：无需安装虚拟机、无需下载额外镜像。
  - **目录与敏感信息隔离**：蝶君只能读写自己的沙箱工作目录，无法读写你的钥匙串、浏览器密码、个人文档或其他私人目录，支持一键开启/关闭联网。
  - 提示：由于没有 Linux 虚拟机环境，蝶君沙箱内不使用 `apt`，但可直接调用内置 Python 3.13 与常用科学/办公库、ripgrep、fd、uv、Node.js 等工具。

## 数据目录与卸载

- **应用数据目录**：`~/Library/Application Support/DreamFlutter`
- **完全卸载**：菜单栏托盘图标（或窗口菜单）完全退出 DreamFlutter 后，将 `/Applications/DreamFlutter.app` 移到废纸篓；如需一并清理聊天记录和设置，同时删除 `~/Library/Application Support/DreamFlutter` 即可。
