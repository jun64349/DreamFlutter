# DreamFlutter 0.12.0

2026-11-16，Windows x64，build 15。用户已确认本轮最终界面与数字字形。最终检查和新便携包已完成，本轮按授权在 `v0.12-frontend` 本地提交；不推送、不打标签、不切分支。

## 本版完成的内容

- 整体界面按 T-143 原型重做，并按后续明确反馈修正：首页独立放大蝴蝶与轻呼吸、居中引文、最大宽 900 的窄底输入轮廓、默认三行高度、窄底以内的矩形文字区、靠右工具栏和五条推荐。
- 侧栏减轻白底与分割线，模式、工作区和会话选中融入主题；等你处理、日程、设置和其他页面统一。工作台右栏文件、Git、后台、上下文纵向排列，默认展开、可独立折叠。
- 审批卡片处理后默认收起，完成后不会再次铺开；思考、工具、运行、改文件和巡检等工作过程统一斜体。正式对话和文档阅读保持正常字形；上下文环按真实占用平滑变化。
- 全局中文使用内置霞鹜文楷、英文使用 Georgia，数字启用齐线字形。中文《庄子》与国外英文引文各 24 条，按文化分组随机，新会话换句、当前会话稳定。
- 六套亮色、六套暗色归为「名作主题集」。两组文物意象图标各 22 枚，配套按钮、输入、分段、开关、滑块、浮层与主题按压反馈；保留减动效设置和原操作入口。
- 下一主题集完成「星仪／构成／生长」研究与可交互样稿，尚未接入客户端，等待用户选择方向。

本轮没有修改 `core/`、设置键、读写路径与 ValueKey。应用版本为 0.12.0+15，后台自己的既有协议版本保持 0.8.3。
