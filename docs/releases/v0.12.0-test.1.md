# v0.12.0-test.1 候选版（0.9–0.11 后台的界面）

日期：2026-11-13。在 0.8.3 的界面上往上加，原来的操作和样子都没动。没有提交、打标签和推送。

## 新加了什么

**蝶君**
- 侧栏「等你处理」下面多了「日程」：月历（周一开头）、每天的事、点一天看清单，点一件事在下面改、现在做一次、删除、看改动记录和撤销。页面顶上是巡检：上次巡检的结果、下次时间、巡检记录、现在巡检。
- 对话右栏「这个对话」最上面：这段对话有目标时出现目标卡（暂停、停止、⋯ 里的紧急停止），下面是后台任务（眼睛看输出，方块停止）。
- 对话里：蝶君提问变成三张选项卡片，可以自己回答或跳过，答完收成一行；「要不要把「…」设为目标？」小卡片；蝶君主动来找你的消息上面有一行「今天 09:12 · 蝶君来找你」；建了日程会有一行「建了日程「…」 看日程」。
- 侧栏里有目标的对话前面有小圆点：绿色在推进，赭色暂停，红色卡住。

**等你处理**：按「待你决定 → 卡住了 → 等你验收」分组，左边一条色带；蝶君起草的规则可以「先观察 / 不要」。

**设置 › 蝶君**：性格（静、暖、利落、灵动）、主动性和每天预算、长期目标（可以加、改、删）、规则（关 / 观察 / 自动）、日程与巡检。

**语音输入**：工作台和蝶君的输入框，发送键左边多了麦克风。点一下开始说，底栏变成声波和计时，再点停止，字填进输入框（不会自动发出去）。默认在本机识别，声音不出这台电脑；设置 › 通用 › 语音输入可以换云端（要填 Key，这次没有实际联调云端）。

**技能页**：多了蝶君自己写的技能，可以「也给工作台用」。**记忆页**多了「蝶君自己记的」一组，写着从哪学来的。

**工作台**：顶栏多了「分支」，从当前位置分出一个新对话；工作区下拉里每个工作区写着有几个对话、几个在跑。

**首次启动**：选蝶君时多了一步选性格；要是电脑上有以前卸载时留下的数据，会问要不要找回来。

## 这次还不能用的（按钮是灰的，或者没出现）

- **目标的计划条**（输入框上面那条「计划 2/5」）：后台还没给出目标的步骤列表，这次不出现。
- **规则「改一改」**：后台还没有给出规则草稿的内容，暂时只能「先观察」或「不要」。
- **长期目标的开关**：后台没有暂停长期目标的接口，这次去掉了开关，要停就删掉。
- **卸载**：设置 › 数据与安全里能看到卸载的两个选项，但「卸载」按钮是灰的（便携包本来也不用卸载）。
- **新建日程选「蝶君去做」**：还要补「做什么、在哪个文件夹做」的填写，这次新建只能选「到点提醒我」。时间只认 `2026-11-20 09:00` 和 `每天 08:00、12:00` 这两种写法。
- **紧急停止**会停下**所有**目标（蝶君和工作台都停），停下后目标卡上有「解除」。

## 怎么试

便携包在 `dist\v012-candidate-test.1\DreamFlutter`，双击 `app\dreamflutter.exe`。想接着用 0.8.3-test.3 的渠道和对话：先关掉 test.3（托盘「退出并停止后台」），把它的 `data` 整个**复制**过来（别剪切，旧的留着当备份），再打开新版。第一次打开后台会把数据升级到新版本，这之后这份数据别再拿回 test.3 用。

建议按这个顺序看：
1. 蝶君 › 日程：点几天、点一件事改个名字、撤销；点「现在巡检」。
2. 设置 › 蝶君：换性格、主动性；加一个长期目标。
3. 跟蝶君说一件要做一阵子的事，看右栏有没有出现目标卡、侧栏对话前有没有圆点。
4. 输入框的麦克风：说一句话，看字有没有填进来。
5. 等你处理：看分组。
