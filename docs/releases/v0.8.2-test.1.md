# v0.8.2-test.1 候选版（按 0.8.1-test.2 实测报告修复）

日期：2026-11-11。按你 0.8.1-test.2 的实测报告 12 条修复和优化，逐条对照见 [v0.8.2 计划](../v0.8.2-plan.md)。版本号（pubspec 和 core）未改，包里显示 0.8.2-test.1；没有提交、打标签和推送。

## 改了什么（对应报告条目）

1. **渠道编辑页重做**：分卡片；底部固定「测试连接」「保存」；下拉框、平台、思考档位等所有选项改了都会存；离开时有改动没保存会问；测试失败说人话（例如 404 →「服务器找不到这个地址：检查接口地址和接口类型」），原始报错放在悬停里。模型一行一个，点开在对话框里改。渠道列表一行一个，右边「测试」。原来「高级」里的迁移信息挪到「开发者选项」。
2. **设置不再左右拉开**：内容限宽居中；每组一张卡片，行间细线；卡片标题前有主题色小蝴蝶。
3. **门槛**：新增「开发者选项」（原有连接配置、版本细节）；蝶君「开工前等你多久」随第 10 条取消。调研了 RikkaHub、HanaAgent 的设置页，结论在计划第三节。
4. **点历史对话不再跳到第一个**：列表按最后一条消息的时间排，打开不算；置顶照旧在最前。第一次启动会把旧对话重新整理一次顺序。
5. **工作区选择在左侧栏**：「工作台 / 蝶君」下面一行，Ctrl O 照旧。
6. **首页标题和引文对齐**：引文改成居中，出处在下一行。
7. **花费是图表了**：近 30 天柱状图，本月按用途、按模型两个环形图，右上角切「按金额 / 按次数」。
8. **记忆页**：顶部搜索和分组筛选（带数量），三组各一张卡片；「最近」按天一张卡片。
9. **已归档、回收站在「设置 › 归档/回收」**，侧栏底部不再有这两个按钮。
10. **蝶君就是对话**：发什么都直接给蝶君，它在回复里说明打算并直接开始；打招呼就正常回话。只有它真缺关键信息、用提问问你时，才进「等你处理」。交付卡不再重复一遍总结（总结就是最后那条回复），只留交付的文件、用时、花费。0.8.1 留下的那几个"等你"的旧开工计划还在，可以在任务里点「取消」。
11. **回复下面**：模型 · 输出速度 · 用时 · 几点，不显示花费；从历史打开的对话也有速度和用时。
12. **右栏**：改的和新建的文件合成「文件」一块，按类型不同颜色的图标，标「新建 / 改动」；点一下在右栏里打开（右栏会变宽、对话让开），改动的文件能切「改了什么 / 现在的内容」；右键有用默认程序打开、打开所在文件夹、另存为、复制路径。文件、上下文、常用操作都是卡片。

## 补丁：ChatGPT 登录（2026-11-11，同一个包）

「登录 ChatGPT」报 "Sign in with ChatGPT requires a device ID (UUID) for this installation"：Pi 新版的 ChatGPT 登录要一个本机安装 ID，Pi 自己的终端会给，我们的后台没给。现在登录时带上这个 ID（存在 Pi 的设置里，第一次登录时生成，以后一直用同一个，和 Pi 终端一致）。只换了包里的 `core\src\gateway\pi-migration.ts` 一个文件，不用重新解压。真实的 ChatGPT 账号登录我这边没法试，请你点一次「登录 ChatGPT」。
