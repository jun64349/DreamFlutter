# v0.5.0-dev.6 开发快照

本版保存 V0.5 第 1–6 步的实现和 2026-11-06 全仓审查修复，供继续第 7 步开发。它是预发布版本；第 7 步会话关系、第 8 步最简界面尚未完成，现有记忆兼容接口继续保留。用户已授权直接提交、打 tag、推送和打包，无须再交 Claude 复核。

## 修复

- 退出不再认领新记忆作业。退出打断的作业立即回队列，失败次数不增加；连续三次退出后仍可继续。
- 记忆关闭等待上限 15 秒。模型、模型目录或运行时初始化不响应取消时，停止等待并完成队列收尾；迟到的记忆工具调用和渠道账本写入不会访问关闭后的数据库。
- 保留已返回的模型用量。每次作业执行使用独立账目编号，避免中断重跑覆盖旧费用；未返回的用量无法推算服务商最终收费。
- 任务边界判断超时会取消请求，迟到判断不改变任务；任务替换使用事务。
- 会话列表刷新避免旧请求覆盖新结果。生产包排除开发缓存。
- 修正真实端到端验收中的渠道等待条件：应用内渠道不必有“来自 Pi 配置”标记；模板清理限制在测试临时目录。
- 打包脚本成功时显式返回 0，避免 Robocopy 的成功码 1 被误报为失败。

- Flutter 128 项通过，analyze 通过。

- 真实 DeepSeek 记忆验证：正常作业完成并入账；下一作业调用中退出耗时 8 ms，回到 queued、attempts=0，已有费用保留。
- 随包 Node、Python、rg、fd、uv 在去除开发工具的 PATH 下运行通过；随包后台认证连接、查询、停止及锁释放通过。

- 真实 DeepSeek 全流程端到端通过（约 2 分 28 秒），覆盖对话、停止、分叉、压缩、重连、搜索、渠道、仪表盘、记忆、模板、任务、计划与模型组等现有验收步骤。首次旧等待条件造成停滞、窗口被关闭的运行不算通过，修正后重跑通过。
- 最终包的 Flutter 窗口在隔离用户目录、无开发工具 PATH 下正常保持运行并自动启动随包后台；退出后后台正常关闭。
