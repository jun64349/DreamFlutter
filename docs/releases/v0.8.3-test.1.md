# v0.8.3-test.1 候选版（模型组回来）

日期：2026-11-11。在 0.8.2（已在本地提交）上恢复模型组，设计见 [design/model-groups.md](../design/model-groups.md)，进度记录见 [v0.8.3 计划](../v0.8.3-plan.md)。版本号（pubspec 和 core）没改，包里显示 0.8.3-test.1。0.8.3 的改动还没提交、没打标签、没推送。

## 改了什么

- **模型组**：一组按顺序排好的模型，在所有选模型的地方当一个模型用；前面的用不了，自动换下一个。
  - 你自己建，数量不限，名字、成员、顺序都自己定。
  - 在「设置 › 模型 › 模型组」，位于「用哪个模型」和「渠道」之间。
  - 每组一行，显示这一队和各成员的状态点；拖动整行可以排序，点进去可以编辑。
- **编辑页**和渠道编辑页一个样子：
  - 名字、这一队（可拖动排序，每行有状态）、高级（默认折叠）。
  - 底部「测试」（每个成员试一遍，结果标在各自那一行）和「保存」；有改动没保存就离开，会先问你。
  - 「添加」可以搜索，也可以一次勾好几个，比如把三个中转站的同一个模型一起加进来。
  - 高级里有两项：「订阅用完后，转到按量付费的渠道」（默认开）；「和上一个轮流用」，按份数分摊请求。
- **怎么换**：
  - 同一个渠道有几个 Key 时，先在渠道里换 Key，整个渠道都不行了才换下一个成员。
  - 订阅（ChatGPT 登录、编程套餐）先用，订阅都用不了才轮到按量付费。
  - 一个对话会一直用当前这个成员（这样能用上缓存）；前面的恢复后，新对话从第一个开始。
  - ChatGPT 额度用完能认出来，并按它给的恢复时间等着。
  - 带图的消息只交给能看图的成员。
  - 回复已经输出了一半就不换，免得重复，这时会出错误卡片。
  - 全都用不了时，错误卡片说清每个渠道为什么不行、什么时候恢复。
- **换了怎么知道**：
  - 对话里出一行，例如「ChatGPT · GPT-6.1 Sol 额度用完，16:52 恢复，换到 中转 A · GPT-6.1 Sol」；从订阅换到按量付费时这行用强调色。
  - 不再出“正在重试……service temporarily unavailable”那种提示。
  - 输入框的模型按钮悬停时显示现在用的是哪个渠道；回复下面那行写实际用的「渠道 · 模型」；右栏上下文块里也有一行。
- **常用模型**：
  - 模型多的渠道（ChatGPT 登录有四十多个）默认只在列表里放最新的几个。
  - 在渠道编辑页的「模型」卡片、ChatGPT 那一行点「常用模型」可以改，「恢复默认」可以改回去。
  - 各处模型列表的分组：模型组在最上面，下面按渠道分段；最后一项「更多模型…」可以搜到全部模型。
- **输入框里的模型名显示完整**：按钮上写「模型 · 渠道」，模型组写「组名 · 模型组」。以前空间够也会被截成「Fau…」，原因是宽度量错了、只分到一半的空位；现在按实际剩下的位置显示，只有窗口真的太窄才缩短。

## 验证

- **后台**：tsc 通过，全量测试结果见下面「测试结果」。新加 9 项，每项都确认过去掉对应的修复就会失败：
  - ChatGPT 额度识别和恢复时间；
  - 常用模型的默认规则；
  - 带图判断；
  - 直接选模型时换 Key；
  - 带图只交给能看图的成员；
  - 恢复后新对话从第一个开始；
  - 常用模型接口；
  - 删掉的组用默认模型；
  - ChatGPT 登录算订阅。
- **窗口**：`flutter analyze` 没有问题；全量 262 项通过，1 项要花钱的跳过。新加的测试：
  - 模型列表的分组、常用模型、「更多模型…」；
  - 对话里换渠道的那一行，以及后台自己的重试提示被藏起来；
  - 编辑页：一次添加两个、轮流用、高级、保存、离开提醒；
  - 常用模型的保存和恢复默认；
  - 输入框模型名不被截断。
  
  这些都确认过去掉修复会失败。
- **端到端**：新加流程 4.13，用真后台和两个假渠道（假密钥、不联网）：第一个渠道报 ChatGPT 额度用完，对话自动换到第二个，对话里出了那一行，第一个渠道在等恢复。全部流程的结果见下面「测试结果」。
- **截图**：在 1600 和 1000 宽、日夜两套下逐张看过，存在 `app\build\v083_shots`：模型组卡片、编辑页、添加对话框、常用模型、输入框和设置里的模型菜单、对话里换渠道的那一行。

## 仍然没验证的

- 真实的多渠道切换：要用你自己的 ChatGPT 登录和中转站密钥，等额度真用完才看得到。
- ChatGPT 真实的“额度用完”报错原文：现在按 Pi 给的文字识别，和 OpenAI 实际返回的不一样时可能认不出来。
- 其余同 0.8.2。

## 怎么试

1. 便携包在 `dist\v083-candidate-test.1\DreamFlutter`。想接着用以前的对话和设置：先关掉旧版，把旧包里的 `data` 整个复制过来，再双击 `app\dreamflutter.exe`。
2. 在「设置 › 模型 › 模型组」点「新建模型组」，起个名字，「添加」几个不同渠道的模型，排好顺序，保存。
3. 在输入框的模型按钮里选这个组，正常聊天。
4. 想看它自动换：把排第一的那个渠道临时停用，或者用一个余额不足的 Key。对话里会出一行「……换到 ……」。
