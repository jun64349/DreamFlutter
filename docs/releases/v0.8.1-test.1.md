# v0.8.1-test.1 候选版（补足体验、修 bug）

日期：2026-11-10。按用户实测 [0.8.0-test.2](v0.8.0-test.2.md) 的 21 条报告做，计划和逐条进度见 [v0.8.1 开发计划](../v0.8.1-plan.md)。版本号（pubspec 和 core）仍未改，包里显示 0.8.1-test.1；没有打标签和推送。

## 改了什么

**右栏（"这个对话"）**
- 从上到下：改了的文件 / 生成的文件 → Git → 上下文 → 常用操作。
- 上下文：已用 / 窗口（如"6.2 万 / 100 万"）、进度条、输入、输出、缓存命中、花费，"整理上下文"整理时转圈、完成后说整理到多少。输入框的圆环点开就是这里，原来居中的小弹窗删了。
- 常用操作：存成技能（点了显示"正在整理…"，完成后提示去"等你处理"看）、导出 Markdown（完成后给路径和"打开所在文件夹"）、归档、删除。
- 标题栏的"⋯"菜单去掉；"定时再做一次"改成在对话里跟 Agent 说，"这段对话不记忆"和"无痕"重复，去掉。导出只留 Markdown。

**对话区**
- 自动重试成功后，"这次没能完成"的卡片和"正在重试"不再留着。
- 错误卡先用人话说原因（如"模型太久没有回应，这次请求超时了"），下面是模型和重试次数、原始信息；三个按钮一样大。
- 输入框的"操作前问我"改成带字的小标签："先问我 / 直接做"。
- 工具调用之间模型说的话归进过程链，正文只留最后的回复。
- 删除对话先确认；带按钮的提示条 5 秒后自己消失。
- "去设置"直接打开对应分组（蝶君页 → 蝶君，出错卡 → 模型）。

**上下文百分比**：用了模型组、组里又有已删除渠道时，窗口被算成 12.8 万，聊几轮就显示六七成；现在已删除的渠道不参与计算。

**设置和花费**
- 主题只在通用里选一处（名画卡片）；设置里的下拉统一成一个从本行下方展开的小菜单。
- 关于、数据与安全、网络、软件源、安全审计去掉了大段说明；数字项改成右侧小输入框；"关闭窗口时"只在通用。
- 模型组不再出现在设置和模型列表里（已经选着的仍显示）。
- 花费页：卡片写次数和套餐用量；按用途一张表；明细紧凑、可按用途筛选；OpenCode Go 这类套餐的账目显示"套餐 $0.0042"，不再是"USD 0"。
