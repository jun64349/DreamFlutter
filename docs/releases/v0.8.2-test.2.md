# v0.8.2-test.2 候选版（ChatGPT 登录）

日期：2026-11-11。在 [0.8.2-test.1](v0.8.2-test.1.md) 上只改了 ChatGPT 登录，test.1 的全部改动都在。没有提交、打标签和推送。

## 改了什么

- **登录不再报"需要设备 ID"**：Pi 新版的 ChatGPT 登录要一个本机安装 ID。现在登录时带上（存在 Pi 的设置里，第一次登录生成，以后一直是同一个，和 Pi 终端一致）。
- **点「登录 ChatGPT」直接打开浏览器**：登录完浏览器会跳回本机，窗口里自动变成「已登录 ChatGPT」，点「完成」就好。窗口里不再显示长链接和 Pi 的英文步骤；浏览器没打开时有「重新打开登录页」「复制链接」。
- **只有登录完没有自动回来时**（例如别的程序占了 1455 端口、远程桌面），才需要展开「登录完没有自动回来？」，把浏览器地址栏里的地址粘贴进来。
- OpenAI 登录页上显示的应用名从 "Pi" 改为 "DreamFlutter"。

## 验证

- 后台：tsc 通过，ChatGPT 登录相关测试通过（新加：登录拿到的是格式正确、每次相同、写进 Pi 设置的设备 ID，应用名是 DreamFlutter；确认去掉修复会失败）。test.1 时全量 605 项通过。
- 窗口：`flutter analyze` 无问题；全量 257 项里除一项 Windows 临时文件夹被占用的清理问题（单独重跑通过）外全部通过；登录对话框的测试改成"自动打开浏览器、不显示链接、手动粘贴折叠起来"。

## 怎么试

便携包在 `dist\v082-candidate-test.2\DreamFlutter`。想接着用 test.1 里的对话和设置：先关掉 test.1，把 `dist\v082-candidate-test.1\DreamFlutter\data` 整个复制到 test.2 的同一位置，再双击 `app\dreamflutter.exe`。然后在「设置 › 模型 › 渠道」点「登录 ChatGPT」。
