## 已知限制

- **沙箱（WSL）搬迁暂不可用**：微软官方搬迁命令报"文件被占用"，占用者为 WSL 服务本身；即使先全部关闭 WSL，搬迁前蝶君沙箱又被自动拉起。失败时自动退回原位置，原沙箱照常可用。其他各类数据的搬迁不受影响。
- **数据库位置不支持网络路径**（如 `\\wsl.localhost\...`）：SQLite/WAL 在这类路径上无法加锁。搬过去会在启动验证时失败并退回原位置。
- **磁盘写满保护**只做了注入测试，没有在真实写满的磁盘上验证（需要管理员权限搭测试盘）。
- **MiniMax 用量接口**没有真实响应样本，新接口的字段显示"未知"。
- **测试版未签名**：没有购买正式代码签名证书；没有可信签名的正式包不会静默安装。正式证书在 V1.0 前由用户决定。
- 应用层的路径保护管不住已经批准的任意 shell 命令、外部程序或 MCP 服务内部行为；WSL 网络验证只覆盖本机 NAT 模式。
- 系统代理只支持手动设置的 HTTP(S) 代理，不解析 PAC/WPAD；Git 不提供镜像，SSH 方式不走代理。
- 跨电脑或跨 Windows 用户复制配置后，加密的密钥无法解密（DPAPI 限制）。
