# v0.8.1-test.2 候选版（去掉模型组）

日期：2026-11-10。在 [0.8.1-test.1](v0.8.1-test.1.md) 上，按用户的决定把模型组从 1.0 正式去掉（见 [全面核对](../REVIEW-2026-11-10.md) 第三节第 1 条）。test.1 的全部改动都在。版本号（pubspec 和 core）仍未改，包里显示 0.8.1-test.2；没有打标签和推送。

## 改了什么

- **模型组没有了**：设置里、模型选择列表里都不再有模型组，也不会再弹"已转到付费渠道"。
- **以前选了模型组的不受影响**：设置里的对话、小任务、大任务、看图模型和各用途模型，如果选的是模型组，启动时自动换成组里第一个渠道还在的模型；一个都不在就用默认模型。旧对话打开时同样处理，不会因为找不到模型组而打不开。
- **同渠道多个 Key**：一个 Key 余额不足或被拒，自动换同渠道另一个能用的 Key 重试（以前靠模型组实现，现在在渠道里直接做）。
