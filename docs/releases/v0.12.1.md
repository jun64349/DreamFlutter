# DreamFlutter 0.12.1

2026-11-16，Windows x64，build 16。用户要求把试用反馈修正本地提交并打包，记录进度和跨窗口交接；真实 API 验证仍按用户要求暂停。

## 本版内容

- 修复 150% 缩放后选中文字的右键菜单错位，保留复制、全选、引用和问一下。
- 数值设置提供常用档位、默认标记和自定义输入，保留原合法值与读写键。
- 默认棉纸、满强度纹理和装饰动效；明确保存的个人偏好不覆盖。
- 工作台系统通知默认关闭；蝶君仅问题和任务结果通知，普通聊天静默；保留总开关、前台查看抑制和日程提醒。
- 新模型组和渠道在设置原节展开，成功保存收起；草稿离开确认、保存失败保留、保存中不离开。
- 数据安全依次为备份、卸载、敏感路径和默认折叠的数据位置。
- 标准字体和 100% 界面缩放采用旧 +2 字号/110% 的舒适大小，既有保存值不叠加放大。

详细实现、测试失败后的修正和证据边界见 [试用反馈修正](v0.12-试用反馈修正.md)。截图入口为 `app/build/trial-feedback/index.html`，11 张原生图和 SHA-256 清单均保留。

## 验证与产物

本批功能验证已完成：受影响 Flutter 测试有通过回执，新增右键缩放 4/4、页内新增 6/6；18 个 Dart 文件分析零问题。Core 相关四文件当时 45/45，后续通知专项最终 5/5，类型检查通过。没有重跑全量，不把不同批次相加为总测试数。

Release 已重新构建成功，程序文件和产品版本均为 **0.12.1+16**。离线资产、沙箱镜像 SHA-256、文楷字体及 OFL、第三方许可清单核验通过；包根无用户 data，修改过的 Core 源码逐项哈希与包内一致。首次包体验证为 19,597 个文件、1,637,326,960 字节，最终含发布说明和 RELEASE.json 的精确数量以归档回执为准。

打包日志、核验脚本与结果统一保存 `app/build/trial-release/`。包内 `RELEASE.json` 记录本地代码提交。便携目录 `dist/v0.12.1/DreamFlutter/`，入口 `app/dreamflutter.exe`；压缩包 `dist/v0.12.1/DreamFlutter-0.12.1-windows-x64.zip`，校验文件在旁边。最终归档结果见本页末尾。

隔离启动复核：实际 Release 首次启动界面正常，使用界面关闭，窗口退出码 0；新包路径下无残留进程。回执 `smoke-002/result.json` 与 `residual-check.json`。首次脚本在后台端口就绪便发起关闭，触发“还有任务，是否退出”的确认框，脚本未处理确认而超时；当时随后只读查询 core.activity/app.exitState 已无任务，computer-use 查到确认框并正常确认退出。失败、恢复记录保存在 smoke-001，未改产品代码，未强杀。第一次屏幕采样被 Codex 遮挡，不能用作产品视觉证据；复核通过 computer-use 查看真实首次启动窗口，不把窗口可见或端口就绪当作完整初始化完成。

本机截图和构建日志位于忽略的 app/build 下，不随 Git 提交；已提交文档保留结果、命令范围、路径和未验证边界。换同一电脑窗口可直接使用这些证据，清理 build 前先转存。

只做本地提交，不推送、不打标签、不切分支。旧 `dist/v0.12.0/` 与用户数据保留。本包是免安装版，完整安装与升级验收未在本轮开展。
