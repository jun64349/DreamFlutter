# v0.12.0-test.5 候选版（接上补齐的后台接口）

日期：2026-11-13。在 [0.12.0-test.4](v0.12.0-test.4.md) 上，把 T-140 补齐的六个后台接口接到界面上，原型也先补了对应的几处。没有提交、打标签和推送。

## 原型先改的（`docs/design/prototype/v0.12-additions.html`）

- 日程：「新建」在右边清单下面打开空表单；「方式」选「蝶君去做」时多一栏「要做的事」；时间一栏写中文，空着时显示「明天下午3点」作为例子。
- 等你处理：「改一改」在卡片里原地改「名称」和「要做的事」，按钮换成「保存 / 取消」，保存后回到卡片再选「先观察 / 不要」。
- 设置 › 蝶君 › 长期目标：去掉「已写 N 篇笔记」（后台算不准篇数，T-140 Q-01），只写「空闲时自己学 · 上次 …」或「暂停了」。

## 界面改了什么

- **日程**
  - 时间交给后台 `schedules.parseTime` 解析，「明天下午3点」「每天8点、12点」「每周一、三、五9点」「工作日9点半」「每月1号10点」「每2小时」都能写。看不懂或已经过了的，在表单下面说一句，不保存。
  - 打开已有的日程，时间显示成同一套写法（`timeText`），比如「11月14日 14:00」。
  - 「蝶君去做」现在可以新建：要写「要做的事」，工作目录用蝶君自己的。
  - 点「新建」时清掉之前选中的那条，表单下面不再显示别的日程的修改记录。
- **等你处理**：规则草稿显示要做的事本身（不再显示后台拼的原始文字），「改一改」能用了（`autonomy.drafts.update`）。
- **设置 › 蝶君 › 长期目标**：每行有开关，关掉就是暂停（`selfwork.longGoals.setEnabled`）；副标题写上次学习的时间或「暂停了」；行间有细线，和原型一样。
- **设置 › 数据与安全 › 卸载**：「卸载」按钮能用了（`uninstall.start`）。选好「全部清干净 / 保留我的数据」后启动卸载，窗口自己关掉。便携包不是安装版，会提示「当前不是支持卸载的 Windows 安装版」，什么也不删。
- **目标**：对话的目标和侧栏的小圆点改用 `goals.bySession` 按对话查，老对话的目标不会再漏。

- **数据目录（重新打包时修的）**：用户第一次试纯净包，打开的却是 0.3.1 以前的旧数据 `%APPDATA%\DreamFlutter`（11 月 3 日已搬走、留着「已搬到新位置.txt」，但里面还剩旧 `core.db`）。窗口选数据目录时没看这个标记。现在 `Installation.chooseRoot`：包自己的 `data` 有数据就用它；旧目录只在**没搬走过**时才用；否则进首次向导。`t88` 加了一项测试。

## 怎么试

便携包在 `dist\v012-candidate-test.5\DreamFlutter`，**纯净版**：用户 2026-11-13 要从零开始体验，所以不复制 test.4 的 `data`。先从托盘「退出」test.4，再双击 `app\dreamflutter.exe`，会从首次向导开始；蝶君沙箱也会按新的数据目录重新建一个，第一次慢一些。

包里没有任何用户数据（`app\data` 是 Flutter 自带的程序资源）。电脑上只有一处旧东西会被带进来：最早期版本留下的窗口偏好 `%APPDATA%\com.dreamflutter\dreamflutter\shared_preferences.json`（旧模型、旧工作区、审批关闭）。新数据目录还没有偏好时会导入它，所以要完全纯净，先把它改名放一边。

可以重点试：
1. 日程 › 新建，方式选「蝶君去做」，时间写「明天下午3点」，写上要做的事，保存。再试一个过去的时间。
2. 等你处理里有蝶君起草的规则时，点「改一改」。
3. 设置 › 蝶君 › 长期目标的开关。
4. 设置 › 数据与安全 › 卸载：便携包里只会提示不是安装版。真卸载在 0.13 的安装版上试。
