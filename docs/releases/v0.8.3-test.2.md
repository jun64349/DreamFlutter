# v0.8.3-test.2 候选版（回复开头的小蝴蝶）

日期：2026-11-11。在 [0.8.3-test.1](v0.8.3-test.1.md) 上只改了等回复时的蝴蝶，test.1 的全部改动都在。没有提交、打标签和推送。

## 改了什么

用户实测：回复一写完，左边那只大蝴蝶和「接住你的念头」就突然消失，正文跟着往上跳。原因有两个：这块在整个回复期间都压在正文上方，写完时一下子被拿掉；写着的回复和写完的回复在界面里是两套结构，所以没法过渡。

- **还没出字时**：照旧是大蝴蝶，加诗意短句和下面那行实际在做的事。
- **第一句话出来**：大的这块在约 0.25 秒内收起，同时一只小蝴蝶出现在这条回复开头的左边。
- **写的过程中**：小蝴蝶轻轻呼吸，透明度和大小缓慢起伏。
- **等你批准时和写完以后**：它停下来，静静留在回复开头，像聊天软件里朋友的头像。历史回复也都有这只小蝴蝶。
- 小蝴蝶放在对话左侧的留白里，正文从头到尾不会挪位置。系统里开了“减少动态效果”的话，它就不动。
- 工作台和蝶君用的是同一套对话界面，两边一起改了。
