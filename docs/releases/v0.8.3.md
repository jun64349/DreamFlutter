# v0.8.3

日期：2026-11-11。上一个正式版是 [v0.7.0](v0.7.0.md)。这一版是 0.8 线的第一个正式版，包含 0.8.0 新界面和用户实测后的三轮修复（0.8.1、0.8.2、0.8.3）。各轮详情见下面链接的候选版说明。只发源码，安装包到 V1.0 再出；便携包照旧用 `scripts\package-windows.ps1` 打。

## 0.8 线做了什么

- **新界面（0.8.0）**：按[交互设计](../design/interaction-design.md)和 [1.0 原型](../design/prototype/interaction-v2.html)重做外壳和全部页面。工作台和蝶君共用一套对话界面；有「等你处理」统一入口、名画主题和蝴蝶品牌。见 [0.8.0-test.1](v0.8.0-test.1.md)、[test.2](v0.8.0-test.2.md)。
- **补足体验（0.8.1）**：右栏补回改动、上下文和常用操作；错误卡片、过程链、设置页、花费页都收拾过。见 [0.8.1-test.1](v0.8.1-test.1.md)、[test.2](v0.8.1-test.2.md)。
- **按实测 12 条修复（0.8.2）**：
  - 蝶君改成直接对话；
  - 设置限宽、分卡片，加「开发者选项」「归档/回收」；
  - 渠道编辑页重做，有「测试连接」「保存」；
  - 对话列表按最后一条消息排序；
  - 工作区挪到侧栏；
  - 花费页有图表；记忆页可以搜索和分组；
  - 右栏「文件」合并，能在右栏预览，有右键菜单；
  - 回复下面显示速度和用时；
  - ChatGPT 登录自动打开浏览器。
  
  见 [0.8.2-test.1](v0.8.2-test.1.md)、[test.2](v0.8.2-test.2.md)。
- **模型组和实测修复（0.8.3）**：
  - **模型组回来**：用户自己建、数量不限。一组模型按顺序用，前面的用不了自动换下一个；先换 Key 再换渠道；订阅优先；ChatGPT 额度用完能认出来，并按它给的恢复时间等着；带图的消息只交给能看图的成员；换的时候对话里出一行说明。
  - **常用模型**：模型多的渠道只列最新的几个，其余用「更多模型…」搜。
  - **输入框**：模型名显示完整，写成「模型 · 渠道」。
  - **小蝴蝶**：出字后大蝴蝶收成回复开头的小蝴蝶，写的时候呼吸，写完留着。
  - **蝶君**：侧栏和工作台一样列对话，去掉悬在对话上的任务头和「没做成」标签。
  - **快速长输出跟得上**：回复按段落画，写完的段落不再重画；最后一行始终排好，滚动条不再乱跳。
  - **长输入折叠**：超过 10 行默认折叠，点「展开全文」展开。
  
  设计见 [model-groups.md](../design/model-groups.md)，过程见 [v0.8.3 计划](../v0.8.3-plan.md)，候选版见 [test.1](v0.8.3-test.1.md)、[test.2](v0.8.3-test.2.md)、[test.3](v0.8.3-test.3.md)。

## 验证

- **后台**：tsc 通过，全量 619 项通过。
- **便携包**：`dist\v0.8.3\DreamFlutter`，约 1.13 GB，build-info 写的是 0.8.3。
- **窗口**：`flutter analyze` 没有问题，全量 267 项通过，1 项要花钱的跳过。
- **端到端**：10 个设计流程在真窗口、真后台下全部通过，其中 4.13 是“模型组遇到额度用完自动换渠道”。
- **新加测试**：每个都确认过去掉对应的修复会失败。
- **长输出**：在测试模式下模拟一万字的流式输出，每次刷新的耗时不再随字数变长；一万字时慢的那几次从 116–126ms（最慢 451ms）降到 60–75ms。正式包比测试模式快好几倍。
- **截图**：改过的页面都在 1600 和 1000 宽、日夜两套下看过（`app\build\v083_shots`、`t87_shots`、`t86_shots`）。

## 已知限制和还没验证的

- 真实的多渠道切换：要用户自己的 ChatGPT 登录和中转站密钥。
- 真实 ChatGPT 登录和真实 400 token/秒长输出：用户手上的模型才能试。
- 安装器还没有，仍是便携包（V1.0 再出）。
- 模型组的轮流分摊按份数随机分，不保证严格轮换。
- 每个蝶君对话的旧状态（0.8.1 的开工计划）只在打开那段对话时出现在「等你处理」里。
