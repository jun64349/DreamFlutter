2026-11-16，接本地提交 `4b6726f` 后的用户反馈。只改前端、原型与对应测试，沿用不打新包、不推送、不切分支的安排。

## 实际改动

1. 两首页按画作来源显示引文。暖纸、暮色、蛱蝶、墨夜、石青使用《庄子·逍遥游》；其余国外主题显示莎士比亚《暴风雨》的英文斜体原文、中文自译及出处。不将文学引文冒称画作题词。名言区最小高度 100，原文 18、翻译 16、出处 14，保持居中。
2. 正式用户输入和助手回复使用内置霞鹜文楷 Regular。整个执行过程统一斜体，涵盖折叠摘要、思考、读取、命令、输出、改文件、diff、过程叙述、子 Agent 工具内容及巡检记录。正式文档阅读保持正常字形，代码保持等宽；正式回复的引用块不再强制斜体，显式 Markdown 强调仍保留。按消息结构区分，不猜文字含义，也不将所有蝶君正式交流改成斜体。
3. 上下文环随真实比例平滑填充，进度头轻微高亮；空用量不显示假进度，未知用量不旋转。进度按原 60%／85% 阈值换警示色，减少动效时即时更新，点击仍打开上下文。模式、工作区、选中对话与导航共享主题渐变浅染和边角纹样；浅色消除白块，深色略微提亮与背景分离。

内置字体来自 [霞鹜文楷官方仓库](https://github.com/lxgw/LxgwWenKai)，约 25.9 MB，仅一份 Regular；SIL OFL 文件随 Flutter 资产保存，应用许可注册包含该字体。原文核对：[《庄子·逍遥游》](https://zh.wikisource.org/zh-hans/庄子/逍遥游)、[Folger《暴风雨》](https://www.folger.edu/explore/shakespeares-works/the-tempest/read/)。中文译句为本项目自译。
