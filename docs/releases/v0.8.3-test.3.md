# v0.8.3-test.3 候选版（蝶君的侧栏和页面理顺）

日期：2026-11-11。在 [0.8.3-test.2](v0.8.3-test.2.md) 上只改了蝶君，test.1 和 test.2 的改动都在。没有提交、打标签和推送。

## 用户实测的问题

1. 在蝶君里进过记忆、花费、设置以后，点侧栏的历史和「新对话」都没反应。
2. 对话上方悬着一块「你好 / 用户补充：？ / 没做成」，带返回箭头。
3. 侧栏写的是「蝶君的任务」，每条前面有一个状态点。

## 原因

0.8.2 定了“蝶君就是对话”，但侧栏和页面还是 0.8.1 的“任务”结构。

- 侧栏点一条任务，只是选中了那个任务，不会把页面切回蝶君。
- 「新对话」打开了新对话，但没有清掉选中的任务，所以旧任务的那块还压在上面。

## 改了什么

- **侧栏**：和工作台一样，列的是蝶君的对话，按时间排，可以搜索。在任何页面点一条都会回到蝶君并打开那段对话；「新对话」也一样。
- **对话页**：只有对话。上面不再有任务头、返回箭头和「进行中 / 已完成 / 没做成」标签。
- **空白页**：只有问候和几个例子，不再列任务卡片。
- **右栏**：改叫「这个对话」，和工作台一致，放这段对话交付的文件和定时任务，不显示状态标签。
- **要你处理的**：蝶君提问、要你批准、0.8.1 留下的旧开工计划，都在「等你处理」里。旧计划会在打开它那段对话时出现在那里。
- **删掉了不再用的**：旧计划的「可以，开始吧」倒计时按钮、任务状态文字、任务卡片。
