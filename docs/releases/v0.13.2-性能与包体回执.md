## 做了什么

- 语音模型（228 MB）改为第一次用本机语音时下载（hf-mirror → Hugging Face，续传、SHA-256 校验）；设置 › 语音显示进度。
- 沙箱镜像（653 MB）只随包带说明，第一次建沙箱从 `jun64349/DreamFlutter` 的预发布 `sandbox-image-ff0303e27cc8` 下载；失败退回国内镜像源现场构建。该发布不设为最新，不影响更新检查。
- 安装后删除 Velopack 留下的整包（我们的更新程序有自己的包缓存）。
- Python 库自带测试目录随打包裁掉（约 25 MB）。
- 新安装器（`tools/installer/`）：先选安装位置、显示所需和剩余空间，再调用 Velopack Setup `--installto`；Velopack 安装进度换成主题启动图。
- 用户试装时要求的：服务商清单去掉 Pi 那串（原属第 4 步，提前做）；首屏改用与向导相同的外壳（标题栏、缩放、字号），窗口标题改为 DreamFlutter。
- G：注销沙箱后删开始菜单里同名空文件夹。H：删掉 v0.3.1 旧数据迁移。
