# v0.12.0-test.4 候选版（沙箱只留一个联网开关）

日期：2026-11-13。在 [0.12.0-test.3](v0.12.0-test.3.md) 上只改了设置 › 蝶君 › 沙箱。没有提交、打标签和推送。

## 改了什么

- 沙箱卡里原来有两个开关：「允许联网」和「允许沙箱联网」，管的是同一件事。用户定：只留「允许联网」。
- 两个开关做的事不完全一样：
  - 旧的「允许联网」只保存设置，要等沙箱下次启动才生效；
  - 「允许沙箱联网」调用 `sandbox.setOnline`，保存设置后，如果沙箱正在运行，会马上重启让它生效。
- 现在留下的「允许联网」改为调用 `sandbox.setOnline`，按下就生效，原来的功能没有丢。沙箱面板里那个开关和它下面的说明去掉了。

## 验证

- `flutter analyze` 没有问题，窗口全量 297 项通过，1 项要花钱的跳过。
- `sandbox_panel_test` 改为按「允许联网」，断言仍然调用 `sandbox.setOnline {online:false}`，并且「允许沙箱联网」已经不在了。这个测试在已定型清单第 4 条里只用来查导航键，这次没有改导航相关的期望。
