# DreamFlutter v0.3.2 发布说明

按用户 v0.3.1 实测（`2026-11-03 dfv0.3.1测试记录.md`）做的：数据集中存放、和别的 Agent 工具隔离，加几处修复。

## 所有数据放在软件目录下的 data 文件夹

- 会话、记忆、任务、模型配置、技能、模板、设置、窗口偏好、卡片、蝶君的沙箱、备份、缓存，全部在 `<软件目录>\data\` 里。软件放在哪个盘，数据就在哪个盘；整个文件夹拷走就带走了数据。
  - 安装包：`DreamFlutter\data\`（安装包的文件夹名不再带版本号，升级时覆盖程序文件，`data\` 不动）。
  - 开发版：仓库根目录的 `data\`（不进 git）。开发版和安装包因此各用一份数据。
- **和别的 Agent 工具隔离**：DreamFlutter 用自己的 Pi 文件夹 `data\pi\`，不再和 Pi 命令行共用 `%USERPROFILE%\.pi\agent`；也不再读好几个 Agent 工具共用的 `%USERPROFILE%\.agents\skills`。Pi 命令行自己的会话不会再出现在会话列表里。
- uv、pip 的下载缓存，命令的长输出，从浏览器拖进来的图片，都放在 `data\cache\`，可以随时删。
- **第一次启动时自动搬家**：把 v0.3.1 及以前放在 `%APPDATA%\DreamFlutter` 和 `%USERPROFILE%\.pi\agent` 里的数据复制进来（用 v0.3.1 的备份和恢复：先打包、再按新位置改好所有路径、后台重启时替换）。只搬 DreamFlutter 自己的会话；蝶君的沙箱一起搬；定时任务搬过来后先暂停。原来的文件夹不删，里面留一个「已搬到新位置.txt」，确认没问题后可以自己删。

## 修复

- 提示条：跟随主题（浅色主题下不再是深色条），字小一点，在窗口顶部居中，宽度随文字。
- 界面缩放不是 100% 时，会话的「⋯」菜单弹在别的地方。

## 已知的限制

- 数据位置暂时不能在设置里改（环境变量 `DREAMFLUTTER_DATA` 可以指定），改位置的界面在 0.6（6.8）。
- 实测里的其他意见排进了后面的版本，见 [roadmap.md](roadmap.md) 和 [HANDOFF.md](HANDOFF.md)。
