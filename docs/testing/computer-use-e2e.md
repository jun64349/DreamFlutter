## 一、背景（先读）

DreamFlutter 是一个个人 AI Agent 桌面应用。它分两部分：

- **窗口**（Flutter 写的，标题栏写着 dreamflutter）：你看到和操作的界面。
- **后台服务**（Node.js 写的）：常驻运行，管理对话会话、调用模型。关掉窗口后台也不会停，托盘里有它的图标。

界面风格叫「蛱蝶」：纸绢色背景、墨色文字、石绿色强调色，左上角有一只工笔蝴蝶。布局从左到右：

1. **导航栏**（最左窄条）：对话、书桌、任务、记忆、技能；底部是仪表盘、外观、设置。
2. **会话栏**：标题「对话」+ 工作区小标签（「工作区 · 名字」，点开切换），石绿色「新会话」按钮，旁边的眼睛按钮是临时对话，下面是搜索框和会话列表。
3. **对话区**：中间。最下面是输入框，输入框里有图片按钮、闪电按钮（Skills 与命令）、地图按钮（计划模式）、「标准 / 极简」模式切换、模型选择、思考级别、上下文小圆环、发送按钮。
4. **右栏**：「本次运行 / 书桌 / 分支」三个标签，可以收起。

模型用的是用户的 **DeepSeek**（会真实花钱，账户余额只有约 5 元人民币）。**所有提问都尽量短**，要求模型简短回答。整套测试预计花费不超过 1 元。

## 二、准备

### 2.1 启动应用

1. 先确认没有旧的后台服务：看任务栏右下角托盘（可能要点「^」展开隐藏图标）里有没有 DreamFlutter 图标；有的话右键 →「退出」。没有就跳过。
2. 打开资源管理器，进入 `E:\claude\DreamFlutter\app\build\windows\x64\runner\Release`，**双击 `dreamflutter.exe`**。窗口几秒内出现，后台服务会自动启动（第一次可能要 10～20 秒才能输入）。
3. 如果窗口里显示「找不到后台程序」或「找不到 Node.js」之类的提示，截图，记为阻塞，停止测试并在报告里说明。
4. 把窗口最大化，测试过程中**不要最小化窗口**。

### 2.2 测试用的工作区和命名规则

- 测试文件夹已经建好：`E:\df-e2e\ws-a`（里面有 `hello.txt`，内容是 `hello from dreamflutter`）和 `E:\df-e2e\ws-b`（空的）。开始前用资源管理器看一眼，确认它们存在。
- 测试中**所有你创建的东西**（渠道、模型组、写笺、模板、定时任务、记忆）名字都以 **「【测试】」** 开头，方便最后清理。
- 测试期间只在 `ws-a`、`ws-b` 两个工作区里操作。

### 2.3 不要做的事

- 不要修改「设置 › 模型与网关 › Pi 配置」里的任何内容，不要删除或修改「来自 Pi 配置」的渠道（那是用户真实的 DeepSeek）。
- 不要删除不是你创建的会话、记忆、技能、定时任务。
- 不要在任何地方输入用户真实的 API Key。测试用的无效 Key 统一用 `sk-invalid-dreamflutter-test`。
- 审批弹窗出现时，只允许在 `E:\df-e2e\` 里面的读写和命令；其他路径一律点「拒绝」。
- 如果应用卡住超过 3 分钟没有任何变化，记为「阻塞」，截图后继续下一条（必要时关掉窗口，再双击 `dreamflutter.exe` 重新打开）。

## 三、测试用例

每条用例的格式：**步骤** → **预期**。执行完立即截图（文件名用用例编号，例如 `A3.png`），如果实际表现和预期不一样，多截几张能说明问题的图。

### A. 启动与基础对话

- **A1 第一次打开**：观察新会话的空白页。→ 有大蝴蝶、「今天想做点什么？」、三张「试试看」卡片；如果出现「开始之前」卡片，点「知道了」后它消失且以后不再出现。
- **A2 切换到 ws-a**：点会话栏的「工作区 · …」标签 → 选择文件夹 → 选 `E:\df-e2e\ws-a`。→ 工作区标签变成 ws-a；如果弹出「信任这个工作区的配置吗？」，选「仅这次信任」之类的选项。**同时盯着整个窗口，看切换时有没有闪黑**（见 J3）。
- **A3 简单提问**：输入「读一下 hello.txt，只回复文件内容」并发送。→ 回复包含 `hello from dreamflutter`；回复上方有可折叠的「过程」块（如「读取 1 个文件」），回复下方一行数据（模型名、输入/输出 token、首字延迟、耗时、时间）。
- **A4 回复操作**：在 A3 的回复下面依次试「复制」「重新生成」。→ 复制后粘贴到记事本能看到 Markdown 原文；重新生成后出现版本切换「‹ 2/2 ›」，点「上一个版本」回到 1/2。
- **A5 编辑问题出版本**：把鼠标移到 A3 的问题气泡上，点编辑（或「修改」），改成「读一下 hello.txt，把内容翻译成中文，只回复译文」后发送。→ 问题下方出现「‹ 2/2 ›」，可以在两个版本之间切换，内容跟着变。
- **A6 从这里分叉**：在某条回复上点「从这里分叉」。→ 会话栏出现一个新会话，内容截止到分叉处。
- **A7 富文本显示**：提问「用一个两列的表格列出 3 种水果和颜色，再给一行 Python 代码打印 hello，再写一个公式 $E=mc^2$」。→ 表格正常、代码块有语言标签和复制按钮并且有高亮、公式正确渲染（不是原样的 `$E=mc^2$`）。
- **A8 运行中切走**：发一个稍长的任务（「写 200 字介绍月亮，不要用工具」），在它输出时立刻点「新会话」再提一个问题（「1+1=?」）。→ 第一个会话在后台继续（会话栏里有呼吸点），两个会话都能完成；回到第一个会话能看到完整回复。

### B. 附件与输入

- **B1 粘贴图片**：用截图工具截一小块纯红色区域（或画图里画一块红色），Ctrl+C 后在输入框 Ctrl+V，问「这张图主要是什么颜色？一个词回答」。→ 输入框里出现图片附件，回复是「红色」之类。
- **B2 拖文件**：从资源管理器把 `hello.txt` 拖进输入框，问「这个文件有几个单词？」。→ 附件以小标签形式出现，回复正确（3 个单词）。
- **B3 @ 书桌资料**：先做 E1 建一张写笺，再回来在输入框打 `@`。→ 弹出书桌写笺和资料，选中后成为附件标签。

### C. Agent 模式与审批

- **C1 标准 / 极简切换**：在新会话里，把输入框的「标准」切成「极简」。→ 当前空会话变成极简模式（或新开一个会话）；设置 › 对话 › Agent 模式里的默认值也跟着变。
- **C2 极简模式运行命令**：在极简模式问「用一条命令列出当前文件夹的文件」。→ 弹出「Agent 请求执行操作」审批框，显示 PowerShell 命令和用途说明；点「允许」后回复列出 hello.txt。
- **C3 计划模式**：切回「标准」，点输入框的地图按钮（计划模式），然后发「在工作区新建 plan.txt，内容是 hi」。→ 出现「请审阅 Agent 的计划」对话框；点「批准，开始执行」后，处理写文件的审批，最后 `E:\df-e2e\ws-a\plan.txt` 存在且内容是 hi。
- **C4 待办清单**：发「分三步：列文件、读 hello.txt、总结。先列待办再做」。→ 右栏「本次运行」里出现待办清单，随着执行打勾。
- **C5 拒绝审批**：发「删除 hello.txt」，审批弹出时点「拒绝」。→ 文件仍然存在，Agent 说明被拒绝了。

### D. 会话管理

- **D1 搜索**：在会话栏搜索框输入「hello」。→ 列出包含 hello 的会话和片段，点一条能打开对应会话。
- **D2 临时对话**：点「新会话」旁边的眼睛按钮开临时对话，问「1+2=?」。→ 有明显的「临时」标识；关掉/切走后它不出现在会话列表和搜索里。
- **D3 右栏分支标签**：打开做过 A5 的会话，点右栏「分支」。→ 显示问题树，A5 的两个版本挂在同一个位置，点另一个版本能切过去。
- **D4 关窗口后台继续**：发「写 300 字关于星空的文字，不要用工具」，开始输出后**直接关掉窗口**（点右上角 ×），等 20 秒，再双击 `dreamflutter.exe` 重新打开（或从托盘打开窗口）。→ 重新打开后，这个会话已经写完（或还在写，写完后完整），内容没丢。

### E. 书桌、任务、记忆、技能

- **E1 写笺**：导航栏「书桌」→ 新写笺，标题「【测试】周会纪要」，内容「周三开会，决定下周一上线新版首页」。→ 自动保存（离开再回来内容还在）。
- **E2 交给 Agent**：在这张写笺上点「交给 Agent」，选一个动作（如「总结」）。→ 跳到对话页开始执行，书桌任务栏里出现这个任务；完成后产物出现在书桌「产物」里。
- **E3 任务页**：导航栏「任务」。→ 「待处理」「全部任务」「定时任务」三块都能打开；E2 的任务在「全部任务」里。
- **E4 定时任务**：在定时任务里「新建定时任务」，名称「【测试】每日问候」，内容「只回复：早上好」，时间设成几分钟后（或每天 9 点）。保存后点「立即运行」。→ 运行记录里出现一次执行，结果是「早上好」。
- **E5 记忆**：新会话发「请记住：【测试】我喜欢用表格写周报。记住后只回复好的」。然后打开导航栏「记忆」。→ 记忆库里出现这条（可能要往下滚动）；页面上「待确认」区如果有候选，能「保存 / 忽略」。
- **E6 技能与模板**：在 A3 的会话里点右上角「…」→「存为模板」，名字「【测试】读文件」，保存。→ 「技能」页的任务模板里出现它。

### F. 模型网关（本阶段重点）

- **F1 渠道列表**：设置 → 左侧「模型与网关」。→ 「渠道」里能看到用户的 DeepSeek，标着「来自 Pi 配置」，状态「正常」；点它的「测试」，显示「可用 · xxx 毫秒」。
- **F2 添加一个坏渠道**：点「添加渠道」→ 平台选「DeepSeek」→ 名称改成「【测试】坏 Key」→ API Key 填 `sk-invalid-dreamflutter-test` → 模型里保留 deepseek-flash（如果是空的，手动添加 `deepseek-flash`）→ 保存。回到列表点它的「测试」。→ 测试失败，提示 Key 无效；渠道状态变成「Key 无效」（红点）。
- **F3 建模型组**：「模型组」里点「新建模型组」→ 名称「【测试】主力」→「＋ 添加模型」先加「【测试】坏 Key · deepseek-flash」，再加「DeepSeek · deepseek-flash」→ 保存。→ 列表显示「【测试】坏 Key · deepseek-flash → DeepSeek · deepseek-flash」。
- **F4 模型菜单分组**：新会话，点输入框的模型按钮。→ 菜单最上面是「模型组」标题和「【测试】主力」，下面按渠道名分组列出模型（看到的是渠道名称，不是 `df-c1234…` 这种代号）。
- **F5 经由模型组对话（自动换渠道）**：先在 F2 的渠道上点「编辑」→ 什么都不改直接「保存」（这会让它从「Key 无效」恢复成可以尝试的状态）。然后新会话选「【测试】主力」，发「只回复两个字：你好」。→ 正常收到「你好」；屏幕下方弹出提示「已从「【测试】坏 Key · deepseek-flash」换到「DeepSeek · deepseek-flash」：Key 无效」；对话里可能有一条重试/换渠道的提示行。
- **F6 粘住渠道**：在同一会话再发「再回复两个字：收到」。→ 正常回复，**不再**出现换渠道提示；回复下方的数据里「缓存」数字明显大于 0。
- **F7 仪表盘**：点导航栏「仪表盘」。→ 顶部三张卡片（今天 / 近 7 天 / 本月）有花费和 token；「渠道」区每个渠道一张卡片（状态点、今天请求数、首字延迟、最近出错）；点「查询余额和额度」后 DeepSeek 卡片显示「余额 x.xx CNY」；「最近 30 天的花费」柱状图；下面按「渠道 / 模型 / 工作区 / 会话」切换的拆分表，渠道名可读。
- **F8 每月上限**：先看 F7 仪表盘「本月」的花费：如果是 \$0（模型没填价格，花费算不出来），这条记为「跳过（模型没有价格）」。否则：设置 → 「运行上限」→「每月花费上限」填 `0.0001` 回车。然后发一个问题。→ 任务暂停，提示「本月的花费已达到上限」，在「任务 › 待处理」里有卡片，可以选「本月不再限制并继续」或「到此为止」。测完把每月上限清空（不限）。
- **F9 设置搜索**：设置页右上角搜索框输入「上限」。→ 跨分类列出「每天花费上限」「每月花费上限」等；输入一串乱码显示「没有找到」。
- **F10 设置分类巡检**：逐个点左侧所有分类（通用、外观、模型与网关、对话、记忆、安全与审批、运行上限、工具与 MCP、数据与存储、关于）。→ 每个分类都有内容、没有报错、没有明显错位。

### G. 外观

- **G1 缩放**：按 Ctrl + 加号两次、Ctrl + 减号一次、Ctrl + 0。→ 整个界面（包括弹窗和菜单）一起缩放，顶部短暂显示「缩放 110%」之类，Ctrl+0 恢复 100%。

- **G3 窄窗口**：把窗口拉窄到大约 900 像素宽。→ 右栏自动隐藏，界面不重叠、不溢出。

### H. 其他页面
