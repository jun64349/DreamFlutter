# 全场景测试清单

v0.3.3 起，每个版本发布前按这份清单走一遍。目标：用户实测时不再碰到「用不了」的问题。
每一行写清楚由哪个自动测试覆盖；只能手动验证的标「手动」，发布前由 Claude 在安装包上走一遍，走不了的写进发布说明请用户试。
