# DreamFlutter v0.2 发布说明

v0.2 是一次全面的重做：新的视觉和对话体验、Agent 模式、模型网关、多模态和交互卡片，以及按新设计重做的各个页面。下一步见 [roadmap.md](roadmap.md)。

## 新的样子

- 视觉方向「蛱蝶」：纸绢底、墨色字、石绿强调、朱印，宋体标题和回复正文，工笔蝴蝶标志。
- 7 个名画主题：日间「蛱蝶」「草蝶」（梵高）「羽化」（梅里安）「神思」（多西），夜间「墨夜」「幽华」（德·黑姆）「琉光」（蒂芙尼）。颜色、圆角、标题字体、印记和题字都跟着主题变；明暗可以跟随系统。
- 自绘顶栏，颜色跟着主题，不再有白色的系统标题栏。
- 界面缩放（Ctrl + 滚轮，或 Ctrl + 加号 / 减号 / 0）和文字大小。

## 对话

- 三栏：会话栏、对话、右栏（本次运行 / 书桌 / 分支）。
- 一次回复的思考和工具调用合成一个「过程」块；命令是终端样式，修改文件显示差异。
- 回复可以复制、重新生成（可换模型，版本可切换）、从这里分叉。
- 数学公式、代码高亮、表格。
- 附件：拖文件到对话区任何地方，或粘贴；图片直接给模型看（看不了图的模型由看图模型转述），Word / PDF 转成文字，`@` 引用书桌的写笺和资料。
- 上下文用量在长任务里每轮刷新。

## Agent

- 两种模式（按 DeepSeek Harness 复现）：「标准」是完整的工具、待办、计划模式、记忆和技能；「极简」是一句话提示词和一个持久 PowerShell。
- Showcard 1.0 交互卡片：Agent 在对话里做可交互的卡片，可以调用授权过的工具，可以导出、导入、收进书桌。

## 模型

- 模型网关：渠道（DeepSeek、智谱 / Kimi / MiniMax 编程套餐、OpenAI / Anthropic 兼容中转）；一个渠道可以有多个 Key，轮流使用；模型组按顺序使用，额度用完、限流或出错时自动换下一个；每月花费上限。
- **OpenCode Go**：选平台、填 Key、获取模型列表即可；每个模型的上下文窗口、价格、能用的思考档位自动带上。
- 仪表盘：花费、各渠道状态、余额和套餐额度。

## 页面

- 书桌三栏：写笺列表和资料、纸面写笺、进行中 / 产物 / 卡片 / 最近任务。
- 任务：待处理、全部任务（按天分组和筛选）、定时任务（可以接着同一个会话运行）。
- 记忆：记忆库、待确认、常驻记忆块。
- 技能与模板：技能、任务模板、待确认。
- 设置：左侧分类和搜索。

## 已知的限制

- 真实对话只用 DeepSeek 实测过。OpenCode Go 按官方公开的模型列表核对过地址和模型信息，真实对话要用户的 Key 实测（`core/scripts/live-opencode.ts`），它也没有额度查询接口。智谱、Kimi、MiniMax 的地址和额度接口来自调研，没有账号实测。
- 自绘顶栏的最大化按钮没有 Windows 11 的贴靠布局菜单（Win + 方向键可以用）。
- 深度测试里的其余建议排进了 v0.3–v0.9，见 [roadmap.md](roadmap.md)。
