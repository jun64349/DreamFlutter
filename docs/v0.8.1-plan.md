# v0.8.1 开发计划：补足体验、修 bug、优化

日期：2026-11-10。来源：用户实测 0.8.0-test.2 的报告（21 条带截图，`dfv0.8.0测试记录.pdf`），用户评价"非常不满意"。

## 一、为什么会这样

- **以前的需求丢了**：roadmap 4.3 和 11.2（来自 v0.4 实测）要求右栏分块放改动、产物、上下文与花费、后台任务，"⋯"里的功能放到显眼位置。写交互设计时右栏被缩成只有"本次改动"，上下文变成圆环小弹窗，常用操作又塞回"⋯"菜单。test.2 照这份设计做，结果就是"毛坯"。
- **test.2 只对了"长什么样"，没走"用起来怎么样"**：重试成功后错误卡还在、点了没反馈、去设置不跳转，这些都要真点一遍才发现。
- **设置页把机制和说明都摊出来了**，违反设计原则第 6、7 条（设置只放偏好；让布局来说明）。

**以后的规矩**：改界面前，除了交互设计，还要对 roadmap 和历次实测报告里的界面要求；两边冲突先问用户。

## 二、范围

只做补足、修复和优化，不加新功能，不动 0.9 起的计划。新东西都装进体验版原型已有的位置（右栏、输入框、设置分组），不另起页面结构。

编号 F 是 bug，R 是右栏和对话操作，C 是对话区，S 是设置和花费。括号里是报告条目号。

### R 组：右栏和对话操作（2、3、4、7、8、10）

- **R.1 右栏改成分块**（工作台；蝶君沿用"任务进度"，同样加 R.2）。从上到下：
  1. **改动和产物**：改了的文件（点开看差异）、生成的文件（预览 / 打开所在文件夹）、Git 提交。
  2. **上下文**（R.2）。
  3. **常用操作**（R.3）。
  4. 后台任务的位置先留好，0.9 有了再填。
- **R.2 上下文块**：一条进度条 + 已用 / 窗口（如"6.2 万 / 100 万"）；这次对话的输入、输出、缓存命中、花费；"整理上下文"按钮，整理时有进度，完成后显示省了多少。去掉现在居中的"上下文"弹窗；输入框的圆环保留，点它打开右栏并定位到这一块。
- **R.3 常用操作**：存成技能、导出（Markdown）、归档、删除，放在右栏底部。
- **R.4 去掉对话"⋯"菜单**：存成技能、导出、归档、删除移到 R.3；"这段对话不记忆"和输入框的"无痕"重复，删掉；"定时再做一次"删掉，定时在对话里跟 Agent 说（流程 4.8 第 5 条本来就是这样）。侧栏对话列表的右键菜单同步：只留置顶、重命名、导出、归档、删除；"复制为新对话"保留。
- **R.5 导出只留 Markdown**，去掉 HTML。
- **R.6 删除**：改成明确的确认（说清删了进回收站、30 天可恢复），不再用底部"已删除 · 撤销"。回收站里的彻底删除仍是二次确认。
- **R.7 提示条**：3～4 秒自己消失；带按钮的（撤销、打开文件夹）5 秒；鼠标停在上面时暂停计时。全应用统一。

### C 组：对话区（5、6、9）

- **C.1 "操作前问我"**：换成一眼看得出当前状态的样子：图标 + 状态字（"先问我" / "直接做"），点一下切换并提示一句。不靠悬停提示解释。
- **C.2 错误卡**：原因完整显示（长的可展开）；三个按钮统一大小和样式，第一个是主按钮；"换个模型"直接弹出模型列表。
- **C.3 中间输出进过程链**：工具调用之间模型说的话（"我按写作方向搜了一圈……"这类）归到过程链里对应的步骤下面，正文只放最终回复；过程链展开后按时间顺序看得到。

### S 组：设置和花费页（12～18、20、21）

- **S.1 设置页整体收拾**（16、17、18）：每项只写名字；说明行全删，确实需要的放"?"悬停；每组只露常用项，其余进底部"高级"。逐组过一遍，目标是每组第一屏就能看到全部常用项。
- **S.2 主题只选一处**（14）：去掉"日间主题 / 夜间主题"两行按钮，只留名画卡片（日间一排、夜间一排），卡片放在"通用"里，不收进"高级"。
- **S.3 下拉和弹出菜单**（13、15）：下拉菜单和原控件同宽、从原控件位置展开，不盖住原有内容；统一圆角、阴影、动效（规范 5.4 的中档 250 毫秒）。全应用的下拉、菜单统一用一个组件。
- **S.4 去重**：在"关于与更新"里重复的"关闭窗口时"删掉（留在"通用"）；"数据备份与恢复"只在"数据与安全"。
- **S.5 数据与安全**（16、17、18）：数据位置改成一张表（名称、大小、打开），"修改位置"收进每行的"⋯"；路径例外、审计、磁盘空间都进"高级"，说明删到一句以内。
- **S.6 模型**（20）：删掉"模型组"和"按模型覆盖上下文窗口"（窗口在渠道里填）；"原有连接配置"进"高级"的最底下或删掉；只留对话 / 小任务 / 大任务 / 看图四个模型（概念表第 37 项）。
- **S.7 工作台 / 网络**（21）：输入框形式的数字项改成和其他项一样的右侧小控件；网络里的价格说明、软件源说明删掉，"联网搜索"只留状态、密钥、测试。
- **S.8 花费页**（12）：顶部本月、今天加上 token 数和对话次数；按用途只列有花费的；账目表紧凑行高、金额右对齐、模型名不折行，可按用途筛选；日期范围用一个控件。
