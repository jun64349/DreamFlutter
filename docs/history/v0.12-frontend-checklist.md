# 0.12 前端清单（2026-11-13 草稿，待用户确认）

来源：roadmap 0.12 节（11.0–11.7）、0.9 节「挪到 0.12 的界面部分」、0.10 节末用户定的方向、0.11 留给 0.12 的事、0.8.1 计划里留下的右栏后台任务，以及 v0.4.0 报告（11.2）。界面形态以体验版原型 [interaction-v2.html](../design/prototype/interaction-v2.html) 为准；[已定型清单](../design/settled-0.8.3.md)里的表现不动，只有用户已经同意的两处例外（蝶君侧栏加「日程」一行、输入框加麦克风）。

演示原型：[prototype/v0.12-additions.html](../design/prototype/v0.12-additions.html)；交互规则：[v0.12-frontend-spec.md](v0.12-frontend-spec.md)。

**用户 2026-11-13 定**：0.12 在 0.8.3 的界面上往上加。0.8 的基本操作逻辑已经测过、没问题，最基础的东西不要轻易动。新功能只往现有的页面和位置里放，不重做已有的页面，也不改已有的交互。

现状：窗口里还没有调用目标、日程月历、巡检、后台任务、语音、性格、主动规则、卸载这些接口，0.9–0.11 的后端都还没接进界面。

「位置」一栏：**原型有**的照原型做；**待定**的原型里没有这一块，要先在原型里画出来给用户点过再做。
