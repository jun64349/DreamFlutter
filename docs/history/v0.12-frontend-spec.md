## 一、总规矩（每张卡都适用）

1. **在 0.8.3 上往上加**（用户 2026-11-13）：0.8 的基本操作逻辑已经测过，不动。新东西只放进原型里标出的位置，不重做已有的页面，也不改已有的交互、布局和用词。
2. **已定型清单**（[settled-behaviors.md](../design/settled-behaviors.md)）里的 16 条，和守着它们的测试，必须一直通过，不能为了让测试通过去改期望。只有两处是用户同意过的例外：蝶君侧栏加「日程」一行（D1），输入框加麦克风（E1）。
3. **让布局自己说话**：能靠位置、分组、顺序、图标或状态看懂的，就不加副标题、说明行和提示文字。原型里每一行字都是定好的，不要多加。
4. **配色、字体、圆角、间距**：一律用现有主题里的值（`app/lib/theme*`），不新增颜色。八套名画主题、浅色和深色都要能看。
5. **只用 `docs/api/` 里的接口**。窗口里换掉标「旧，0.12 换掉」的接口（A1）。要用的接口文档里没有，或者行为对不上，记进卡里第 4 节，不要自己去改后台。
6. **测试**：每一项都要有组件测试；新页面和新区块加进视觉检查截图（浅色、深色，1600 和 1000 两种宽度）；改完要跑已定型守护测试和三个真窗口截图守护。

## 二、各项规则

编号和清单、原型一一对应。「接口」列的是主要用到的接口，细节看 `docs/api/`。

### A 接口换新

- **A1**：蝶君旧任务流（`butterfly.prepare/start/answer/cancel/tasks`）换成 `butterfly.chat.*` 加目标服务；`memory.list` 换成 `memory.items`；`providers.*` 换成 `gateway.*`；删掉 `notes.save` 的测试夹具。换完以后，`app/lib` 里不应再出现这些旧名字。
- **A2**：修复批里的错误码一起改，界面上的错误提示要说人话。

### B 蝶君这个人

- **B1 性格和主动性**（设置 › 蝶君；首次向导里蝶君那一步）：性格是四张卡片，下面一句示例话随选择变化。主动性三档，下面一行写这一档会做什么。「自己做事每天最多花」是金额选择。接口：`persona.presets`、`settings.update`。
- **B2 规则**：蝶君起草的规则进「等你处理」，按钮是「先观察 / 改一改 / 不要」。设置里列出全部规则，每条三档（关 / 观察 / 自动），由 `autonomy.rules.mode` 切换。规则只有用户能改。接口：`autonomy.rules.*`、`attention.*`。
- **B3 主动聊天**：消息出现在和用户的对话里，上面一行小字「今天 09:12 · 蝶君来找你」，不进「等你处理」。这里只做显示，什么时候发、发几次由后台控制。
- **B4 蝶君写的技能**：技能页里加「蝶君写的」标记；点「也给工作台用」调用 `selfwork.skills.adopt`，之后标成「工作台也在用」。
- **B5 蝶君的记忆**：记忆页（已定型第 16 条）不改布局，分组里加「蝶君自己记的」；每条都显示来源。
- **B6 等你处理**：按「待你决定 → 卡住了 → 等你验收」的固定顺序分组，每组左边一条色带，空的组不显示。卡片写清楚是谁、哪件事，现在怎样、会有什么影响，再给能直接做的按钮。接口：`attention.prioritized`、`attention.resolve`。
- **B7 长期目标**（设置 › 蝶君）：列出用户交给蝶君的长期目标，每条可以暂停或继续，点开看它做过什么；最后一行「加一个」。接口：`selfwork.longGoals.*`、`selfwork.history`。

### C 目标和长任务

- **C1 目标卡片**（右栏「这个对话」最上面）：目标名（宋体加粗）、一句话目标（和目标名相同时不重复）、下一步、预算条、用时；按钮「暂停目标」「停止目标」，「⋯」里放紧急停止。只在这个对话有目标时出现。接口：`goals.get`、`goals.control`、`goals.changed`。
- **C2 目标状态**：不另做目标列表页。侧栏对话前面加小圆点（在推进：绿色闪烁；暂停：赭色；卡住：红色），没有目标就没有圆点。要用户处理的进「等你处理」。
- **C3 计划**：贴在输入框顶上，默认收起，标题行写「计划 2/5 · 正在：…」加进度条；点一下展开成清单，做完的打勾划线，正在做的加粗。没有计划时不出现。
- **C4 提问**：三张选项卡片，加「自己回答」和「跳过」。限时的在右上角倒数，写明到点按哪个选项继续；默认的选项下面写「默认」两个字。答过以后收成一行「你选了…」。
- **C5 三种停止**：输入框的停止按钮 = 停下这一步（已有，不改）；暂停 / 停止目标 = 管这个目标的续跑；紧急停止 = 停下所有目标（蝶君和工作台，接口 goals.control emergency 是全局的；2026-11-13 Claude 定），停下后目标卡上出「已紧急停止」和「解除」（clear_emergency），要先确认，确认框里说清楚会停下什么、不会删什么。
- **C6 后台任务**（右栏一块）：正在跑的命令和子任务、用时；眼睛图标在原地展开输出，方块图标停止；刚结束的变淡，留一会儿再消失。工作台和蝶君都有。接口：`jobs.list`、`jobs.output`、`jobs.stop`、`jobs.changed`。
- **C7 过程图片**：中间过程生成的图片和截图，直接显示在回复里，下面一行小字写文件名和产生它的命令。
- **C8 「要不要设为目标」**：后台给出提议时，在对话里出一张小卡片，按钮「设为目标 / 不用」。接口：`goals.proposals`、`goals.proposals.resolve`。

### D 日程和巡检（只在蝶君）

- **D1**：蝶君侧栏「等你处理」下面加一行「日程」。
- **D2 日程页**：标题照其他页面的格式（艺术字「朝暮」，下面一行小字「日程」），右上角「新建」。「每天」一行放重复的事项；下面左边是月历（周一开头），右边是选中那天的清单。点某一条，下面展开详情：可以改、现在做一次、删除，改动历史里每一条都能撤销。过去的事显示结果，没做成的标红。接口：`schedules.occurrences`、`schedules.save`、`schedules.history`、`schedules.undo`、`schedules.runNow`。
- **D3 巡检**：日程页顶上一行，写上次的结果和下次的时间；「巡检记录」在原地展开，「现在巡检」有冷却。接口：`patrol.status`、`patrol.log`、`patrol.runNow`。
- **D4 对话里的提示**：建了或改了日程，在对话里出一行淡色提示，两边各一条细线，中间写「建了日程「…」」，后面跟「看日程」。
- **D5**（设置 › 蝶君 › 日程与巡检）：巡检开关、多久一次、夜间不打扰、提醒到点时怎么告诉你；其余设置收进「高级」。

### E 语音输入

- **E1 麦克风**：放在输入框底栏、发送键左边，工作台和蝶君都有。**按一下开始，再按一下结束**。录音时：输入框边框换成印章红，底栏换成实时声波和计时，模型选择先藏起来，识别到的字实时写进输入框。结束后文字留在输入框里，不自动发送。出错时在输入框下面用一行字说明，不弹窗。录音用 16 kHz 单声道 PCM，每块 100–200 ms，送给 `voice.chunk`；`voice.partial` 和 `voice.final` 拿到的文字写进输入框，显示校正后的文本。
- **E2**（设置 › 通用 › 语音输入）：识别方式选本机或云端；选云端才出现「服务」和「Key」两行。接口：`voice.setKey`、`voice.keyStatus`、`settings.update`。

### F 卸载和数据

- **F1**（设置 › 数据与安全 › 卸载）：点「卸载…」弹出对话框，二选一：「全部清干净」或「保留我的数据」。选保留时，写入保留数据标记（`data/uninstall-keep-data`），然后启动 Velopack 卸载程序。
- **F2**（首次向导第一步）：`uninstall.preservedData` 找到上次保留的数据时，显示保存时间、大小和里面有什么，按钮「找回来 / 重新开始」。「找回来」调用 `uninstall.restorePreservedData`，显示进度，后台会重启。「重新开始」不删那份数据，只告诉用户它放在哪里。存储布局不同、不能自动恢复的，也只给出位置，不提供强行恢复。
