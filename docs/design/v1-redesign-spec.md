## 4. 设计系统

### 4.1 设计原则（做每个界面时都要对照）

1. **一屏一个重心，装饰只放一处。** 首页的中线（蝴蝶 → 问候 → 引文 → 输入框 → 例子）、每个面板只有一处诗意标题。
2. **少边框，多用浅底色分层。** 卡片用很淡的阴影描边（`0 0 0 1px line2`），凹进去的区域用 `sunk` 底色。
3. **强调色只给能点的和选中的。** 危险的值只用红字。
4. **布局自己说话。** 不加副标题和说明行；设置的说明行只写「改了会怎样 / 什么时候生效 / 什么不会被影响」（`hana-study.md` 第 6 条）。
5. **快、只淡入。** 面板 120–140 毫秒淡入（略微上移和缩放），展开内容 120 毫秒淡入，**不做高度动画**；没有空壳先出、内容后到的情况。
6. **我们自己的气质**：宣纸纹理、竖排题字、书法问候、墨色渐变、会浮动和扇翅的蝴蝶、诗意页名。每样都只出现在固定位置，不到处撒。

### 4.4 字体

| 用途 | 字体 |
|---|---|
| 全部界面、导航、设置、按钮、标题、问候、卡片与主题名 | Georgia 显示英文，中文首选内置霞鹜文楷 LXGW WenKai，后备 KaiTi / STKaiti；共用字体栈 |
| 用户输入、用户气泡、正式助手回复和文档阅读 | 同全局字体栈，正常字形；代码仍用等宽体 |
| 工作过程、工具与文件操作、巡检说明 | 全局字体 / 等宽字体统一斜体，含折叠摘要、路径、命令、输出、diff；按消息类型区分 |
| 首页中华引文、中文译文与出处 | 同全局字体栈，居中正常字形 |
| 首页国外引文英文原文 | Georgia 衬线斜体，备用 Times New Roman / serif |
| 代码、路径、快捷键 | Cascadia Mono / Consolas |

字号：正文 14；回复 15、行高 1.85；设置页名 19；分组标题 14 粗；说明 12.5；小字 11.5–12。

2026-11-16 数字追加：全局启用 `lnum` 与 `tnum`，让数字使用齐线字形，避免 Georgia 默认旧式数字高低错落。时间、金额、统计和模型版本沿用各自既定字号，字母/中文风格不变；显式数字样式不能只开 `tnum` 而漏掉 `lnum`。Web 卡片与原型同样适用。

2026-11-16 用户追加：正式回复的引用块不因 `>` 自动斜体；显式 Markdown 强调仍保留。蝶君主动发起只是来源提示，正式交流也用楷体；工作链中的过程叙述和巡检记录才用过程字形。字体只内置一份 Regular，SIL OFL 许可随资产保存并注册到应用许可清单。

2026-11-16 再次明确：字体是整个系统一起换，覆盖原来的 sans / serif / handwriting 角色；整体中文楷体，普通英文艺术衬线不强制倾斜。Georgia 使用 Windows 系统字体，中文使用内置霞鹜文楷；嵌入式 Web 卡片使用 Georgia / Windows KaiTi 后备，不为字体改动后台或复制字体到用户文件。

现有六套日间与六套夜间主题统称「名作主题集」，主题 ID 与设置键不变。常用图标两族以器物、册页、印面和仪器刻度区别，设置不再齿轮；停止保留单实心方块，品牌蝴蝶不变。按压 100 ms，释放 110–140 ms：纸上压印、木作横向嵌合、羽化垂直落针、石青斜向嵌合、玻璃轻压分段亮痕。反馈只随操作出现，减动效/停用 TickerMode 时立即静止；原点击、焦点、键盘和保存行为不变。

上下文环为 18 px、占用弧 2.4 px，按实际比例在 420 ms 内平滑变化；未知用量和 0 均不画假进度，不持续旋转。进度头有轻光晕，60%／85% 沿用警示阈值，减动效时立即更新，点击仍打开上下文。

侧栏模式、工作区、选中对话和导航共用主题选中表面：浅色在 sidebar 底上混 accent 16% → art-2 8%；深色先以 ink 3.5% 提亮，再混 accent 25% → art-2 14%。边线分别 22%／34%，右上 36×20 局部纹样分别 .22／.32；保留原点击区和选中左条，不让纹样挡字。

### 4.7 动效

| 场景 | 做法 |
|---|---|
| 浮层打开 | 遮罩 120ms 淡入；面板 140ms，从下移 6px、缩放 0.985 到原位 |
| 过程块、行展开 | 内容 120ms 淡入，高度直接变 |
| 侧栏收起 / 展开 | 宽度 120ms ease-out，内容裁切不挤压 |
| 开关、分段 | 120ms |
| 蝴蝶 | 首页是独立 104 px 原标志，5 秒轻呼吸（上移最多 2 px、放大最多 3.5%、透明度最低 .92），停 1 秒后继续；无圆圈、底盘或光圈。品牌与回复动效沿用原规则；减少动效时首页静止（2026-11-16 用户追加） |
| 系统设置减少动效时 | 全部关掉 |

### 4.8 名画细节与动效层次（R0 新增，必须实现）

精确样式以 `v1-art.css` 为准，线条母题以 `v1-motifs.js` 为准。不是只换配色，也不是另外堆一层花纹；按四层实现：

1. **材质层**：纸绢、草叶笔触、博物图版刻度、双层画框、琳派折痕、暗室花卉、彩玻铅条、色粉晕染、石青绣线，分别进入 `--home-art`、`--side-art`、`--card-art`。只作低对比度背景，正文对比度不能被装饰拉低。
2. **控件层**：开关滑块、范围滑块、按钮、选中描边和卡片边角跟随当前主题。石青用平金菱形，羽化用图版刻度，琉光用透光高亮，其余主题照 CSS 的 `data-art` 规则；颜色一律取自主题变量。
3. **反馈层**：图标按钮、普通按钮、发送、胶囊、卡片按下时轻微下落并缩到 0.975，100–160ms 内完成；发送、复制、重新生成、计划展开各有很轻的图标反馈。不能用大幅弹跳、长尾粒子或持续闪烁。
4. **环境层**：首页 `wash` 18 秒轻微漂移，名画母题 22 秒呼吸；只放在首页留白和主题卡预览，不铺到回复正文后面。母题默认透明度约 13%，同一屏仍只保留一个视觉重心。

`motif(id)` 覆盖 12 套主题；暖纸 / 暮色共用一组，蛱蝶 / 墨夜共用一组，其余各有自己的线条。Flutter 实现应做成主题对应的矢量绘制或资产，不引用原型 JS，不另找风格不一致的图片。

系统「减少动效」或原型 `data-motion="off"` 时，所有装饰和蝴蝶静止，按压位移动画也关闭；布局、可读性和操作反馈不能依赖动画才能完成。

### 4.9 计划条、展开清单和输入框的共同容器

- 三者必须同属一个 `.planbox`，共同受正文最宽 720、左右自动居中的约束；内部三者的左右边距都为 0、宽度一致。
- 不得再用 `.planlist` 的简写 `margin` 覆盖居中边距，也不能按窗口宽度补固定左边距。
- 展开只做 120ms 内容淡入，不做高度动画；展开后计划条和清单使用相接圆角。
- R0 已在本机 Edge 验证 1600 / 1000 / 760 宽：三者左右边界误差均为 0，无横向溢出。Flutter 的 R3 要保持同样结果，R7 再截图验收。

## 5. 各页面规格

每一节写「结构 → 内容 → 状态」。像素和文字以原型为准；这里写原型里看不出来的规则。

### 5.1 窗口外壳

- 三栏：侧栏 264 | 主区 | 右栏 312。右栏只在对话页出现，可以收起；窗口宽度不到 1100 时右栏自动收起，不到 860 时侧栏变成浮在上面的抽屉。
- **宣纸纹理**：整个窗口最上面一层很淡的噪点（浅色主题 5% 正片叠底，深色主题 3% 滤色），不挡点击。强度在设置 › 外观 › 纸调；「关」就去掉。Flutter 可以用一张平铺的噪点图加 `BlendMode`。

### 5.2 侧栏

从上到下（2026-11-15 用户修订：工作区挪到搜索框下、对话行第二行写「时间 · 当前模型」、分支默认折叠）：
1. 品牌行：蝴蝶（浮动）＋「DreamFlutter」（衬线、强调色、粗）＋「梦蝶」小字＋收起按钮（`Ctrl + B`）。
2. 工作台 / 蝶君切换，做成分段按钮。
3. 导航：新对话、等你处理（红色数字）、日程（只在蝶君出现，右边写「今天 N」）、记忆（右边写「新 N」）、技能（有等你确认时一个赭色小点）。**记忆和技能从底栏挪到这里。**
4. 分隔线，搜索框（右边写 `Ctrl K`）。
5. 工作区按钮（只在工作台出现；定型第 6 条）。
6. 对话列表：按「今天 / 更早」分组；每行两行字，标题 + 淡色的「时间 · 当前模型」（蝶君写状态，比如「在推进 · 计划 2/5」）；状态小圆点：绿色呼吸 = 在推进、赭色 = 暂停、红 = 卡住；分支默认折叠，主对话左边一个小钮展开／收起（带上分支条数），展开后分支缩进、带分支图标。
7. 右下角**竖排题字**：随主题换，透明度 13%，不挡点击。
8. 底栏：头像和称呼、花费按钮、设置按钮（`Ctrl + ,`）。纯图标按钮一律不带文字标签，悬停显示名字（2026-11-15 用户定，全窗口适用）。

### 5.3 首页

- 主区一条中线：独立蝴蝶（104，轻呼吸，无外圈）→ 问候（书法 34、字距 0.12em、墨色到强调色到赭色的渐变）→ 一笔淡淡的墨痕 → 居中引文 → 输入框（最大 900 px，窄窗随空间收缩；默认三行，整体约 130 px 高）→ 五枚例子胶囊（同 900 px 上限，自然换行）。工作台和蝶君首页共用这一尺寸。
- **2026-11-16 最新引文决定：中文和英文都扩充并随机。** 暖纸、暮色、蛱蝶、墨夜、石青使用 24 条庄子原文；草蝶、羽化、神思、千蝶、幽华、琉光、幻蝶使用 24 条公版英文精选与项目自译。按画作文化来源分组，不按圆转／截角造型分组；千蝶画源日本，属于国外组。候选原文与逐条出处见 [引文候选](research/T-143-引文候选.md)。
- 新对话从各自的洗牌袋取一句，抽完一轮再重排，跨轮不连续重复。当前页面重建、切换主题、切回已有对话保持对应文化组的句子；无定时轮播、无新增设置键，会话绑定仅保存在当前运行内存。
- 引文原文 18 px；中文译文 16 px；出处 14 px。英文原文用衬线斜体，中文正常楷体，居中排列，出处始终在最下行。名言区最小高度 120 px，窄窗允许自然换行。Flutter 数据在 `ui/home_quote_data.dart`，选择在 `ui/home_quote.dart`；原型在 `v1-home-quotes.js`、`v1-redesign.js` 和 `v1-art.css`。首页输入仍最大 900 px、默认三行、左右各留 20 px 安全矩形。
- 顶部一层主题色的淡晕（径向渐变）。
- 工作台的问候轮换；蝶君的问候固定「交给我吧，你去忙别的」。
- 例子点了**只填进输入框，不发送**。
- 第一次使用时，「开始之前」三步引导放在问候和输入框之间，样子照新卡片（见 5.12）。

### 5.4 输入框

- 外形使用第 4.10 节的圆肩收足或直梁截角，`card` 底。编辑区用底部窄边确定矩形的左右边界，各留 20 px，较宽的上部自然留白。缩放和多行输入时保持这个文字区，边线不遮挡文字。焦点沿同一外形描边，并加约 3 px 的浅色外晕。
- 占位文字每 4.5 秒轮换一条用法提示（`TIPS`）；正在输入或有草稿时不换。
- 底行左边：附件、无痕、先问我（工作台才有）。右边从左到右：模型按钮（`sunk` 底胶囊，写完整的「模型 · 渠道」，定型第 11 条）、思考深度、上下文环、麦克风、发送。2026-11-16 用户对实窗图明确要求这组靠右贴近发送键，空白留在左工具与模型之间；窄窗换行后也靠右，替代旧存档图中的居中排列。
- 宽首页里，只有超长「模型 · 渠道」占不下同一行时才把左工具和右工具分为两行，让模型全名有完整位置。常规模型名保持单行靠右；窄窗沿用原来的渐进省略和换行规则。
- 发送按钮：没字时是淡色，有字时强调色实心；生成中换成主题警示色的停止方块，沿用原中止动作。按用户本轮要求融入的两套文物组件轮廓，见 `research/T-143-文物组件调研.md`、`prototype/v1-craft.js`，不把所有主题强行套同一圆形外圈。
- 输入框上方可能出现三种条，从上到下：计划条（蝶君）、出错 / 提醒条（红色浅底，带去处链接和关闭）、引用。

### 5.5 对话

- 正文一栏最宽 720，居中。
- 你的消息：靠右，`sunk` 底，圆角 16/16/4/16。
- 回复：左边 34px 的位置放小蝴蝶（定型第 12 条），正文衬线 15、行高 1.85。
- **过程块**：`sunk` 底、圆角 10、没有边框；折叠时只和标题一样宽（最少 380），展开占满正文宽度。
  - 标题：进行中写正在做的那一步，前面一个赭色呼吸点，右边写「前面 N 步」；做完写汇总（沿用现在的 `workSummary` 文字），前面一个勾，右边写总用时；有出错时底色变成浅红，右边写「N 个出错」。
  - 展开后一行一步：图标、动词、对象、右边写用时和结果。思考只占一行「思考 · N 秒」，斜体淡色，点开才看内容。路径从目录那头截短，文件名保持完整，悬停看完整路径。命令点开看输出，改动点开看差异，读取不用点开。出错的那一行自动展开。
- 批准卡：`card` 底、圆角 14；标题前面一个盾牌图标；一句为什么；差异；按钮「允许 / 拒绝 / 这个对话里都允许这类操作」。
- 提问卡（蝶君）：三张选项卡片，默认那张写「默认」；限时的在右上写倒计时和到点按哪个继续；下面一行「自己回答…」和「跳过」。答完收成一行淡色的「你选了…」。
- 淡色提示行（建了日程等）：左右两条细线，中间一句话加一个链接。
- 回复下面那一行：内容照定型第 8 条；右边的按钮（复制、重新生成、从这里重来、参考了哪些记忆、更多）悬停才出现。
- Markdown：表格细线全框、表头用 `sunk` 底；引用左边一条 2px 竖线、斜体；行内代码 `sunk` 底。
- 代码块：底色是 ink 5% 混进 card；头上一行左边写语言名，右边的按钮平时 55% 透明、悬停变清楚。
- 图表块（Mermaid / Chart / SVG）：头上一行「图 / 源码」分段按钮加复制、放大；**图要跟主题换颜色**。

### 5.6 右栏「这个对话」

- 工作台：标题「这个对话」加收起；**文件 / Git / 后台 / 上下文** 四区纵向排列，默认全部展开，各自可收起。收起和预览返回保留区内状态；上下文环会重新展开并定位到上下文。此项按用户 2026-11-16 反馈覆盖横向页签。
  - 文件：工具行（「2 个改动 · 3 个读过」、筛选、排序），文件行左边一个带颜色的类型方块（MD 蓝、PY 绿、CSV 赭……）。定型第 7 条的预览和右键菜单照旧。
  - Git：分支、改动列表、「提交这些改动」「看差异」。
  - 后台：后台任务列表、看输出、停止。
  - 上下文：用量条、整理阈值、「现在整理」。
- 蝶君：竖着排四张卡片：目标（阶段、一句话、下一步、预算条、用时、暂停 / 停止 / 更多里是紧急停止）、后台、交付、定时。
