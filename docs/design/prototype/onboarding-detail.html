共用的样子

侧栏底部的「入门」进度卡

放在侧栏对话列表下方、用户名上方（现在那里是空白）。必修五课学完，或点「不用了」，它就消失；以后只能从使用说明里重学。

跟着做的小卡片

贴在要操作的地方旁边；其余界面压暗（点压暗处不会误触）。每步只说一件事。用户真做了才进下一步；只有纯「看」的步骤才有「看懂了」按钮。

「帮我写一张明天请假一天的请假条，理由是去医院复查」
不想打字就点「帮我填好」，然后按 Enter。
帮我填好看图文说明先退出
  • 「看图文说明」：打开课本对应那一页，压暗暂时撤掉；关掉课本回到这一步。
  • 「先退出」：收起卡片，进度保留，侧栏卡片显示「继续 ›」。
  • 窗口太窄、要亮的东西被收起时，卡片先说「先把左边栏展开」，并亮出展开按钮。

第 1 课　Agent 是什么必修3 分钟

步卡片上的话亮出哪里怎样算做完
1DreamFlutter 是一个会动手的助手。普通聊天机器人只回答问题；它还能读写你电脑上的文件、运行程序、上网查资料，把一件事从头做到尾。整个主区（不压暗）点「看懂了」
2它有两种用法。工作台：你在旁边看着它做，它动你的文件前会先问你。蝶君：交给它一件事就可以走开，它在一个隔离的小系统里自己做完，碰不到你的文件。左上角「工作台 / 蝶君」切换点「看懂了」
3做这些事需要一个「大脑」，也就是 AI 模型。下一课把它接上。无点「下一课」

课本这一页：上面三段话 + 首页截图标出「工作台 / 蝶君」+ 一张对比小表（工作台 vs 蝶君：谁看着、能不能碰你的文件、适合什么事）。

第 2 课　接上一个模型必修10 分钟

安装向导里已经有「连接模型」这一步。向导里接好了，这课自动打勾，卡片只说一句「你在安装时已经接好了 DeepSeek ✓」。没接好的人才走下面的步骤。

步卡片上的话亮出哪里怎样算做完
1「模型」是帮你思考的 AI，「密钥」是你在模型公司那里的账号凭证，像一把钥匙。我们用 DeepSeek 举例：便宜、国内能直接用。无点「看懂了」
2点左下角的齿轮，打开设置。左下角齿轮设置页打开
3点「模型服务」，再点「新建渠道」。模型服务 → 新建渠道新建渠道页打开
4服务商选 DeepSeek，然后点「去 DeepSeek 拿密钥 ↗」。浏览器会打开 DeepSeek 的网站；网站上的每一步看「图文说明」（注册 → 充值 10 元 → 创建 API Key → 复制）。DeepSeek 选项、拿密钥链接选中 DeepSeek
5回到这里，把复制的密钥粘贴到「密钥」框里。粘贴后会自动试连接。密钥输入框出现「连接成功」
6点「保存」。接好了 ✓ 以后每次对话就用它。保存按钮渠道保存且有可用模型
网站上的那几步（注册、充值、建 Key）在 DeepSeek 自己的网站里，程序看不到也亮不出来，只能在课本里一张图一张图地教；DeepSeek 改版时课本要跟着更新。

课本这一页：程序里 3 张截图 + DeepSeek 网站上 5 张截图（注册、实名、充值、API Keys、复制），每张一句话；再加「常见问题」：没收到验证码、余额不足、密钥粘错（多了空格）。

第 3 课　第一次对话必修5 分钟

步卡片上的话亮出哪里怎样算做完
1先开一个新对话：点左边的「新对话」。侧栏「新对话」回到空白首页
2在这个框里打一句话，比如「帮我写一张明天请假一天的请假条，理由是去医院复查」。不想打字就点「帮我填好」，然后按 Enter。输入框发出一条消息
3它正在写。字是一点点冒出来的；想让它停，点右下角的方块。这次等它写完就好。输入框右侧发送 / 停止按钮这一轮回复结束
4写好了。把鼠标移到它的回复上，下面会出现一排小按钮，点「复制」，就能粘到微信或 Word 里。回复下方的按钮排复制过一次（出现「已复制」）
5不满意可以直接接着说，比如「语气再正式一点」。它记得前面说过的话。输入框再发一条，或点「下一课」

这一课会真的调用模型，大约花 0.01 元，卡片第 2 步之前会说一句。

第 4 课　让它动手干活必修10 分钟

程序随包带一个「练习」文件夹：销售记录.xlsx（有重复行、日期格式乱）、三篇短文章、一张图片。开这课时复制到数据目录里的「练习」文件夹（用户定），不碰你自己的文件。

步卡片上的话亮出哪里怎样算做完
1「工作区」就是它能动的那个文件夹。我们给你准备了一个练习文件夹。点这里的文件夹名。侧栏工作区下拉菜单打开
2点卡片上的「用练习文件夹」，工作区就换成我们准备好的练习文件夹。（想自己选别的文件夹时，用菜单里的「打开文件夹」。）卡片按钮；菜单里的「打开文件夹」工作区换成练习文件夹
3看输入框左下角：「先问我」表示它要改文件前会先问你。新手请一直开着。「先问我」开关点「看懂了」
4让它干活：「把 销售记录.xlsx 里重复的行删掉，日期统一成 年-月-日，按月份汇总成一张新表，存成 汇总.xlsx」。可以点「帮我填好」。输入框发出消息
5它想写文件了，所以停下来问你。看清它要做什么，点「允许」。对话里的允许 / 拒绝卡片回答过一次允许
6做完了。点右上角这个按钮打开「这个对话」，在「文件」里能看到它读了什么、新建了什么。点 汇总.xlsx 就能打开。右上角侧边栏按钮、文件列表右侧面板打开

课本这一页另讲：什么时候点「拒绝」、拒绝了会怎样、「直接做」是什么意思和风险。

第 5 课　认识蝶君必修15 分钟，建沙箱另算

步卡片上的话亮出哪里怎样算做完
1点左上角的「蝶君」。「蝶君」切换进入蝶君
2蝶君在自己的「沙箱」里干活：一个隔离的小 Linux 系统，看不到你的文件，所以它做事不用你一次次批准。第一次要先建好沙箱：点「建立沙箱」。
电脑没有 WSL 时会弹出 Windows 的管理员确认，点「是」；可能要重启一次电脑，重启后程序会自己打开，接着学。		「建立沙箱」沙箱就绪（期间可去学别的，进度卡显示「沙箱正在建」）
3交给它一件事，比如「帮我查一下今年国内新能源车销量前五的品牌，写一份一页的小报告」。可以点「帮我填好」。输入框发出消息
4它会先列个计划（这件事大约 5–15 分钟、花 0.1–0.3 元，发出前卡片会先说），然后自己去查、去写。右边能看到目标、进度和花了多少钱。你现在可以去干别的。右侧目标卡点「看懂了」
5做完它会通知你，报告出现在「等你处理 › 等你验收」。点「打开看看」，满意就点「收下」。「等你处理」收下过一次交付（或点「做完再看」，之后自动打勾）
学完五课：卡片说「入门完成 🎉 你已经会用了。记忆、定时、技能、花费这些进阶内容在 设置 › 使用说明 里，用到再看」，侧栏进度卡消失。

第 6–10 课（只在课本里，每课带「带我去这里」）

课讲什么「带我去这里」去哪
6 它记住了什么记忆是什么；在哪看、怎么改、怎么删；「无痕」对话不留记忆；怎么让它别记某件事。侧栏「记忆」；输入框「无痕」
7 定时和长期目标让它每天早上整理新闻；给蝶君一个长期目标；在「日程」里暂停、删除。蝶君 ›「日程」
8 技能和常用说法技能是什么；装一个技能；把常说的话存成模板。侧栏「技能」
9 钱花在哪每次对话花多少；花费页怎么看；给蝶君设每天上限；小活换便宜模型。左下角「$」花费；设置 › 模型
10 出问题怎么办常见报错逐条对照：密钥不对、余额不足、网络不通、沙箱没建好、它卡住了；怎么重试、换模型；怎么导出诊断发给我们。设置 › 关于

课本放在哪、长什么样

程序里

  • 设置 › 关于 下面加一项「使用说明」，打开后左边十课目录、右边内容（像原型方案二那张图）。学过的课打 ✓。
  • 随包带，不联网也能看；内容就是仓库里的 Markdown，打包时一起带上，截图也带。
  • 每个「带我去这里」：切到对应页面，那个按钮闪两下。

仓库里

  • docs/guide/ 下十个 Markdown 文件 + 截图，GitHub 上直接能看；README 首页放一个「新手入门」链接。
  • 和程序里是同一份文件，改一处两边都变。
  • 截图按 1.0 preview 的界面重拍。

要你定的几处

用户 2026-11-18 已定：第 2 课用 DeepSeek；练习文件夹放数据目录里；第 5 课用「查资料写报告」；首页三个示例换成零基础的「帮我写请假条 / 把这张表整理一下 / 帮我查点资料」，点了只填进输入框。
  1. 第 2 课 DeepSeek 网站部分：网站上的注册、实名、充值几步只能放截图教。要不要另外推荐一个更省事的服务商当默认例子（比如已有账号的 OpenCode Go），还是就用 DeepSeek？
  2. 练习文件夹位置：放「文档\DreamFlutter 练习」可以吗？还是放在数据目录里（用户更难找到，但不往文档里加东西）？
  3. 第 5 课等待：蝶君做一份报告可能要 5–15 分钟，并会花大约 0.1–0.3 元。可以接受吗？还是换一个更小的任务（比如「写一段介绍你自己的话，存成文件」，一两分钟、几分钱）？
  4. 首页那三个示例按钮：保留现在的「整理这个文件夹里的资料 / 帮我读懂这段代码 / 一起梳理今天的工作」，还是换成更贴近零基础的（比如「帮我写请假条 / 把这张表整理一下 / 帮我查点资料」）？

做的顺序：先做课本（程序里 + 仓库），交你看；再做跟着做的五课，交你看。沙箱一键安装放在第 5 课之前做完。
