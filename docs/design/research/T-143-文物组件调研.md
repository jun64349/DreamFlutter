# 梦蝶文物线描与组件提案

配套 [离线组件样张](T-143-文物组件预览.html) · 2026-11-16

十二套主题共用按钮的尺寸和操作状态。第一版试了主题纹样和少量功能图标的转折。第二版回应用户反馈，把同一组八枚图标完整画成宋瓷和嵌木两套，连按钮边缘、选中反馈和背景方向一起对照。两套都保留图标的功能含义和 [现有蝴蝶资产](../assets/butterfly.svg)。

## 第二版 · 宋瓷与嵌木

**宋瓷**取北宋定窑白釉刻花洗一件实物。馆方记录了微敞器口、斜直壁、平底及口沿刻纹。从器口投影取宽圆的弧，从斜壁取内收，从口沿取和边缘平行的一小段浅刻。图标把这三种关系重新组合：主轮廓有长弧，必要的折线收于圆端，接缝转折用圆接。 [故宫定窑洗，故00143080](https://www.dpm.org.cn/collection/ceramic/228034.html)

**嵌木**取意大利古比奥公爵宫书斋嵌木一处实物。馆方说明木片组合产生透视效果。从构件取笔直板边、一致的短斜拼角和平齐收线。图标转折以直角与 45° 为主，端头平齐，留白也沿同方向对齐。玻璃只借一次静态内沿高光来提示部件亮面，轮廓始终按木嵌线处理。 [大都会艺术博物馆，39.153](https://www.metmuseum.org/art/collection/search/198556)

| 动作 | 宋瓷 | 嵌木 |
|---|---|---|
| 对话 | 横向圆腹一气勾成，左下短尾顺腹线弯回 | 截角的直边框，左下尾由两段直线接成 |
| 记忆 | 三层叠页，上层明确画出翻折纸角，下两层以圆转的页角和横边错开 | 三层叠页，上层保留 45° 折页，下两层以直边和齐平斜角错开 |
| 日程 | 上宽下略收的器形轮廓、圆端双挂钩、浅弧隔线 | 四角截断、方端双挂条、直隔线和一对短刻线 |
| 文件 | 页身圆转，右上角两道弧转成卷页 | 平直页身、小截角、右上大折角和 L 形折缝 |
| 搜索 | 横展圆腹作为镜面，右下柄延入一条向内收的弧 | 切角方形镜面，右下 45° 笔直柄，切平收尾 |
| 设置 | 六个圆钝齿连成花口外沿，以小圆提示齿轮中心 | 八个梯形直齿，中心六角榫，凹口短而分明 |
| 发送 | 朝上的箭头，双翼轻弯，主轴末端圆收 | 朝上的箭头两翼等角、平头，轴是竖直木线 |
| 停止 | 单个实心方形，边缘略外鼓，四角连续圆转 | 单个实心方形，四边直，四角轻截。两套均占约 16 个画板单位，在 14 px 的显示尺寸约为 9 px |

| 在组件中的位置 | 宋瓷 | 嵌木 |
|---|---|---|
| 图标 | 同一 `24×24` 画板和 `1.6` 主线，圆头圆接，至少保留约 2 单位的小间隙 | 相同画板和主线，平头、短斜切、折角收紧，避免多层点缀 |
| 按钮常态 | 轴线垂直的一圈柔圆边缘，内底留一小段浅弧刻线 | 轴线垂直的截角轮廓，右上可留一处斜拼缝 |
| 悬停／按下 | 原位加强浅弧可见度和底色，按下仅下移 1 px | 原位加强底色和斜拼缝，按下仅下移 1 px |
| 已选 | 选中底加贴边的短弧，保持同样点击区 | 选中底加一条直底边，保持同样点击区 |
| 键盘焦点 | 控件外一层清晰指示，焦点和已选可同时读出 | 同样是一层清晰指示，斜角里仍有足够留白 |
| 背景 | 边缘一小段低对比度器口弧，正文和工具栏区域留净底 | 侧缘留稀疏直纹和一处斜交缝，正文和工具栏区域留净底 |

样张支持黑白对照，初始先看 24 px 的形状。随后切到 16 px 看连续操作时能否区分。发送和停止的轮廓区别保留，停止仍用产品的危险状态表达。两套均使用原来的键盘操作、按下和禁用节奏。表中八枚是新画的功能线稿，器物资料提供外轮廓和工艺关系。

### 交给实现的两套形状

[组件路径与主题映射 JSON](T-143-文物组件路径.json) 已同步 Flutter 和原型中两套各 22 枚图标路径，保留原有尺寸、动效字段与主题映射，`calendar` 和 `settings` 适配源码中的 `cal` 和 `gear`。离线样张预览核心八枚，用 34 px 按钮容纳 24 px 图标，现有密集工具栏按 30 px 点击区、16 px 图标接入，原有较大入口按 24 px 使用。

- **用宋瓷轮廓**：暖纸、暮色、蛱蝶、墨夜、石青。从圆转、内收和短弧进入侧栏动作、输入框按钮、开关选中及同类按钮。石青继续保留清宫绣线和菱形滑块，宋瓷只作为通用控件的轮廓骨架。
- **用直边嵌木轮廓**：草蝶、羽化、神思、幽华、千蝶、琉光、幻蝶。使用直边、截角和平头进入同样的位置。千蝶仍用日本折本和漆器作为主题纹样来源，琉光仍用美国彩玻作为主题纹样来源；两者共享几何轮廓，保留各自素材和主题色。羽化已有刻度，继续沿用。
- **试用版最初接入位置**：八个功能图标先用于侧栏对话、记忆、日程，文件预览、搜索、设置和输入框发送／停止。后续统一的同族边缘、选中标记、控件反馈与局部背景见文首覆盖表。

## 从哪件藏品取哪一笔

十二套主题里有两对共用来源。暖纸、暮色是项目的基础明暗主题，原本没有指定作品，此处借同一件中国文房器。草蝶按梵高该画创作地法国南部选同期法国工艺，羽化依据荷兰出版和苏里南观察两个线索，幽华保留尼德兰语境并注明画家移居安特卫普的背景。下表中「画法」是本次设计提案。

| 主题 | 器物和年代 | 画法及适用位置 |
|---|---|---|
| 暖纸、暮色 | 中国，明代澄泥风字砚，故宫博物院 | 取砚面宽、下端敞开的形势和一道浅内沿。大样用开口轮廓加一笔内沿。控件只取一段浅折线作选中预览样式。深浅共用线稿，各自取现有颜色。省去铭文和印文。 [故宫藏品](https://www.dpm.org.cn/collection/studie/230397.html) |
| 蛱蝶、墨夜 | 中国，北宋定窑白釉刻花蟠螭纹洗，定窑窑址在今河北曲阳，故宫博物院 | 取刻划的深浅感和口沿回纹一个折转，结合原画草虫的一根斜茎构成样张。细线只出现在主题卡上，避免多重圆框，也省去蟠螭主体。原画名按故宫名画记标作北宋赵昌传。 [故宫藏品](https://www.dpm.org.cn/collection/ceramic/228034.html) · [故宫名画记](https://minghuaji.dpm.org.cn/article/detail?id=934) |
| 草蝶 | 法国南锡，埃米尔·加莱，1890 年以前的昆虫纹玻璃瓶，布达佩斯应用艺术博物馆 842 | 取瓶身翻沿的线条和刻纹疏密，提炼为长短错开的三笔；与原画草叶方向呼应。主题卡用三笔，按钮不加草叶或写实虫纹。这里的昆虫纹器形是同年代工艺参考。 [布达佩斯应用艺术博物馆](https://collections.imm.hu/gyujtemeny/vase-with-insect-decoration/82?npn=1) · [英国国家美术馆原画](https://www.nationalgallery.org.uk/paintings/vincent-van-gogh-long-grass-with-butterflies) |

## 共用的组件规格

| 项目 | 统一约定 |
|---|---|
| 功能图标 | 继续用原型 `24×24` 画板，常用显示 `16×16`，画板线宽 `1.6`，等比缩放后的视觉线宽约 `1.07`。圆头圆角、用当前前景色。图标仅是按钮的一部分。 |
| 点击区和圆角 | 密集桌面图标按钮统一用原型 `30×30` 逻辑像素点击区。普通按钮按现行 `8–10` 圆角，点击区互不相叠。 |
| 器物线稿 | 主题样张用 `24×24` 的 `1.6` 线，边缘留约 3 单位空白，彼此独立的线条留至少约 2 单位，通常 1–3 组笔画。16 px 看不清的纹样留在 24 px 及以上展示。纹样层不接收点击、焦点及读屏。 |
| 按钮 | 保留主按钮、普通、线框、危险、图标按钮。默认显露程度按原型。文字或提示沿用项目用词；图标按钮同名提示、读屏名称和快捷键继续可用。发送生成中沿用红色描边和停止方块，能立即停止。 |
| 选择和表单 | 分段通过原有选中底及语义表达，列表选中可沿用选中边线。开关用 `38×22` 和滑块两侧位置加语义。范围控件只有滑块和刻度随主题变，键盘仍能逐步调节且当前值可读。下拉沿用常见箭头。 |
| 颜色与尺寸检查 | 色值跟现有主题变量，正文及常规按钮字至少 `4.5:1`，有信息的图标、控件外形和焦点指示至少 `3:1`；用相邻真实底色检查。比较尺寸时覆盖 100%、125%、150% 缩放以及窄窗口。 [WCAG 2.2](https://www.w3.org/TR/WCAG22/) |

### 按钮反馈表

| 状态 | 看起来和用起来怎样 |
|---|---|
| 默认 | 原型常态底色和原有动作图标，密集图标按钮显示大小一致。 |
| 悬停 | 原位置轻抬底色的对比，显示已有名称提示。琉光可以有一条内高光。 |
| 按下 | `100–120ms`，下移 1 px、缩放 0.975；按压开始同时显露按下底，指针移出后松手取消。 |
| 键盘焦点 | 只在键盘焦点时显示一层 2 px 清晰轮廓，样张用方圆角沿控件边缘。焦点既可与已选叠加，也无须靠悬停才看见。用 Tab 到达、Enter/空格触发，从原控件语义继承按键。 |
| 已选 | 原有分段、开关或行选中形态，维持选中位置和读屏语义；有勾的场景只留原有勾。样张用「无痕」模拟可切换动作。 |
| 禁用 | 底色和图标收淡，保留原尺寸，不触发。密集工具栏仅在确实不可执行时禁用。 |
| 处理中 | 以同宽文字/图标给持久反馈，防重复提交；成功/失败在原有结果区给出。生成型操作保留原有「停止」入口。样张用短时「保存中」模拟。 |
| 减少动效 | 同步切换颜色、状态和文字。位移、缩放、旋转、亮度呼吸关闭；处理中仍显示静态符号和状态文字。 |

## 审阅建议

1. 优先看第二版「宋瓷与嵌木」板，先用黑白判断能否看出两套共同轮廓，再开材质色看按钮边缘与背景。点击任一个对应按钮，可以并排看同义动作的选中态。
2. 第一版「馆藏线稿」保留十二主题资料，后续决定哪些细节适合留给现有主题卡、滑块、范围刻度和内沿。
3. 进入实际原型前再核对原有快捷键、悬停提示、控件次序与深浅两端的读法。先在全组 24 px 和工具栏 16 px 下检查是否一眼认出。
