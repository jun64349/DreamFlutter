# T-143 主题与动效补充调研

2026-11-16 · **候选，未定稿**。只读 LibreChat、OpenHands 的固定版本源码及 LibreChat 主题文档；没有安装运行。配合 [开源 Agent 交互调研](T-143-开源Agent交互调研.md) 和 [文物组件调研](T-143-文物组件调研.md)，不重复其对话恢复、计时与图标提案。以下数值是可试的设计，不是已批准的行为；均放进现有页面，不改变定型操作。

## 五个小范围候选

1. **主题切换：统一换色，不让每层各跳一次。** LibreChat 的[官方主题说明](https://www.librechat.ai/docs/configuration/librechat_yaml/object_structure/theme)将颜色、形状、阴影、动效作为同一主题，区分明暗；该文档说明这套配置尚未发布到标签版。梦蝶现有 [v1-art.css:79](../prototype/v1-art.css) 给背景、文字、边框、阴影统一 `160ms cubic-bezier(.2,.7,.2,1)`；主题卡在 [v1-settings.js:27](../prototype/v1-settings.js) 已存在。**候选**：保留 160ms，只在颜色上过渡；同一次选择让全窗口一起换，避免主题纹样分别飞入。快速连续选择时以最后选中的主题为准，焦点仍在所选卡片；不加新开关。

2. **展开与收起：内容只淡入，焦点有归处。** LibreChat 的[工具参数源码](https://github.com/LibreChat-AI/LibreChat/blob/9363db541ecd4e23ab6a41dca47ca48ee2bd418e/client/src/components/Chat/Messages/Content/ToolCallInfo.tsx#L109-L128)以 `200ms ease-out` 转箭头、使用 `aria-expanded`，焦点环采用 `ring-2`；其[过程组源码](https://github.com/LibreChat-AI/LibreChat/blob/9363db541ecd4e23ab6a41dca47ca48ee2bd418e/client/src/components/Chat/Messages/Content/ToolCallGroup.tsx#L383-L399)在自动收起且焦点处于内容内时先返回标题。梦蝶 [v1-redesign.html:162](../prototype/v1-redesign.html) 的过程内容、[v1-art.css:142](../prototype/v1-art.css) 的计划内容均为 `120ms` 淡入，计划箭头反馈 `160ms`。**候选**：保留现有淡入及折叠规则，补展开状态语义；仅当焦点随内容被隐藏时送回原标题，不额外自动折叠、不做整段高度推拉。长消息既有十行规则不变。

3. **工具运行到完成：同一位置换状态，正文不动。** LibreChat [过程组源码](https://github.com/LibreChat-AI/LibreChat/blob/9363db541ecd4e23ab6a41dca47ca48ee2bd418e/client/src/components/Chat/Messages/Content/ToolCallGroup.tsx#L665-L693)运行中使用固定图标槽及脉动；新增过程项在平滑流式模式使用 `200ms` 淡入加位移，并显式关闭减少动效时的动画（[源码](https://github.com/LibreChat-AI/LibreChat/blob/9363db541ecd4e23ab6a41dca47ca48ee2bd418e/client/src/components/Chat/Messages/Content/ToolCallGroup.tsx#L780-L787)）。OpenHands [任务项](https://github.com/OpenHands/OpenHands/blob/2914e63bc8af5bcb58debb5dc869c73e292433df/src/components/features/chat/task-tracking/task-item.tsx#L22-L39)使用同尺寸 `w-4 h-4` 的未开始、进行中和完成图标。梦蝶现有 [v1-redesign.html:157](../prototype/v1-redesign.html) 过程块、`1.2s` 呼吸点及 `0.9s` 旋转标记。**候选**：继续只让正在执行的已有标记动；结束时同槽立即换静态完成/失败形状，文字与结果依事实更新，不播放庆祝动画或让正文位移。减少动效时运行状态仍有静态标记和原有文字。

4. **侧栏与预览：先稳定内容，再处理焦点。** LibreChat [侧栏打开源码](https://github.com/LibreChat-AI/LibreChat/blob/9363db541ecd4e23ab6a41dca47ca48ee2bd418e/client/src/components/Chat/Menus/OpenSidebar.tsx#L27-L39)等待 `250ms` 后，只有焦点仍在触发器或页面主体时才交给关闭按钮，避免抢回已经移走的焦点。梦蝶 [v1-redesign.html:50](../prototype/v1-redesign.html) 声明侧栏宽 `264px`、宽度及内边距 `120ms`，右栏 `312px`；但后载入的 [v1-art.css:79](../prototype/v1-art.css) 同样对 `#side` 写了 `transition` 简写，按 CSS 层叠会覆盖前面的宽度过渡声明，实际效果应以渲染检查为准。**候选**：若要保留侧栏宽度过渡，把同一元素需要的属性合并在一处，试 `120ms`；预览继续在右栏，切换时只换其内容，不叠加整页滑动。焦点交接应由实际布局完成触发，并先检查焦点是否还在原位置，不照搬固定 250ms。

5. **键盘焦点与减少动效：状态比运动更可靠。** LibreChat 参数按钮有明确焦点环、展开状态（见第 2 条）；[过程组](https://github.com/LibreChat-AI/LibreChat/blob/9363db541ecd4e23ab6a41dca47ca48ee2bd418e/client/src/components/Chat/Messages/Content/ToolCallGroup.tsx#L699-L705)收起后将内容标记隐藏。梦蝶输入框已有 `3px` 聚焦外晕（[v1-redesign.html:112](../prototype/v1-redesign.html)），系统减少动效及应用动效关闭均取消动画和过渡（[v1-art.css:148](../prototype/v1-art.css)）。**候选**：按钮、主题卡、过程标题在键盘焦点时用主题色 `2px` 清晰轮廓，与选中状态并存；收起的内容退出键盘顺序。把动效关闭选择器覆盖到与系统减少动效相同的按压目标：现有应用关闭规则漏了 `.tcard` 等后半组（[v1-art.css:150](../prototype/v1-art.css)）。检查主题实际相邻底色的焦点对比度至少 3:1；不是所有悬停效果都需要动画。

## 两套文化语言怎样落在十二主题

这是**几何与材质的设计类比**，不是把全部主题归属到两种文化，更不是给每个主题另造一套控件。现有颜色、名画母题和图标语义照旧；共用尺寸、排版、状态、交互和动效。馆藏依据与十二主题对应见[文物组件调研](T-143-文物组件调研.md)。

| 用法 | 建议范围 | 分寸 |
|---|---|---|
| 中式文房 / 宋瓷：圆弧、薄口沿、向内收 | 暖纸、暮色、蛱蝶、墨夜可优先试；石青借已有刺绣母题，不强称宋瓷 | 只在主题预览或大卡的一处边缘做浅内沿；常规卡仍用现有 `14px` 圆角、按钮 `8–10px`。内沿从主题色低对比取色，不能代替选中或焦点边界。 |
| 古比奥嵌木：平行直边、45° 小截角 | 神思优先试；草蝶、羽化、千蝶、幽华、琉光、幻蝶仍以各自名画和工艺为主，可在主题预览中试一小段直线而不改文化归属 | 神思已有 `3px` 内缩加第 `4px` 细线、12% 色混合（[v1-art.css:91](../prototype/v1-art.css)）。候选只在主题预览一角试小截角，不切掉真实按钮或卡片点击区，也不普遍加金边、厚框和木纹。 |

两组只是控制线条的不同手法：同屏最多一处明显装饰，正文和过程块不铺器物图案。主题区别主要靠现有配色与母题，状态靠清楚的文字、形状和对比；不做徽章、属性条、场景边框或奖励特效。无论形态，100%、125%、150% 缩放及深浅主题都要可辨，避免小角细线挤进文本。

## 控制范围与检查

先只在现有原型试 **主题切换、过程展开、运行到完成、侧栏开关** 四处；聚焦和减少动效与这四处一起检查。主题形态先各选暖纸、蛱蝶、神思做静态对比，接受后才看其他主题，不先逐主题重画。检查快速连续切换、焦点在展开内容内收起、执行结束、侧栏刚开就继续 Tab、系统减少动效和应用动效关闭；长回复滚动、预览位置及原定型交互保持稳定。调研未运行浏览器或 Flutter，也未声称这些候选已实装或通过验收。
