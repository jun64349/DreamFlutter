# 界面用词表（2026-11-09，0.8 起）

依据：[interaction-design.md](interaction-design.md) 5.3「一个词只有一个意思、全应用统一」和第二节第 4、7 条。界面上的文字（按钮、标题、提示、通知、错误）都照这张表。后台代码和文档里的内部名不受影响。

## 一、统一的叫法

| 界面上说 | 不说 | 指什么 |
|---|---|---|
| 对话 | 会话、session、会话文件 | 一次来回的聊天，侧栏列表里的每一项。新建的默认标题是「新对话」 |
| 工作台 | 对话模式、桌面 | 用户主导的空间 |
| 蝶君 | 书桌、梦君、Agent | 自主干活的空间和它本身 |
| 工作区 | 项目目录、cwd | 工作台里的一个项目文件夹，顶栏切换 |
| 等你处理 | 待处理、待确认、收件箱 | 侧栏入口和页面；页面诗意标题「这一笔等你点头」 |
| 允许 / 拒绝 | 批准、审批通过、approve | 批准卡上的按钮。设置里的那一项叫「操作前问我」 |
| 从这里重来 | 分支、分叉、fork | 消息上的操作；产生的对话缩进挂在原对话下 |
| 问一下 | 侧边对话、side chat | 选中文字后的操作；保存后在列表里显示为「问一下：……」 |
| 引用 | 选中回复、quote | 选中文字后变成输入框里的引用卡片 |
| 无痕 | 隐私模式、不保存 | 这次不保存、不记忆 |
| 思考深度 | 思考级别、reasoning effort | 输入框里的选项 |
| 对话模型 / 小任务模型 / 大任务模型 / 看图模型 | 辅助模型、记忆模型、压缩模型、主模型 | 设置「模型」里的四项 |
| 上下文 | tokens、窗口占用 | 圆环；点开有「整理上下文」 |
| 整理上下文 | 压缩、compact | 圆环里的操作 |
| 记忆 | 记忆库、记忆条目 | 侧栏入口；页面诗意标题「记下的事」 |
| 关于你 / 关于这个项目 / 蝶君自己的 | 全局 / 工作区 / 蝶君范围、scope | 记忆的三组 |
| 最近 | 记忆日志、memory log | 记忆页顶部按天的记录 |
| 可能过时了 | 待复核、review、过期 | 记忆条目唯一会显示的状态 |
| 它参考了哪些记忆 | 用到的记忆、快照 | 回复信息行里的项 |
| 技能 | 任务模板、模板、skill | 技能页列表项（模板也是技能，用「/」调出）；页面诗意标题「蝶园」 |
| 连接的服务 | MCP、MCP 服务、服务器 | 技能页的第二个分区 |
| 可用 / 已停用 / 等你确认 | 已信任、未信任、启用、来源状态 | 技能和服务每项唯一的状态 |
| 任务 | 写笺、笺、作业、job | 交给蝶君的一件事 |
| 进行中 / 等你 / 已完成 / 没做成 | 运行中、阻塞、失败、成功、已取消 | 蝶君任务的四种状态 |
| 交付物 | 产出、artifact | 蝶君任务完成时交的文件 |
| 产物 | artifact、输出文件 | 工作台对话里生成的文件，右栏「这个对话」的「生成的文件」里列出 |
| 这个对话 | 详情、运行面板、本次改动 | 工作台右栏：改动和产物、Git、上下文、常用操作（0.8.1） |
| 任务进度 | 详情 | 蝶君右栏 |
| 花费 | 仪表盘、账本、费用、用量 | 侧栏入口和页面 |
| 模型组 | 号池、模型池、备用链、自动 | 用户自己建的一组模型，按顺序用，前面的用不了自动换下一个（0.8.3）；设置「模型」里一张卡片 |
| 常用模型 | 收藏、显示的模型 | 一个渠道在各处模型列表里列出的那几个；其余在「更多模型…」里（0.8.3） |
| 设置 | 选项、偏好 | 侧栏入口；页面诗意标题「一方天地」 |
| 高级 | 更多选项、开发者 | 每组设置最下面收起来的部分 |
| 网络 | 联网搜索、网页读取、软件源、代理 | 设置里合并成的一组 |
| 沙箱 | WSL、发行版、虚拟机 | 蝶君干活的隔离环境，设置「蝶君」里 |
| 归档 / 回收站 | 隐藏、删除记录 | 对话列表底部；回收站 30 天内可恢复 |
| 定时 | 定时接着做、计划任务、schedule、定时再做一次 | 在对话里跟 Agent 说（0.8.1 起没有按钮） |
| 存成技能 | 把这次做法存成技能、存为模板 | 右栏「常用操作」 |
| 无痕 | 这段对话不记忆、本会话记忆 正常/只读/关闭 | 输入框里；不保存、不记忆 |

## 二、界面上不出现的词

tokens、快照、层级（一级 / 二级 / 三级）、状态码、slot、session、scope、MCP、Pi、WSL、schema、job、模板、写笺、Agent（用「工作台」「蝶君」或「它」）。

## 三、写文字的规矩

- 能靠布局看懂的不写字（设计第二节第 7 条）：输入框的占位只写「说点什么…」，快捷键说明放进「?」或悬停提示；数字为 0 的徽标不显示；空的搜索框不显示清除按钮。
- 按钮用动词开头、两到四个字；状态用形容词或短语，不加「状态：」前缀。
- 错误说清两件事：出了什么事、可以怎么办（设计 4.4 第 4 条）。

新词先加进这张表再用。表里没有、拿不准的，写进任务文件问 Claude。
