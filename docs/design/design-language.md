# DreamFlutter 界面设计语言（0.4）

记录日期：2026-11-05。0.4「外壳与呈现」做出来、用户确认过的界面规则。品牌（图标、配色随主题）见 [brand.md](brand.md)；计划见 [../roadmap.md](../roadmap.md) 的 v0.4；实现细节和测试见 [../HANDOFF.md](../HANDOFF.md)「0.4 进度」。

## 一、总的气质

- 文艺、简洁、大气，留白多（用户 2026-10-29，参考 HanaAgent）；蝴蝶元素；颜色、字体、圆角来自当前名画主题（`app/lib/theme.dart` 的 `PaintingTheme` / `AppColors` / `AppTokens`），**任何颜色都不写死在页面里**。
- 字体：标题、回复正文、问候语用宋体（Noto Serif SC），界面文字用黑体（Noto Sans SC），代码用等宽（Cascadia Mono）。
- 少而清楚：平时只露必要的东西，过程、数字、操作在需要时（悬停、点开、打开详情）才出现。

## 二、窗口框架（4.2，用户选定：设计稿方案三 + 方案一的顶栏）

设计稿：https://claude.ai/artifact/NYpoVANRPEKZPmMgkhKYuS，源文件 [canvases/frame-0.4/](canvases/frame-0.4/)：`option3-focus-chosen.dc.html` 是选定稿，`option1-main.dc.html` 留作对照（顶栏取自它），`option2-rail-rejected.dc.html` 用户删掉了。

- **顶栏**（`ui/window_frame.dart` 的 `AppTitleBar`，高 44，不随界面缩放，每个页面都在）：标志 + 「DreamFlutter」（宋体）｜位置面包屑「工作台 / 〔工作区下拉〕 / 会话标题」（蝶君页「蝶君 / 标题」，任务、记忆、技能页显示页名）｜右侧详情开关、窗口按钮。空白处拖动窗口、双击最大化。
- **工作区切换要一眼看得到**：面包屑里的工作区是带边框的下拉按钮；下拉列出每个工作区的名字和完整路径、当前的打勾；底部「打开文件夹作为工作区…」「在资源管理器中显示」；Ctrl O 打开，Esc 关；侧栏「某工作区 的对话」旁的切换按钮打开同一个下拉。
- **一条共用侧栏**（`ui/sidebar.dart`，取代原来的图标导航条）：顶部「工作台 | 蝶君」切换（另一边在忙时有呼吸点）、新建对话（旁边是无痕）、搜索（点了才出搜索框）、任务（有待处理时红底数字）；中间是当前工作区的对话（蝶君页列蝶君的对话）；底部图标：记忆、技能、仪表盘、外观，最右设置。右边缘可拖宽（232–420，记住）。
- **详情（右栏）按需打开**：默认关着，顶栏按钮打开；窗口够宽（对话还剩 ≥640）时停在对话旁边，窄时盖在对话上带阴影；左边缘可拖宽（280–560，记住）。

## 三、详情的内容（4.3）

标签：概览｜写笺（只在蝶君）｜分支｜侧边对话（有时才出现）。「概览」分块，每块可折叠、记得折叠状态：

进度（待办清单，几 / 几）→ 步骤（只显示最近 5 步，「显示前面的 N 步」）→ 产物与改动 → 子 Agent 与后台 → 上下文与花费（圆环 + 用量 + 会话花费 + 上次耗时花费）→ 常用操作（存成技能、存为模板、定时接着做、用到的记忆、刷新记忆快照；原来藏在「⋯」里，用户反馈第 27 条）。

**给 0.8 的「目标」留了位置**：设计稿里详情最上面是目标块（标题、状态和原因、验收条目、已用预算、暂停 / 停止 / 修改目标），任务视图按「等你决定 / 阻塞 / 等你验收 / 运行中 / 暂停 / 完成」排。数据结构见 [../long-task-design.md](../long-task-design.md) 第十四节。

## 四、对话里的呈现（4.4、4.5）

- **过程默认折叠**（用户反馈 32、额外 7）：结束后一行总结（「思考过 · 读取 2 个文件 · 运行 1 条命令」）；运行中标题写「正在读取：…」，下面只露最近三步、每步一行，更早的写「前面还有 N 步」。
- 每种工具一行（图标 + 动词 + 对象）；命令也是一行（写用途），点开才是终端，出错自动展开；**终端颜色跟主题**：白天用纸色代码底，夜里用深色终端；改动块（加删行的差异）保留用户喜欢的样子；MCP 写「MCP · 服务 · 工具」；看过的图片显示缩略图，点开大图可缩放。
- **回复下方**（用户反馈 21）：信息和按钮在同一行，平时隐藏，鼠标移上去或键盘焦点时才出现；信息只留「模型 · 耗时 · 花费」，完整数字在悬停提示里；按钮 18 号图标、36×34。

## 五、输入框（4.6）

模式在输入框里选：标准 / 极简 / **无痕**。无痕 = 原来的临时对话（极简模式、不保存、不读写记忆）；从无痕选别的模式会新开保存的会话；设置里只选默认模式（标准或极简）。上下文用量小圆环在发送键左边。

## 六、选中文字回复（4.7）

在回复里拖选文字，松开处浮出小框「回复 / 侧边对话」（右键菜单里也有）。「回复」把选中内容作为引用接在输入框已有文字后面；「侧边对话」在详情里开一段小对话，带着主对话到此为止的内容（后台在内存里分叉，不写回、不保存、不进记忆），可「带回主对话」（把回答作为引用放进输入框）、「结束」。

## 七、首页（v0.3.1 第 5 条）

新会话只显示蝴蝶和一句问候语：宋体 32、字距 6、墨色 → 主色 → 赭石渐变。问候语随机（`ui/greetings.dart`：清晨、上午、午后、傍晚、深夜各 4 句，通用 10 句，蝶君 6 句），同一会话不变。用户原话：「只保留 logo 和一句问候语，问候语多做一些然后随机显示就好，用一下艺术字啥的效果会很好」。第一次使用的「开始之前」引导保留到用户点「知道了」。
