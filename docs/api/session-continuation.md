# 旧会话续聊

启用 DSH 的后台以只读方式打开旧 Pi 会话。`slot.open` 和会话的 `get_state` 返回 `readOnly: true`。`df_navigate_tree` 在打开的视图里选择一条分支。原会话文件保留原有字节，分支切换也不会落盘。

## sessions.continue
<!-- api:method -->

- 参数 `sourceSlotId` 是已打开的旧会话槽位。可选的 `branchId` 指定该会话的条目，默认接续窗口当前选中的分支。可选的 `slotId` 是调用方为新槽位预先分配的标识。
- 返回新槽位的 `SlotInfo`。新会话有独立的路径和编号，记录来源会话及分支。创建时不请求模型。第一次发送消息时，所选分支的上下文进入 DSH 会话。
- 图片、已完成的工具结果和压缩摘要随所选分支保留。历史工具调用作为记录进入上下文，启动续聊不会执行这些调用。旧记忆快照、记忆及历史搜索工具结果、系统提示和其他分支不会随分支送入新模型请求。引用所选分支以外的分支摘要留在历史里供查看。
