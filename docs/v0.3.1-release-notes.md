# DreamFlutter v0.3.1 发布说明

v0.3.1 加上整个平台的备份、迁移与恢复：把数据打成一个文件，在新版本或另一台电脑上导入，出了问题能回到原样。设计见 [v0.3.1-backup-design.md](v0.3.1-backup-design.md)。

## 设置 › 数据与迁移 › 备份与恢复

- **导出备份**：记忆、会话、任务、定时任务、卡片、模型渠道、Pi 的设置（技能、模板、模型配置）、界面偏好、蝶君的资料和沙箱里的文件，打成一个 `.dfbackup` 文件。工作区里的文件只记位置，不打包。
  - 可选「包含 API Key」：Key 用你设的迁移密码加密后放进去，导入时输入这个密码；不勾选时，导入后要重新填 Key（这台电脑上已有的 Key 会保留）。
  - 有任务正在运行时不能导出；导出中途取消或出错，不会留下半成品。
- **导入备份**：选文件 → 检查（来源版本、时间、电脑，各有多少会话、记忆、任务……）→ 核对工作区的位置（换了电脑或用户名时可以改）→ 准备 → 替换。替换前会**自动备份现在的数据**，后台重启后完成替换；任何一步失败都回到原来的数据。
  - 恢复后定时任务都先暂停，检查后再打开。
  - 「上次恢复」里能看到恢复了什么、没恢复什么、要重填哪些 Key，可以**撤销这次恢复**。
  - 只支持 v0.3.0 及以后做的备份；比当前应用新的备份会被拒绝，不改任何数据。
- **备份记录**：手动导出和自动备份的列表。升级数据库前、导入前各自动备份一次，各留最近 3 份。

## 已知的限制

- 第一版只能整套替换：不能和现在的数据合并，也不能把备份恢复成另一套并存的数据。
- 备份包含会话文件夹里的所有会话，包括你用 Pi 命令行自己开的会话；恢复时不删除这台电脑上原有的会话。
- 蝶君的沙箱只带 `/workspace` 和家目录，不带整个系统：恢复后用应用自带的镜像重建，沙箱下次启动时放回文件。
- 换电脑、换 Windows 用户的迁移只在测试里模拟过（不同的文件夹），还没在两台真实电脑之间试过。
