# DreamFlutter v0.3.3 发布说明

按用户 v0.3.2 实测（`dfv0.3.2测试记录.md`）做的修复版。用户的要求：做全功能常用场景的测试，排除影响使用的 bug，把踩过的坑写成开发规范。

## 修好的问题（v0.3.2 实测）

- **生成时滚轮滚不动、点一下又跳回底部**：原来离底部 80 像素内都算「在底部」，一格滚轮约 50 像素，生成时下一帧就被拉回去。现在用户一滚就放开，只有真正回到底部才继续跟随；离开底部时右下角出现「回到底部」箭头，点了回到底部并保持跟随。工作台和蝶君都一样。
- **拖选文字错位、拖不动只能双击**：界面缩放不是 100% 时，Flutter 自己的滚动列表把滚动距离按没缩放的值算，滚得越远偏得越多（拖第一段选中第三段，偏太多就什么都选不上）。对话列表改为让文字直接登记到选区，不经过列表的换算。100%、110%、125%、150% 都测过。
- **工作台的图片跑到蝶君的输入框里**：拖放区会收到整个窗口的拖放，藏在后面的蝶君页面也收了。现在只有正在显示的页面接收（工作台、蝶君的「交流」和「工作」、上面盖着设置页时都不收）。会话本身没有串，两边的会话是分开的。
- **生成时图片明暗闪**：每出一个字都把图片重新解码一次。现在同一张图只解码一次。
- **按了 Ctrl 后一直是缩放状态**：截图工具（Ctrl+Alt+A、Win+Shift+S）在按键按下时抢走了键盘，应用收不到「松开」。现在判断 Ctrl / Shift 时会问 Windows 实际有没有按着。
- **问题气泡里出现「[Image: original 1350x817, …]」**：这是 Pi 写给模型看的图片说明，不再显示。
- **记忆重复、把 Agent 的名字记成用户的**（止血，整体重做在 0.5）：
  - 写入记忆前查有没有意思相近的：重复的不再加；说得更完整的变成对原来那条的「修改」建议，等你确认。
  - 自动整理时把全部记忆和待确认的都给模型看（原来只给字面相近的几条），并要求以「用户」为主语、Agent 的名字和身份不算用户的信息。
  - 已经在记忆库里的重复条目没有自动删，请在记忆页手动删掉多余的那条（「用户叫蝶君……」那条可以删）。
  - 你提的这些问题都记进了记忆系统的设计（[memory-design.md](memory-design.md) 第十五节），0.5 逐条解决。

## v0.3.1 实测留下的几条

- 选中文字时行内代码没有高亮：段落是先画选区、后画文字，行内代码的底色把选区盖住了。行内代码改成不铺底色，用等宽字体和赭石色区分。
- 备份页太复杂：改成一行说明 + 「导出备份」「导入备份」两个按钮；导出选项和备份记录折叠起来，选了备份文件才显示要导入的内容。
- 仪表盘的分项表格加了表头（渠道 / 模型 / 工作区 / 会话、花费占比、token、花费、回复）。
- Python 报错乱码：用 Agent 的方式（PowerShell、你的 `E:\coding environment\.venv` 里的 Python、中文路径、中文断言信息）实测了一次性和常驻两种 shell、带不带 `2>&1`，都正常显示中文，没能复现。v0.3.2 起 Agent 的命令带 `PYTHONIOENCODING=utf-8`，可能已经解决；再遇到请把那条命令和脚本发给我。

## 测试

- 新增**场景巡检**（`integration_test/scenarios_test.dart`，真窗口、真字体、假后台）：生成中滚轮和「回到底部」、图片不闪、四档缩放下工作台和蝶君的拖选复制、拖放只给正在显示的页面、打开全部页面 / 设置分类 / 名画主题不报错、Shift+Enter 换行。它第一次跑就发现了一个新问题：**窗口不高、缩放 150% 时左侧导航栏溢出**（底部出现黄黑条纹），已改为放不下时可以滚动。
- 新增组件测试 `chat_reading_test.dart`（滚动、选字），以及拖放、备份页、记忆去重的回归测试。每个修复都确认过「去掉修复测试就失败」。
- 全量：后台 199、窗口 95、场景巡检 5、视觉检查、卡片、真实模型端到端。
- 全场景测试清单：[testing/scenarios.md](testing/scenarios.md)（每个场景由哪个测试覆盖、哪些只能手动、发布前的手动清单）。
- 开发规范与踩坑：[dev-guide.md](dev-guide.md)（这次的几个坑：隐藏页面还在收事件、界面缩放下的坐标、修饰键卡住、流式输出时的重建、PowerShell 编码……）。

## 要你试的

1. 生成一个长回答时用滚轮往上看，再点右下角的箭头。
2. 缩放到你平时用的比例，在一个很长的对话里拖选一段复制。
3. 用截图工具截个图再回到应用，滚轮应该是滚动。
4. 往工作台拖一张图，切到蝶君，输入框里不该有它。
5. 选中带行内代码的一段，看看高亮。
6. 备份页、仪表盘看一眼。
