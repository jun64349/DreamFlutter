## 一、调研要点

### HanaAgent（openhanako，2026-10-30 查看）

- **整体气质**：暖纸色底（`#F8F4ED`，带一层很淡的纸纹）、低对比的灰墨文字（`#3B3D3F`）、一种克制的雾蓝强调色（`#537D96`），宋体/衬线做标题。默认主题叫「暖纸」，说法是「Hana 的手抄本」。官网横幅是浮世绘风格的月夜枝影。
- **布局**：三栏。左栏会话列表（含「助手活动」「任务计划」），中间对话，右栏上半是「书桌」文件、下半是「笺」（淡黄便签，Agent 会读）。顶部居中一个「聊天 / 频道」切换。
- **新会话空状态**：居中的剪影头像（像一枚浮雕胸针）、一句「今天想聊点什么？」、Agent 选择、当前工作空间、记忆入口。没有一堆功能按钮。
- **输入框**：圆角卡片，下方一排小标签（「操作电脑」「看看书桌」）、模型选择、发送。
- **装饰**：标题两侧各一条细线（「—— 书桌 ——」），分区靠留白和极淡的底色区分，几乎没有边框和阴影。
- **其他值得借鉴**：首次运行的引导向导（语言 → 名字 → 连接模型 → 选三个模型）；可单独设视觉模型（Vision Bridge）；全屏媒体查看器（滚轮缩放、+ / − / 0）；选中正文可引用到输入框继续追问。
- **不照搬的**：多 Agent 人格、频道群聊、社交平台接入，不在我们这一轮范围内。

### 同类桌面客户端（Claude、ChatGPT、Cherry Studio、LobeChat 等）的共同做法

- 会话列表可收起；对话区最大行宽约 720–760px，正文行高 1.6–1.8。
- 回复下面一行操作（复制、重新生成、分支），最新一条常显。
- 工具调用默认收成一行，展开看细节；命令显示成终端样式。
- 模型和思考级别放在**输入框**里，而不是顶栏：选模型是「这一句话用谁」，离发送按钮近更自然。
- 设置分类在左、内容在右，带搜索。

### 蝴蝶与名画（主题来源）

| 作品 | 作者 / 年代 / 收藏 | 能借的东西 |
|---|---|---|
| 《写生蛱蝶图》 | 北宋·赵昌，北京故宫博物院 | 淡设色、留白、工笔细线、秋草与蛱蝶；宋画的纸绢色和石绿、赭石 |
| *Long Grass with Butterflies*（开花的长草与蝴蝶） | 梵高，1890 年 5 月，伦敦国家美术馆 | 满幅的草绿笔触、白色小蝴蝶；同系列《罂粟与蝴蝶》（1890，梵高博物馆）的一点罂粟红 |
| *Metamorphosis insectorum Surinamensium*（苏里南昆虫变态图谱） | 玛丽亚·西比拉·梅里安，1705 年 | 博物图谱：铜版细线、手工上色、编号图版；卵 → 幼虫 → 蛹 → 蝶的「变态」顺序 |

另外一个和名字天然契合的意象：**庄周梦蝶**（「昔者庄周梦为胡蝶」，《庄子·齐物论》）。DreamFlutter = 梦 + 振翅，可以作为品牌故事，三套方向都能用。

备选（以后做更多主题时用）：神坂雪佳的琳派木版、海克尔《自然界的艺术形态》里的鳞翅目图版、雷东的粉彩蝴蝶（适合深色主题）。

## 二、信息架构

### 导航（最左侧窄栏）

| 位置 | 入口 | 说明 |
|---|---|---|
| 上 | 对话 | 主页面 |
| | 书桌 | 写笺、资料、产物 |
| | 任务 | 待处理收件箱 + 全部任务 + 定时任务（不变） |
| | 记忆 | 不变 |
| | 技能 | 技能与模板（不变） |
| 下 | 仪表盘 | **新增**（阶段 3）：花费、用量、渠道健康、额度 |
| | 外观 | 阶段 0 已加（缩放、文字大小、主题），以后主题选择也在这里 |
| | 设置 | 阶段 3 改为分类 + 搜索 |

### 对话页（三栏，左右两栏都可收起）

- **左：会话列表**（240px）：搜索、新会话、临时对话；按「今天 / 昨天 / 更早」分组；运行中的会话有呼吸点；定时任务产生的会话单独折叠成一组。
- **中：对话**
  - 顶栏：会话标题（衬线）、右侧只留「分支树」和「右栏开关」「更多」三个图标。模型和思考级别从顶栏移到输入框。
  - 消息：用户消息靠右浅底；AI 回复不加气泡，正文行宽 ≤ 720px。
  - 思考：一行「思考了 12 秒」，展开后弱化显示。
  - 工具：连续调用合成一组「读取 2 个文件 · 运行 1 条命令」；命令是终端样式（命令 + 输出），改文件是差异对比，读取和搜索各一行。
  - 回复下方：一行小字数据（模型 · 输入/输出 token · 首字延迟 · 速度 · 耗时 · 花费 · 时间），再下面是操作栏（阶段 0 已做）。
  - 输入框：圆角卡片；左下「附件」「@ 书桌」，右下「模型」「思考」「上下文用量小圆环」「发送」。原来的底部状态栏取消，连接状态出问题时才在输入框上方出现一条提示。
- **右：任务面板**（300px，可收起）：三个标签——「本次运行」（阶段进度、步骤、改动的文件、花费）、「书桌」（把资料拖进对话）、「分支」（分支树）。
- **新会话空状态**：居中的蝴蝶标志 + 一句问候 + 三个「试试看」卡片 + 当前工作区；不放说明文字墙。

### 书桌页

- 左：写笺列表（上）和资料（下）。
- 中：打开的写笺，纸面样式编辑器，右上「交给 Agent」。
- 右：产物（最近生成的文件）和进行中的任务。

### 仪表盘（阶段 3 实现，这里先定样子）

- 顶部四个数字：本月花费 / 预算、今日 token、今日请求、成功率。
- 中间：近 30 天花费趋势；按渠道、模型拆分。
- 下方：渠道列表（健康状态、延迟、今日花费、Token Plan 周期额度进度条）；逻辑模型的路由（例如「主力对话：DeepSeek → Kimi → OpenRouter」）。

### 第一次打开

三步引导：连接模型（或导入 CC Switch / Pi 现有配置）→ 选工作区 → 试一个任务（从三个例子里点一个）。各页面空状态写清楚「这里能做什么」和第一步按钮。

## 三、三套视觉方向

三套用同一套布局（上面的信息架构），只换视觉语言，方便对比。都能在设置里切换，以后每幅名画一个主题。

| | A「蛱蝶」 | B「草间」 | C「图谱」 |
|---|---|---|---|
| 来源 | 赵昌《写生蛱蝶图》 | 梵高《开花的长草与蝴蝶》 | 梅里安《苏里南昆虫变态图谱》 |
| 气质 | 宋画、留白、安静 | 明亮、生机、手绘感 | 博物志、精确、理性 |
| 底色 | 纸绢色 `#F3ECDD` | 暖白 `#F7F6EE` + 淡草绿侧栏 | 纸白 `#FAF9F4` |
| 强调色 | 石绿 `#3F6E5E`，一点朱砂印章 `#A8332A` | 草绿 `#3B6A35`，一点罂粟红 `#C0462C` | 闪蝶蓝 `#2C5A8A`，一点赭红 `#B0502F` |
| 字体 | 标题和正文都用宋体（思源宋体） | 标题宋体，正文黑体 | 标题衬线（拉丁用 Cormorant），正文黑体，小标签用字距拉开的小号字 |
| 形状 | 小圆角、细线、几乎无阴影 | 大圆角、柔和投影 | 直角、发丝线、图版边框和角标 |
| 蝴蝶 | 工笔线描、淡彩 | 白色小蝶、短笔触 | 对称的标本图，编号「图 I」 |
| 特色 | 「梦蝶」朱印、竖排题字 | 草叶笔触作为分隔和进度 | 运行进度用「卵 → 幼虫 → 蛹 → 蝶」四个阶段表示 |

每套以后都配深色版（不在这一轮设计稿里）。

## 四、落地须知

- 字体要随应用打包：思源宋体 / 思源黑体（可只打常用字子集），C 方向另需 Cormorant Garamond；等宽用 JetBrains Mono。
- 所有颜色、字体、圆角、阴影、蝴蝶插图集中到 `app/lib/theme.dart`，主题是一组值，可切换。
- 设计稿里的数字都是示例数据。
